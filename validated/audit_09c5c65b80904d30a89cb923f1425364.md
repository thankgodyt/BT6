### Title
Stub `validatePerasCert` always returns `Right`, enabling fabricated multi-round certificate flood to inflate chain weight and force divergent chain selection — (`ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Block/SupportsPeras.hs`)

### Summary

The production `makePerasCertPoolWriterFromChainDB` passes `validatePerasCert mkPerasParams` — a stub that unconditionally returns `Right` for every certificate — to `processCerts`. An adversarial peer on `NodeToNodeV_16` can send a batch of N `PerasCert` messages with distinct `pcCertRound` values all referencing the same adversarial `pcCertBoostedBlock`. Every certificate bypasses cryptographic validation, passes the round-number deduplication filter, is stored in the `PerasCertDB`, and contributes its `perasWeight` (= 15) to the `PerasWeightSnapshot` for the adversarial block. With N = 100 certs the adversarial block accumulates a boost of 1500, making any chain containing it appear 1500 blocks heavier than it actually is. `chainSelectionForBlock` is then triggered for the adversarial block, and if the inflated weight exceeds the honest chain's total weight, the node irreversibly switches to the adversarial chain.

### Finding Description

**Entry point**: `NodeToNodeV_16` Peras cert diffusion mini-protocol, wired unconditionally in `mkHandlers` / `initiatorAndResponder` in `NodeToNode.hs` (lines 375–383, 1259–1263). No version guard prevents a peer from sending `PerasCert` messages.

**`processCerts` (lines 156–184, `PerasCert.hs`)**:
```
alreadyInDb <- atomically alreadyInDbSTM          -- reads Set PerasRoundNo
let certsNotAlreadyInDb = filter (not . (`Set.member` alreadyInDb) . getPerasCertRound) certs
case partitionEithers (validateCert <$> certsNotAlreadyInDb) of
  ([], validatedCerts) -> mapM_ (addCert . WithArrivalTime now) validatedCerts
```
The filter is keyed on `pcCertRound`. N certs with rounds 1…N and the same `pcCertBoostedBlock` all pass.

**`validatePerasCert` stub (lines 353–358, `SupportsPeras.hs`)**:
```haskell
validatePerasCert params cert =
  Right ValidatedPerasCert { vpcCert = cert, vpcCertBoost = perasWeight params }
```
No signature check, no committee membership check, no quorum check. Every cert is accepted.

**`implAddCert` (lines 174–201, `Impl.hs`)**: Deduplication is `Set.member roundNo pcdsCertIds`. Different rounds → all N certs are inserted.

**`implGetWeightSnapshot` (lines 207–214, `Impl.hs`)**:
```haskell
mkPerasWeightSnapshot
  [ (getPerasCertBoostedBlock cert, getPerasCertBoost cert)
  | cert <- Map.elems pcdsCertsByTicket ]
```
`mkPerasWeightSnapshot` uses `Map.insertWith (<>)` — weights for the same point are **summed**. N certs boosting block B → boost of N × 15.

**`chainSelSync` (lines 483–532, `ChainSel.hs`)**: For each cert whose boosted block is in the VolatileDB and not on the current chain, `chainSelectionForBlock` is called. With N = 100 certs, this runs 100 times for the same adversarial block, each time with the accumulated boost already in the snapshot.

**`wsvTotalWeight` / `preferCandidate` (`SelectView.hs` lines 58–87)**: The candidate chain wins if `blockNo(adversarial) + 1500 > blockNo(honest) + honestBoost`. For a node with an honest chain of length H and no honest boosts, any adversarial chain of length ≥ H − 1499 wins.

### Impact Explanation

An adversarial peer can cause an honest node running `NodeToNodeV_16` to irreversibly switch to a minority or adversarial chain. Once the node's immutable tip advances on the adversarial chain, the divergence is permanent without operator intervention. This satisfies the "irreversible divergent chain" criterion. If the adversarial chain omits transactions present on the honest chain, this also enables double-spend.

### Likelihood Explanation

- Requires `NodeToNodeV_16` to be negotiated (introduced in this codebase, changelog confirms it).
- No stake, no keys, no privileged access required — any peer that can establish a `NodeToNodeV_16` connection can send arbitrary `PerasCert` CBOR messages.
- The adversarial block must be a structurally valid block already in the victim's VolatileDB (obtainable via normal block diffusion on a minority fork).
- The attack is deterministic and requires sending only ~100 small messages.

### Recommendation

1. **Immediate**: Gate `processCerts` on a real `validatePerasCert` implementation that verifies the certificate's aggregate signature and committee membership before accepting any cert. Until real validation is available, reject all inbound certs (return `Left` unconditionally) rather than accepting all.
2. **Structural**: Add a deduplication check in `processCerts` / `implAddCert` that rejects any cert whose `pcCertBoostedBlock` is already boosted by a cert for a different round (equivocation across rounds for the same block is not a valid Peras protocol state).
3. **Weight cap**: `implGetWeightSnapshot` should enforce the Peras invariant that at most one certificate per round contributes weight, and that the total boost for any single block is bounded by the protocol parameters.
4. **Protocol version guard**: Until validation is complete, disable the Peras cert diffusion inbound handler for all negotiated versions.

implAddCert PerasCertDbEnv{pcdbTracer, pcdbState} cert = do
  let roundNo = getPerasCertRound cert
  addPerasCertRes <- do
    WithFingerprint pcds fp <- readTVar pcdbState
    if Set.member roundNo (pcdsCertIds pcds)
      then pure PerasCertAlreadyInDB
      else do
        let pcdsLastTicketNo' = succ (pcdsLastTicketNo pcds)
            pcdsCertIds' = Set.insert roundNo (pcdsCertIds pcds)
            pcdsCertsByTicket' = Map.insert pcdsLastTicketNo' cert (pcdsCertsByTicket pcds)
            pcdsLatestCertSeen' = case pcdsLatestCertSeen pcds of
              Nothing -> Just cert
              Just prev
                | getPerasCertRound cert > getPerasCertRound prev -> Just cert
                | otherwise -> Just prev
        writeTVar pcdbState $
          WithFingerprint
            PerasCertDbState
              { pcdsCertIds = pcdsCertIds'
              , pcdsCertsByTicket = pcdsCertsByTicket'
              , pcdsLastTicketNo = pcdsLastTicketNo'
              , pcdsLatestCertSeen = pcdsLatestCertSeen'
              }
            (succ fp)
        pure AddedPerasCertToDB
  pure $ do
    traceWith pcdbTracer (AddCert roundNo cert addPerasCertRes)
    pure addPerasCertRes

chainSelSync cdb@CDB{..} (ChainSelAddPerasCert cert varProcessed) = do
  curChain <- lift $ atomically $ Query.getCurrentChain cdb
  let immTip = AF.castAnchor $ AF.anchor curChain

  certResult <- withEarlyExitId $ do
    -- Ignore the certificate if it boosts a block that is so old that it can't
    -- influence our selection.
    when (pointSlot boostedBlock < AF.anchorToSlotNo immTip) $ do
      lift $ lift $ traceWith tracer $ IgnorePerasCertTooOld certRound boostedBlock immTip
      idExitEarly PerasCertIgnoredTooOld

    -- Add the certificate to the PerasCertDB.
    certRes <- lift $ lift $ join $ atomically $ PerasCertDB.addCert cdbPerasCertDB cert
    -- Here:
    -- \* if the certificate is already in the PerasCertDB, we exit early with that result
    -- \* if the certificate is newly added to the PerasCertDB, we bind  the result value that we will return in any of the branches below
    addedCertRes <-
      case certRes of
        PerasCertDB.PerasCertAlreadyInDB -> idExitEarly $ PerasCertProcessed PerasCertDB.PerasCertAlreadyInDB
        PerasCertDB.AddedPerasCertToDB -> pure $ PerasCertProcessed PerasCertDB.AddedPerasCertToDB

    -- If the certificate boosts a block on our current chain (including the
    -- anchor), then it just makes our selection even stronger.
    when (AF.withinFragmentBounds (castPoint boostedBlock) curChain) $ do
      lift $ lift $ traceWith tracer $ PerasCertBoostsCurrentChain certRound boostedBlock
      idExitEarly $ addedCertRes

    boostedHash <- case pointHash boostedBlock of
      -- If the certificate boosts the Genesis point, then it can not influence
      -- chain selection as all chains contain it.
      GenesisHash -> do
        lift $ lift $ traceWith tracer $ PerasCertBoostsGenesis certRound
        idExitEarly $ addedCertRes
      -- Otherwise, the certificate boosts a block potentially on a (future)
      -- candidate.
      BlockHash boostedHash -> pure boostedHash
    boostedHdr <-
      lift (lift $ VolatileDB.getBlockComponent cdbVolatileDB GetHeader boostedHash) >>= \case
        -- If we have not (yet) received the boosted block, we don't need to do
        -- anything further for now regarding chain selection. Once we receive
        -- it, the additional weight of the certificate is taken into account.
        Nothing -> do
          lift $ lift $ traceWith tracer $ PerasCertBoostsBlockNotYetReceived certRound boostedBlock
          idExitEarly $ addedCertRes
        Just boostedHdr -> pure boostedHdr

    -- Trigger chain selection for the boosted block.
    lift $ lift $ traceWith tracer $ ChainSelectionForBoostedBlock certRound boostedBlock
    lift $ chainSelectionForBlock cdb BlockCache.empty boostedHdr noPunishment
    pure $ addedCertRes
