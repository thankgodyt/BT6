### Title
Peras Certificate Validation Unconditionally Accepts All Inbound Certificates, Enabling Chain-Selection Manipulation by Any Unprivileged Peer - (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Block/SupportsPeras.hs`)

---

### Summary

The `validatePerasCert` function in the production `BlockSupportsPeras` instance performs no cryptographic or semantic validation whatsoever — it unconditionally returns `Right` for every certificate it receives. This function is the sole validation gate called by `makePerasCertPoolWriterFromChainDB` when processing inbound Peras certificates over the live `PerasCertDiffusion` miniprotocol. Any unprivileged peer can craft a `PerasCert` pointing to an arbitrary block and have it accepted, boosted, and applied to chain selection without any proof of quorum, signature, or round validity.

---

### Finding Description

The `BlockSupportsPeras` typeclass defines `validatePerasCert` as the mandatory validation step before a certificate is stored and its boost weight applied to chain selection. The production instance (the only compiled instance, covering all `StandardHash blk`) is:

```haskell
-- TODO: perform actual validation against all
-- possible 'PerasValidationErr' variants
-- see https://github.com/tweag/cardano-peras/issues/120
validatePerasCert params cert =
  Right
    ValidatedPerasCert
      { vpcCert = cert
      , vpcCertBoost = perasWeight params
      }
``` [1](#0-0) 

This function never inspects the certificate's content. It carries no BLS aggregate signature check, no quorum-membership proof, no round-number bounds check, and no boosted-block existence check. The `PerasCert blk` data type in this instance contains only `pcCertRound` and `pcCertBoostedBlock` — no signature field at all:

```haskell
data PerasCert blk = PerasCert
  { pcCertRound :: PerasRoundNo
  , pcCertBoostedBlock :: Point blk
  }
``` [2](#0-1) 

This `validatePerasCert` is called directly in the production inbound certificate handler `makePerasCertPoolWriterFromChainDB`:

```haskell
makePerasCertPoolWriterFromChainDB systemTime chainDB =
  ObjectPoolWriter
    { opwAddObjects = \certs ->
        processCerts
          systemTime
          (ChainDB.getPerasCertIds chainDB)
          -- TODO replace when actual plumbing is in place
          (validatePerasCert mkPerasParams)
          (void . ChainDB.addPerasCertAsync chainDB)
          certs
    ...
    }
``` [3](#0-2) 

`processCerts` filters only for round numbers already in the DB, then calls `validateCert` on the remainder. Since `validatePerasCert` always returns `Right`, every new-round certificate passes: [4](#0-3) 

This pool writer is wired directly into the live `hPerasCertDiffusionClient` handler in `NodeToNode.hs`:

```haskell
hPerasCertDiffusionClient = \version controlMessageSTM peer ->
    objectDiffusionInbound
      ...
      (makePerasCertPoolWriterFromChainDB systemTime getChainDB)
      version
      controlMessageSTM
``` [5](#0-4) 

The accepted certificate is then stored in `PerasCertDB` and its boost weight is applied to the boosted block in chain selection via `getPerasWeightSnapshot`. The `implAddCert` function in `PerasCertDB.Impl` performs no additional validation — it only deduplicates by round number: [6](#0-5) 

The contrast with the intended V1 design is stark. The concrete `Peras.Cert.V1.PerasCert` type carries a `pcSignature :: AggregateVoteSignature PerasBLSCrypto` field and a `pcVoters :: PerasCertVoters` bitmap — none of which exist in the active degenerate instance: [7](#0-6)

### Impact Explanation

A forged certificate accepted by the node is stored in `PerasCertDB` and its boost weight (`perasWeight params`) is applied to the attacker-specified `pcCertBoostedBlock` in the `PerasWeightSnapshot`. Chain selection uses this snapshot to prefer chains containing the boosted block. An attacker who injects a certificate pointing to a block on a minority or adversarial fork can cause the victim node to assign extra weight to that fork, potentially making it prefer a non-canonical chain over the honest chain. This directly undermines the Peras protocol's chain-quality and common-prefix guarantees.

**Impact class**: High — chain selection bug that lets an unprivileged peer make an honest node prefer a non-canonical or less-secure chain beyond the intended security assumptions.

---

### Likelihood Explanation

The `PerasCertDiffusion` miniprotocol is compiled into the production node and wired up in `NodeToNode.hs`. Any peer that establishes a node-to-node connection can send crafted `PerasCert` messages. No keys, stake, or privileged access are required. The attack requires only knowledge of a target block's `Point` (slot + hash), which is public information. The deduplication check (one cert per round number) means an attacker must use a fresh round number per injection, but `PerasRoundNo` is a `Word64` — effectively unlimited.

---

### Recommendation

1. **Immediate**: Gate the `PerasCertDiffusion` miniprotocol behind a feature flag that is disabled until the full `validatePerasCert` implementation (with BLS aggregate signature verification, quorum-membership proof, and round-validity checks) is in place.
2. **Short-term**: Replace the degenerate `validatePerasCert` stub with a function that returns `Left PerasValidationErr` (reject all) rather than `Right` (accept all), so that the fail-safe direction is rejection, not acceptance.
3. **Long-term**: Implement the full validation using the V1 certificate type (`Peras.Cert.V1.PerasCert`) which carries `pcSignature` and `pcVoters`, verifying the BLS aggregate signature against the committee's public keys and confirming quorum is met.

---

### Proof of Concept

```
Attacker (unprivileged peer) connects to victim node via PerasCertDiffusion miniprotocol.

1. Attacker observes a block B_adv on a minority fork (slot S, hash H).
2. Attacker crafts:
     PerasCert { pcCertRound = R_fresh   -- any round not yet in victim's DB
               , pcCertBoostedBlock = Point (SlotNo S) (BlockHash H)
               }
3. Attacker sends this cert via the ObjectDiffusion protocol.
4. Victim's hPerasCertDiffusionClient receives it.
5. processCerts filters: R_fresh not in DB → proceeds to validatePerasCert.
6. validatePerasCert returns Right (unconditionally).
7. cert is timestamped and passed to ChainDB.addPerasCertAsync.
8. implAddCert stores it; PerasWeightSnapshot now assigns boost weight to B_adv.
9. Chain selection now treats any chain containing B_adv as heavier by perasWeight.
10. If the boosted weight tips the balance, victim switches to the adversarial fork.
```

The entry path is:
`hPerasCertDiffusionClient` → `objectDiffusionInbound` → `makePerasCertPoolWriterFromChainDB` → `processCerts` → `validatePerasCert` (always `Right`) → `ChainDB.addPerasCertAsync` → `PerasCertDB.implAddCert` → `PerasWeightSnapshot` → chain selection. [5](#0-4) [8](#0-7) [1](#0-0)

processCerts systemTime alreadyInDbSTM validateCert addCert certs = do
  alreadyInDb <- atomically alreadyInDbSTM
  let certsNotAlreadyInDb = filter (not . (`Set.member` alreadyInDb) . getPerasCertRound) certs
  now <- systemTimeCurrent systemTime
  case partitionEithers (validateCert <$> certsNotAlreadyInDb) of
    -- All certs are valid => add them to the pool
    ([], validatedCerts) ->
      mapM_
        (addCert . WithArrivalTime now)
        validatedCerts

  let roundNo = getPerasCertRound cert
  addPerasCertRes <- do
    WithFingerprint pcds fp <- readTVar pcdbState
    if Set.member roundNo (pcdsCertIds pcds)
      then pure PerasCertAlreadyInDB
      else do
        let pcdsLastTicketNo' = succ (pcdsLastTicketNo pcds)
            pcdsCertIds' = Set.insert roundNo (pcdsCertIds pcds)
            pcdsCertsByTicket' = Map.insert pcdsLastTicketNo' cert (pcdsCertsByTicket pcds)
            pcdsLatestCertSeen' = case pcdsLatestCertSeen pcds of
              Nothing -> Just cert
              Just prev
                | getPerasCertRound cert > getPerasCertRound prev -> Just cert
                | otherwise -> Just prev
        writeTVar pcdbState $
          WithFingerprint
            PerasCertDbState
              { pcdsCertIds = pcdsCertIds'
              , pcdsCertsByTicket = pcdsCertsByTicket'
              , pcdsLastTicketNo = pcdsLastTicketNo'
              , pcdsLatestCertSeen = pcdsLatestCertSeen'
              }
            (succ fp)
        pure AddedPerasCertToDB
  pure $ do
    traceWith pcdbTracer (AddCert roundNo cert addPerasCertRes)
