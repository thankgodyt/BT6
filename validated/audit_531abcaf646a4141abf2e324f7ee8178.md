### Title
Hardcoded Taylor-Series Error Bound in `localSortitionNumSeats` Causes Incorrect Peras Non-Persistent Seat Allocation - (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/LS.hs`)

---

### Summary

`localSortitionNumSeats` in `LS.hs` uses `taylorExpCmpFirstNonLower` with a hardcoded `boundX = 3` to determine how many non-persistent Peras voting seats a committee member is entitled to. The function's own contract requires `boundX = e^{|x|} = e^lambda` for correct error bounds. When `lambda > ln(3) ≈ 1.099` — a realistic condition for any non-persistent voter holding more than roughly 11% of the non-persistent stake pool with 10 non-persistent seats — the error term is underestimated, and the Taylor-series comparison can produce an incorrect seat count. The code itself acknowledges this with an open TODO. Because `implVerifyVote` and `implVerifyCert` recompute `numSeats` from the network-supplied VRF output using the same broken arithmetic, a non-persistent voter whose true seat count should be zero can have their vote or certificate accepted with a non-zero seat count, granting unauthorized voting power.

---

### Finding Description

`localSortitionNumSeats` computes the number of non-persistent seats for a voter by evaluating a Poisson CDF comparison via a Taylor-series approximation:

```haskell
expectedSeats :: Int
expectedSeats =
  fromMaybe 0 $
    taylorExpCmpFirstNonLower
      3          -- <-- hardcoded boundX
      orders
      (-lambda)
``` [1](#0-0) 

The internal contract of `taylorExpCmpFirstNonLower` is explicit:

```
-- IMPORTANT: boundX must be e^{|x|} for correct error bounds (see taylorExpCmp).
``` [2](#0-1) 

Here `x = -lambda`, so the correct value is `boundX = e^lambda`. The hardcoded `3` is only valid when `lambda ≤ ln(3) ≈ 1.099`.

`lambda` is computed as:

```haskell
lambda =
  fromRational $
    fromIntegral numNonPersistentVoters
      * voterStake
      / totalNonPersistentStake
``` [3](#0-2) 

For a voter holding 20% of the non-persistent stake with 10 non-persistent seats, `lambda = 2.0 > 1.099`. For 50% stake with 10 seats, `lambda = 5.0`. In both cases `e^lambda >> 3`.

The `decideOne` inner function uses `errorTerm = abs (err' * boundX)` to decide whether the Taylor partial sum has converged:

```haskell
| cmp >= acc' + errorTerm = Stop   -- classified ABOVE → grants seat
| cmp < acc' - errorTerm = Below   -- classified BELOW → denies seat
``` [4](#0-3) 

When `boundX` is too small, `errorTerm` is underestimated, narrowing the uncertainty band. A threshold value that is genuinely uncertain (neither provably above nor below `e^{-lambda}`) can be prematurely classified as `Stop` (ABOVE), granting a seat that should not be granted.

The code itself acknowledges the problem with an open TODO:

```
-- TODO(peras): evaluate whether the limit used below (3) makes sense in
-- this context.
-- Tracked by this issue:
-- https://github.com/tweag/cardano-peras/issues/234
``` [5](#0-4)

### Impact Explanation

`localSortitionNumSeats` is called in three production paths in `WFALS.hs`:

1. `implCheckShouldVote` — the voter's own eligibility check
2. `implVerifyVote` — verifying a received non-persistent vote
3. `implVerifyCert` — verifying a received certificate [6](#0-5) [7](#0-6) 

In `implVerifyVote` and `implVerifyCert`, the verifier recomputes `numSeats` from the VRF output embedded in the received message. If the broken arithmetic yields `numSeats > 0` when the correct answer is `0`, the vote or certificate passes the `nonZero numSeats` guard and is accepted. The resulting `WFALSNonPersistentMember` witness carries the inflated seat count, which is then used to compute `VoteWeight`:

```haskell
VoteWeight $
  fromIntegral (unLocalSortitionNumSeats (unNonZero numSeats))
    * stake
    / nonPersistentStake
``` [8](#0-7) 

An unauthorized vote or certificate accepted with inflated weight directly weakens the Peras quorum threshold, potentially allowing a minority-stake adversary to forge a certificate for a block that should not be boosted.

---

### Likelihood Explanation

The condition `lambda > 1.099` is met whenever a non-persistent voter holds more than `ln(3) / numNonPersistentVoters` of the total non-persistent stake. With a committee of 10 non-persistent seats, any voter with more than ~11% of the non-persistent stake triggers the bug. This is a normal operating condition for a moderately concentrated stake distribution. No special privileges, key compromise, or social engineering are required — the attacker only needs to be a registered stake pool that falls into the non-persistent committee range.

---

### Recommendation

Replace the hardcoded `3` with the correct value `e^lambda`, computed before calling `taylorExpCmpFirstNonLower`:

```haskell
-- boundX must be e^{lambda} for correct error bounds
let boundX = exp (realToFrac lambda :: Double)
expectedSeats =
  fromMaybe 0 $
    taylorExpCmpFirstNonLower
      (realToFrac boundX)
      orders
      (-lambda)
```

Alternatively, use the exact `FixedPoint` exponentiation already available in `cardano-ledger`'s `NonIntegral` module. Document and test the expected rounding direction for each arithmetic step in `localSortitionNumSeats`, and add property-based fuzz tests that verify seat counts are monotone in VRF output and stake, analogous to the invariant tests recommended in the external report.

### Proof of Concept

Consider:
- `numNonPersistentVoters = 10`
- `voterStake = 2`, `totalNonPersistentStake = 10`
- `lambda = 10 * 2 / 10 = 2.0`
- Correct `boundX = e^2 ≈ 7.389`; used `boundX = 3`

For `orders[0] = normalizedVRFOutput / 2.0`, suppose the voter's VRF output normalizes to `0.14` (just below `e^{-2} ≈ 0.135`). The correct answer is 0 seats. With `boundX = 3`, the error term at the first Taylor step is `|err' * 3|` instead of `|err' * 7.389|`. The narrower band causes the comparison to prematurely return `Stop` (ABOVE), granting 1 seat. The vote is accepted by `implVerifyVote` because `nonZero (LocalSortitionNumSeats 1)` succeeds, and the voter receives `VoteWeight = 1 * 2 / 10 = 0.2` of the non-persistent stake — unauthorized voting power.
