### Title
Missing Quorum-Stake Check in `implVerifyCert` Allows Sub-Quorum Certificate Acceptance — (`File: ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/EveryoneVotes.hs` and `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/WFALS.hs`)

### Summary

Both `EveryoneVotes.implVerifyCert` and `WFALS.implVerifyCert` verify cryptographic membership and aggregate signatures for a Peras certificate, but neither checks that the total stake represented by the voters meets the quorum threshold. The quorum-stake check (`stakeAboveThreshold`) exists only in the local vote-aggregation path (`Aggregation.hs`) and is absent from the certificate-verification path. An attacker who controls any pool with positive stake (under `EveryoneVotes`) or holds a committee seat (under `WFALS`) can craft a cryptographically valid certificate backed by sub-quorum stake and present it to a node; `verifyCert` will return `Right` and the certificate will be treated as valid.

### Finding Description

`implVerifyCert` for `EveryoneVotes` (lines 301–340) traverses the voter set, confirms each seat index is within bounds and has non-zero stake, then calls `verifyAggregateVoteSignature`. It returns `Right members` on success. [1](#0-0) 

`implVerifyCert` for `WFALS` (lines 494–586) additionally verifies VRF outputs for non-persistent voters, but likewise returns `Right members` without any quorum check. [2](#0-1) 

The quorum check, `stakeAboveThreshold`, compares total vote stake against `perasQuorumStakeThreshold + perasQuorumStakeThresholdSafetyMargin`: [3](#0-2) 

This function is called only inside `votesReachQuorum` (the local forging path) and the `PerasVoteDB` test model — never inside `verifyCert`: [4](#0-3) 

The `CryptoSupportsVotingCommittee` class exposes `verifyCert` as the sole certificate-verification entry point: [5](#0-4) 

Because `verifyCert` returns `NE [EligibilityWitness]` without a quorum verdict, any caller that trusts the `Right` result without independently summing stake and calling `stakeAboveThreshold` will accept a sub-quorum certificate as fully valid.

### Impact Explanation

A Peras certificate that passes `verifyCert` is used to boost a block's chain-selection weight by `perasWeight`. If a sub-quorum certificate is accepted, an attacker can unilaterally boost an arbitrary block — including one on a minority fork — causing honest nodes to prefer that fork over the canonical chain. This is a **High** chain-selection / Peras voting-check bypass: an unprivileged peer with any positive stake (under `EveryoneVotes`) can make an honest node prefer a non-canonical chain, violating the Peras security assumption that only a quorum of honest stake can produce a valid certificate.

### Likelihood Explanation

Under `EveryoneVotes`, every pool with positive stake is a committee member. Any such pool can forge a single-voter certificate (valid aggregate signature over one seat) and broadcast it. The certificate will pass `implVerifyCert` because the signature is genuine and the seat is in-bounds. The only barrier is whether the caller independently checks quorum; the codebase shows no such check in the verification path, making exploitation straightforward for any registered stake-pool operator.

### Recommendation

Move the quorum check inside `implVerifyCert` (or a shared `verifyCert` wrapper in `Committee/Class.hs`). After collecting `members`, compute total stake from the returned `EligibilityWitness` list using `eligiblePartyVoteWeight`, sum it, and reject the certificate with a new `InsufficientQuorum` error variant if the total falls below the threshold. This mirrors the existing `votesReachQuorum` logic and ensures no caller can accidentally skip the check.

### Proof of Concept

1. Operate a stake pool with any positive stake under an `EveryoneVotes` committee.
2. Obtain your seat index from `candidateSeats`.
3. Call `forgeVote` with your eligibility witness to produce a single `EveryoneVotesVote`.
4. Call `forgeCert` on that single-vote `UniqueVotesWithSameTarget` — this succeeds because `forgeCert` also does not check quorum, only that voter seats are unique.
5. Transmit the resulting `EveryoneVotesCert` (one voter, sub-quorum stake, valid aggregate signature) to a peer node.
6. The peer calls `implVerifyCert`: seat is in-bounds, stake is non-zero, aggregate signature verifies → returns `Right [EveryoneVotesMember seatIndex stake]`.
7. The certificate is accepted and the targeted block receives a `perasWeight` boost, influencing chain selection without a quorum of honest stake.

    -- Traverse the list of voters in ascending seat index order, collecting:
    -- 1. their membership status
    -- 2. their vote verification keys (to verify the aggregate vote signature)
    (members, voteVerificationKeys) <-
      fmap munzip . flip traverse (NESet.toAscList voters) $ \case
        seatIndex
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee) -> do
              let voterVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              case nonZero voterStake of
                Nothing ->
                  Left (PoolHasNoStake seatIndex)
                Just nonZeroVoterStake ->
                  pure
                    ( EveryoneVotesMember
                        seatIndex
                        nonZeroVoterStake
                    , voterVerificationKey
                    )
          | otherwise ->
              Left (MissingSeatIndex seatIndex)

      bimap CryptoError id $ do
        aggregateVoteVerificationKeys
          (Proxy @crypto)

        (Proxy @crypto)

        candidate

implVerifyCert committee = \case
  WFALSCert electionId candidate voters aggSig -> do
    -- Traverse the list of voters in ascending seat index order, collecting:
    -- 1. their membership status
    -- 2. their vote verification keys (to verify the aggregate vote signature)
    -- 3. optionally, their VRF verification keys and outputs (to verify the
    --    aggregate VRF output for non-persistent voters, if any)
    (members, voteVerificationKeys, optionalVRFKeysAndOutputs) <-
      fmap nonEmptyUnzip3 . flip traverse (NEMap.toAscList voters) $ \case
        -- Persistent voter
        (seatIndex, Nothing)
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
          , isPersistentMember seatIndex committee -> do
              let voterVoteVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              pure
                ( WFALSPersistentMember
                    seatIndex
                    voterStake
                , voterVoteVerificationKey
                , Nothing
                )
          | otherwise ->
              Left (NotAPersistentMember seatIndex)
        -- Non-persistent voter
        (seatIndex, Just vrfOutput)
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
          , not (isPersistentMember seatIndex committee) -> do
              let voterVoteVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              let voterVRFVerificationKey =
                    getVRFVerificationKey (Proxy @crypto) voterPublicKey
              let numSeats =
                    localSortitionNumSeats
                      (nonPersistentCommitteeSize committee)
                      (totalNonPersistentStake committee)
                      voterStake
                      (normalizeVRFOutput vrfOutput)
              case nonZero numSeats of
                Nothing ->
                  Left (ZeroNonPersistentSeats seatIndex)
                Just nonZeroNumSeats ->
                  pure
                    ( WFALSNonPersistentMember
                        seatIndex
                        voterStake
                        vrfOutput
                        nonZeroNumSeats
                    , voterVoteVerificationKey
                    , Just (voterVRFVerificationKey, vrfOutput)
                    )
          | otherwise ->
              Left (NotANonPersistentMember seatIndex)

    -- Verify aggregate signature
    aggVerificationKey <-
      bimap CryptoError id $
        aggregateVoteVerificationKeys
          (Proxy @crypto)
          voteVerificationKeys
    bimap InvalidCertSignature id $
      verifyAggregateVoteSignature
        (Proxy @crypto)
        aggVerificationKey
        electionId
        candidate
        aggSig

    -- Verify VRF outputs for non-persistent voters (if any)
    case catMaybes (NonEmpty.toList optionalVRFKeysAndOutputs) of
      -- No non-persistent voters => no VRF outputs to verify
      [] -> do
        pure ()
      -- Some non-persistent voters => verify their aggregate VRF outputs
      vrfKeysAndOutputs -> do
        let (vrfVerificationKeys, vrfOutputs) =
              munzip
                . NonEmpty.fromList -- safe 'vrfKeysAndOutputs' /= []
                $ vrfKeysAndOutputs
        bimap InvalidCertSignature id $
          batchVerifyVRFOutputs
            vrfVerificationKeys
            ( mkVRFElectionInput
                @crypto
                (epochNonce committee)
                electionId
            )
            vrfOutputs

    -- Return the list of voters attesting the election winner
    pure members
