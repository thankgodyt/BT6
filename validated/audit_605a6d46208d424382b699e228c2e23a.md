### Title
Missing Post-Condition Invariant Check in `taylorExpCmpFirstNonLower` Enables Unauthorized Peras Committee Seat Grants — (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/LS.hs`)

---

### Summary

`localSortitionNumSeats` uses `taylorExpCmpFirstNonLower` with a hardcoded `boundX = 3` to determine how many non-persistent Peras committee seats a voter receives. The contract for `boundX` requires it to equal `e^{|x|}`, but `x = -lambda` (the expected seat count), so the correct value is `e^{lambda}`. For any voter whose `lambda > ln(3) ≈ 1.099`, the error bound is systematically underestimated. Additionally, when the 1000-iteration cap is hit, the function returns `Stop` (grants a seat) with no post-condition check that the voter actually deserves it. Both the voter-side (`implCheckShouldVote`) and the verifier-side (`implVerifyVote`) call the same function with the same incorrect `boundX`, so the verifier accepts whatever seat count the approximation produces — including inflated counts. This is the direct analog of the external report: an iterative approximation that can terminate early or with incorrect error bounds, producing a result that violates the required invariant, with no assertion to catch it.

---

### Finding Description

**Root cause — incorrect `boundX` in `taylorExpCmpFirstNonLower`:**

`taylorExpCmpFirstNonLower` approximates `e^x` via a Taylor series and uses `boundX` as an upper bound on `e^{|x|}` to compute the error term:

```
errorTerm = abs(err' * boundX)
``` [1](#0-0) 

The convergence decision is:

- `cmp >= acc' + errorTerm` → `Stop` (grant seat, proven ABOVE)
- `cmp < acc' - errorTerm` → `Below` (deny seat, proven BELOW)
- otherwise → iterate

When `boundX` is too small, `errorTerm` is too small, narrowing the uncertainty interval `[acc' - errorTerm, acc' + errorTerm]`. This causes the function to reach a premature decision: a threshold that is actually inside the true uncertainty interval can be misclassified as "proven BELOW" (voter gets more seats than deserved) or "proven ABOVE" (voter gets fewer). The false-positive direction — granting extra seats — is the security-relevant case.

The call site hardcodes `boundX = 3`:

```haskell
expectedSeats =
  fromMaybe 0 $
    taylorExpCmpFirstNonLower
      3          -- boundX, supposed to be e^{lambda}
      orders
      (-lambda)
``` [2](#0-1) 

The code comment explicitly acknowledges this is unverified:

> `-- TODO(peras): evaluate whether the limit used below (3) makes sense in this context.` [3](#0-2) 

The value `3` was copied from `checkLeaderNatValue` (Praos slot leadership), where `x = sigma * ln(1-f)` and `|x| ≤ 0.05` for typical parameters, making `e^{|x|} ≈ 1.05 << 3` — so `3` is safe there. For the Peras committee, `x = -lambda` where `lambda = numNonPersistentVoters * voterStake / totalNonPersistentStake`. For a voter with 10% of non-persistent stake and 11 expected non-persistent voters, `lambda = 1.1 > ln(3) ≈ 1.099`, and `e^{1.1} ≈ 3.004 > 3`. For a voter with 20% stake and 11 expected voters, `lambda = 2.2` and `e^{2.2} ≈ 9.025 >> 3`. The error bound is underestimated by a factor of 3× to 9×+ for realistic high-stake voters.

**Root cause — max-iterations fallback grants a seat unconditionally:**

When the 1000-iteration cap is reached, `decideOne` returns `Stop` — the same result as "proven ABOVE" — without any post-condition check:

```haskell
decideOne maxN n err acc divisor cmp
  | maxN == n = Stop          -- iteration cap: grant seat, no invariant check
  | cmp >= acc' + errorTerm = Stop   -- proven ABOVE: grant seat
  | cmp < acc' - errorTerm = Below …
  | otherwise = decideOne …
``` [4](#0-3) 

There is no assertion that the partial sum has actually converged past the threshold. This is the exact structural analog of the external report's missing `assert!(old_inv < new_inv)`.

**Both voter and verifier use the same flawed function:**

`implCheckShouldVote` (voter side) calls `localSortitionNumSeats`: [5](#0-4) 

`implVerifyVote` (verifier side) calls the identical `localSortitionNumSeats` with the same inputs: [6](#0-5) 

Because both sides share the same incorrect approximation, the verifier accepts whatever seat count the flawed function produces — including inflated counts for high-`lambda` voters. There is no independent ground-truth check.

---

### Impact Explanation

A non-persistent Peras committee member with `lambda > ln(3)` — achievable by any pool holding more than roughly `ln(3) / numNonPersistentVoters` of the non-persistent stake — may receive a `LocalSortitionNumSeats` value that is higher than the mathematically correct Poisson-CDF result. The verifier in `implVerifyVote` recomputes the same inflated count and accepts the vote. The `implEligiblePartyVoteWeight` function then scales the voter's weight by `numSeats`, so extra seats translate directly into extra voting power: [7](#0-6) 

This is a bypass of the Peras voting committee eligibility check: an unprivileged pool with sufficient stake can cast votes with inflated weight, potentially reaching the quorum threshold with fewer honest participants than the protocol requires, enabling unauthorized Peras certificate issuance.

---

### Likelihood Explanation

The threshold `lambda > ln(3) ≈ 1.099` is crossed whenever a pool's share of non-persistent stake exceeds `1.099 / numNonPersistentVoters`. With a committee of 11 non-persistent voters, any pool holding more than ~10% of non-persistent stake triggers the bug. This is a realistic stake concentration for a production Cardano stake pool. The attacker needs no special access — only a pool registered in the stake distribution.

---

### Recommendation

1. Replace the hardcoded `boundX = 3` with the mathematically correct value `e^{lambda}` (computed from the actual `lambda` at the call site), matching the documented contract of `taylorExpCmpFirstNonLower`.
2. Add a post-condition assertion after `taylorExpCmpFirstNonLower` returns that the granted seat count is consistent with the Poisson CDF evaluated at the voter's normalized VRF output — analogous to the remediation in the external report (`assert!(invariant_after >= invariant)`).
3. Resolve the open TODO at line 86–92 of `Committee/LS.hs` before the WFALS committee scheme is used in production.

---

### Proof of Concept

Consider a pool with:
- `numNonPersistentVoters = 11`
- `voterStake / totalNonPersistentStake = 0.20` (20% of non-persistent stake)
- `lambda = 11 * 0.20 = 2.2`
- Correct `boundX` = `e^{2.2} ≈ 9.025`; actual `boundX` = `3`

The error term is underestimated by factor `9.025 / 3 ≈ 3.0`. For a `normalizedVRFOutput` value that places the voter near the boundary between 1 and 2 seats, the narrow `[acc' - errorTerm, acc' + errorTerm]` interval causes `decideOne` to classify a threshold as "proven BELOW" when the true interval would classify it as uncertain. The function returns `Just 2` (2 seats) where the correct answer is `Just 1` (1 seat). `implVerifyVote` recomputes the same `Just 2` and accepts the vote with double the intended weight. No assertion in either path detects the invariant violation. [8](#0-7) [9](#0-8)

taylorExpCmpFirstNonLower ::
  forall a.
  RealFrac a =>
  -- | boundX = e^{|x|} for correct error estimation
  a ->
  -- | list of cmp thresholds (checked in order)
  [a] ->
  -- | x in e^x
  a ->
  Maybe Int
taylorExpCmpFirstNonLower boundX cmps x =
  goList 1000 0 x 1 1 0 cmps
 where
  -- Traverse the list of cmps, advancing the Taylor state as needed while
  -- checking if the current cmp is ABOVE or BELOW. If ABOVE, return the index.
  goList ::
    Int -> -- maxN
    Int -> -- n
    a -> -- err
    a -> -- acc
    a -> -- divisor
    Int -> -- current index
    [a] -> -- remaining cmps
    Maybe Int
  goList _ _ _ _ _ _ [] = Nothing
  goList maxN n err acc divisor i (cmp : rest) =
    case decideOne maxN n err acc divisor cmp of
      Stop ->
        Just i
      Below n' err' acc' divisor' ->
        goList maxN n' err' acc' divisor' (i + 1) rest

  -- Decide current cmp by advancing the shared Taylor state as needed.
  -- If BELOW is established, returns the *advanced* state to continue with.
  -- If ABOVE is established or maxN reached, returns Stop.
  decideOne ::
    Int -> -- maxN
    Int -> -- n
    a -> -- err
    a -> -- acc
    a -> -- divisor
    a -> -- cmp
    Step a
  decideOne maxN n err acc divisor cmp
    | maxN == n = Stop
    | cmp >= acc' + errorTerm = Stop
    | cmp < acc' - errorTerm = Below (n + 1) err' acc' divisor'
    | otherwise = decideOne maxN (n + 1) err' acc' divisor' cmp
   where
    divisor' = divisor + 1
    nextX = err
    acc' = acc + nextX
    err' = (err * x) / divisor'
    errorTerm = abs (err' * boundX)
