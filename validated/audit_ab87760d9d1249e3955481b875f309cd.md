### Title
Unauthenticated `request_refund` Allows Any Caller to Redirect BTC Refund to Attacker-Controlled Address - (File: contracts/satoshi-bridge/src/api/bridge.rs)

### Summary
`request_refund` in `satoshi-bridge` carries no ownership check: any NEAR account can supply the correct `deposit_msg` (publicly available from on-chain events) together with an attacker-controlled `refund_address`. After the `unsafe_refund_timelock_sec` elapses, the same attacker calls `execute_refund` and the bridge MPC-signs a Bitcoin transaction that pays the user's deposited BTC to the attacker's address.

### Finding Description

`request_refund` is publicly callable — it has no `#[trusted_relayer]` attribute on the function itself, only on the surrounding `impl` block, which (as confirmed by the pattern of `get_user_deposit_address` and `get_change_address` in the same block being freely callable) does not propagate the guard to every method. [1](#0-0) 

The only guard on the `refund_address` parameter is:

```rust
if let Some(msg_refund_address) = &deposit_msg.refund_address {
    require!(
        msg_refund_address == &refund_address,
        "refund_address does not match deposit_msg.refund_address"
    );
}
```

```rust
    #[allow(clippy::too_many_arguments)]
    #[payable]
    #[pause(except(roles(Role::DAO)))]
    pub fn request_refund(
        &mut self,
        deposit_msg: DepositMsg,
        refund_address: String,
        tx_bytes: Base64VecU8,
        vout: usize,
        proof: TxInclusionProof,
        gas_fee: Option<U128>,
    ) -> Promise {
        if gas_fee.is_some() {
            let caller = env::predecessor_account_id();
            require!(
                self.acl_has_role(Role::DAO.into(), caller.clone())
                    || self.acl_has_role(Role::Operator.into(), caller),
                "Only DAO or Operator can specify custom gas_fee"
            );
        }
        self.internal_request_refund(
            deposit_msg,
            refund_address,
            tx_bytes,
            vout,
            proof,
            gas_fee.map(|v| v.0),
        )
    }
```
