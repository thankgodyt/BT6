### Title
Unbounded `PerasWeightSnapshot` Inflation via Stub Certificate Validation Enables Chain Selection Manipulation — (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Block/SupportsPeras.hs`)

---

### Summary

The production `BlockSupportsPeras` instance contains a stub `validatePerasCert` that unconditionally accepts every inbound Peras certificate. Because `addToPerasWeightSnapshot` accumulates weight per block-point without any cap, an unprivileged peer can send an arbitrary number of crafted certificates (each for a distinct round number, bypassing the per-round deduplication gate) to inflate the `PerasWeightSnapshot` for any block. The inflated snapshot is then consumed by `wsvTotalWeight` and `preferAnchoredCandidate` during chain selection, allowing the attacker's shorter fork to appear heavier than the honest chain and causing the node to switch to it.

---

### Finding Description

**Root cause — stub validation (`SupportsPeras.hs` lines 350–358)**

```haskell
-- TODO: perform actual validation against all
-- possible 'PerasValidationErr' variants
-- see https://github.com/tweag/cardano-peras/issues/120
validatePerasCert params cert =
  Right
    ValidatedPerasCert
      { vpcCert = cert
      , vpcCertBoost = perasWeight params
      }
```

This is the only `BlockSupportsPeras` instance in the codebase (the catch-all `instance StandardHash blk => BlockSupportsPeras blk`). It returns `Right` for every certificate regardless of round validity, committee membership, BLS signature, or any other check.

**Inbound path — `processCerts` (`PerasCert.hs` lines 156–185)**

```haskell
processCerts systemTime alreadyInDbSTM validateCert addCert certs = do
  alreadyInDb <- atomically alreadyInDbSTM
```

The only deduplication is by `PerasRoundNo`. An attacker who sends one certificate per distinct round number will have every certificate accepted and stored.

**Weight accumulation — `addToPerasWeightSnapshot` (`Weight.hs` lines 125–132)**

```haskell
addToPerasWeightSnapshot pt weight =
  PerasWeightSnapshot . Map.insertWith (<>) pt weight . getPerasWeightSnapshot
```

`PerasWeight` is `newtype PerasWeight = PerasWeight { unPerasWeight :: Word64 }` with `deriving via Sum Word64 instance Semigroup PerasWeight`. Each accepted certificate adds `perasWeight params` (e.g. 15) to the target block's entry in the map, with no upper bound.

**Chain selection — `wsvTotalWeight` and `preferAnchoredCandidate`**

```haskell
-- SelectView.hs lines 58–61
wsvTotalWeight wsv =
  PerasWeight (unBlockNo (wsvBlockNo wsv)) <> wsvWeightBoost wsv

-- preferCandidate (SelectView.hs lines 81–87)
preferCandidate cfg ours cand =
  case compare (wsvTotalWeight ours) (wsvTotalWeight cand) of
    LT -> ShouldSwitch ...
    ...
```

`preferAnchoredCandidate` (`AnchoredFragment.hs` lines 204–213) takes the non-empty Peras path whenever `isEmptyPerasWeightSnapshot weights` is `False`. Once the attacker has injected even one certificate, the snapshot is non-empty and all subsequent chain comparisons use `wsvTotalWeight`.

**`addPerasCertAsync` triggers chain selection** (`ChainDB.API` line 441–443):

> "If this leads to a fork to be weightier than our current selection, this will trigger a fork switch."

---

### Impact Explanation

An attacker whose fork is one block shorter than the honest chain (block number N−1 vs N) needs to boost their fork's tip by only `(N − (N−1)) / perasWeight + 1 = 2` weight units — achievable with a **single** crafted certificate (contributing `perasWeight = 15` by default). After the certificate is accepted, the attacker's fork has total weight `(N−1) + 15 = N+14 > N`, and `preferAnchoredCandidate` returns `ShouldSwitch`, causing the honest node to roll back to the attacker's chain. This satisfies the allowed impact: **"Chain selection bug that lets an unprivileged peer make an honest node prefer a non-canonical or less-secure chain beyond the intended security assumptions."**

---

### Likelihood Explanation

- The entry point is the public Peras certificate diffusion mini-protocol; no privileged access is required.
- The stub validation is the only production implementation; it is unconditionally reachable.
- A single crafted certificate is sufficient to trigger a fork switch against a one-block-shorter adversarial chain.
- The per-round deduplication does not limit the total number of distinct rounds an attacker can fabricate.

---

### Recommendation

1. **Implement real certificate validation** in `validatePerasCert`: verify committee membership, BLS aggregate signature, round number bounds (not in the future, not older than `PerasCertMaxRounds`), and that the boosted block is on a known chain.
2. **Cap accumulated weight per block-point** in `addToPerasWeightSnapshot` to at most one certificate's worth of boost per round, preventing unbounded accumulation even if multiple certificates for the same block arrive.
3. **Validate round number range** in `processCerts` before calling `validateCert`, rejecting certificates whose round number is implausibly far in the future.

---

### Proof of Concept

```
Honest chain:  ... → B_{N-1} → B_N          (total weight = N)
Attacker fork: ... → B_{N-1} → B'_{N-1}     (total weight = N-1, one block shorter)

Step 1: Attacker crafts PerasCert { pcCertRound = R_new, pcCertBoostedBlock = B'_{N-1} }
Step 2: Cert is sent to the target node via the Peras cert diffusion protocol.
Step 3: processCerts calls validatePerasCert → returns Right (stub, no checks).
Step 4: addPerasCertAsync stores the cert; addToPerasWeightSnapshot adds 15 to B'_{N-1}.
Step 5: wsvTotalWeight(attacker fork) = (N-1) + 15 = N+14 > N = wsvTotalWeight(honest chain).
Step 6: preferAnchoredCandidate returns ShouldSwitch; node rolls back to attacker's fork.
```

```haskell
  alreadyInDb <- atomically alreadyInDbSTM
  let certsNotAlreadyInDb = filter (not . (`Set.member` alreadyInDb) . getPerasCertRound) certs
  now <- systemTimeCurrent systemTime
  case partitionEithers (validateCert <$> certsNotAlreadyInDb) of
    -- All certs are valid => add them to the pool

      mapM_
        (addCert . WithArrivalTime now)
        validatedCerts
```
