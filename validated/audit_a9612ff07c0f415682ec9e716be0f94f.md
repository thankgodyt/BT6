### Title
`protocolInfoCardano` silently ignores `triggerHardForkDijkstra`, hardcoding `TriggerHardForkNotDuringThisExecution` for the Conway→Dijkstra transition - (File: `ouroboros-consensus-cardano/src/ouroboros-consensus-cardano/Ouroboros/Consensus/Cardano/Node.hs`)

---

### Summary

`protocolInfoCardano` accepts a `triggerHardForkDijkstra` field via `CardanoHardForkTriggers'` but omits it from the internal pattern match, causing `partialLedgerConfigConway` to be built with the hardcoded `TriggerHardForkNotDuringThisExecution` instead of the caller-supplied trigger. The Conway→Dijkstra hard-fork transition is therefore permanently suppressed regardless of what the operator or test harness configures, mirroring the "same value used twice" class of the reference bug.

---

### Finding Description

`CardanoHardForkTriggers'` is a pattern synonym with seven fields, one per Shelley-based era transition: [1](#0-0) 

Inside `protocolInfoCardano`, the `where`-clause destructures `CardanoHardForkTriggers'` with only **six** fields — `triggerHardForkDijkstra` is absent: [2](#0-1) 

Because `triggerHardForkDijkstra` is never bound, `partialLedgerConfigConway` cannot use it and instead hardcodes `TriggerHardForkNotDuringThisExecution`: [3](#0-2) 

Every other era follows the correct pattern — each era's partial ledger config receives the *next* era's trigger:

| Era | Trigger used |
|---|---|
| Byron | `toTriggerHardFork triggerHardForkShelley` |
| Shelley | `toTriggerHardFork triggerHardForkAllegra` |
| Allegra | `toTriggerHardFork triggerHardForkMary` |
| Mary | `toTriggerHardFork triggerHardForkAlonzo` |
| Alonzo | `toTriggerHardFork triggerHardForkBabbage` |
| Babbage | `toTriggerHardFork triggerHardForkConway` |
| **Conway** | **`TriggerHardForkNotDuringThisExecution` ← BUG** |
| Dijkstra | `TriggerHardForkNotDuringThisExecution` ← correct (last era) | [4](#0-3) 

The correct line for Conway should be:
```haskell
partialLedgerConfigConway =
  mkPartialLedgerConfigShelley
    transitionConfigConway
    (toTriggerHardFork triggerHardForkDijkstra)   -- was: TriggerHardForkNotDuringThisExecution
```

---

### Impact Explanation

`TriggerHardForkNotDuringThisExecution` instructs the HFC that the current era **cannot end during this process execution**. Placing it on Conway means the node's `singleEraTransition` for Conway will always return `Nothing`, so the HFC will never advance the chain state into the Dijkstra era, regardless of what the on-chain ledger protocol-version votes say.

When the Cardano network reaches the Conway→Dijkstra transition epoch, a node built with this code will:
1. Refuse to apply Dijkstra-era blocks (era mismatch in the HFC telescope).
2. Diverge from the canonical chain, permanently preferring a stale Conway tip.
3. Expose a split-brain: honest peers on Dijkstra and this node on Conway will never agree on the best chain.

This satisfies the **High** impact category: *Hard-fork, era transition, ledger-view, or network-version mismatch that breaks cross-era consensus or ledger invariants for production Cardano nodes.*

---

### Likelihood Explanation

The Dijkstra era and its trigger field were added to `CardanoHardForkTriggers'` but the corresponding destructuring line was not added to `protocolInfoCardano`. The omission is silent at compile time because Haskell record-pattern matches do not require all fields to be named. Any operator who sets `triggerHardForkDijkstra = CardanoTriggerHardForkAtDefaultVersion` (the standard production value) will observe no effect. The bug activates the moment the network's ledger protocol version reaches the Dijkstra threshold, which is a deterministic, unprivileged network event.

---

### Recommendation

Add `triggerHardForkDijkstra` to the pattern match and wire it into `partialLedgerConfigConway`:

```diff
  cardanoHardForkTriggers =
    CardanoHardForkTriggers'
      { triggerHardForkShelley
      , triggerHardForkAllegra
      , triggerHardForkMary
      , triggerHardForkAlonzo
      , triggerHardForkBabbage
      , triggerHardForkConway
+     , triggerHardForkDijkstra
      }

  partialLedgerConfigConway =
    mkPartialLedgerConfigShelley
      transitionConfigConway
-     TriggerHardForkNotDuringThisExecution
+     (toTriggerHardFork triggerHardForkDijkstra)
```
