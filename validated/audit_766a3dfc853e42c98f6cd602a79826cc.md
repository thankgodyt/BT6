### Title
Peras Certificate Stored in `PerasCertDB` Before Boosted-Block Existence Check Allows Blocking Legitimate Certificates - (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Storage/ChainDB/Impl/ChainSel.hs`)

### Summary

In `chainSelSync`, a Peras certificate is unconditionally written into `PerasCertDB` **before** the code checks whether the boosted block actually exists in the VolatileDB. Because `PerasCertDB` enforces one-certificate-per-round semantics, a peer that delivers a certificate for a non-existent (or not-yet-received) block for round R will permanently occupy that round's slot. Any subsequent legitimate certificate for the same round is silently rejected as `PerasCertAlreadyInDB`, losing its chain-selection weight boost entirely. Both `implAddCert` and `implAddVote` carry an explicit TODO acknowledging that non-trivial validation logic is still missing.

implAddCert PerasCertDbEnv{pcdbTracer, pcdbState} cert = do
  let roundNo = getPerasCertRound cert
  addPerasCertRes <- do
    WithFingerprint pcds fp <- readTVar pcdbState
    if Set.member roundNo (pcdsCertIds pcds)
      then pure PerasCertAlreadyInDB
      else do
        let pcdsLastTicketNo' = succ (pcdsLastTicketNo pcds)
            pcdsCertIds' = Set.insert roundNo (pcdsCertIds pcds)
            pcdsCertsByTicket' = Map.insert pcdsLastTicketNo' cert (pcdsCertsByTicket pcds)
            pcdsLatestCertSeen' = case pcdsLatestCertSeen pcds of
              Nothing -> Just cert
              Just prev
                | getPerasCertRound cert > getPerasCertRound prev -> Just cert
                | otherwise -> Just prev
        writeTVar pcdbState $
          WithFingerprint
            PerasCertDbState
              { pcdsCertIds = pcdsCertIds'
              , pcdsCertsByTicket = pcdsCertsByTicket'
              , pcdsLastTicketNo = pcdsLastTicketNo'
              , pcdsLatestCertSeen = pcdsLatestCertSeen'
              }
            (succ fp)
        pure AddedPerasCertToDB
  pure $ do
    traceWith pcdbTracer (AddCert roundNo cert addPerasCertRes)
    pure addPerasCertRes
