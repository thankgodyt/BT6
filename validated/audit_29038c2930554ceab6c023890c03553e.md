### Title
Non-Injective `PerasCertVoters` Decoding via Manipulated `maxIx` in `votersBitmap` Enables Voter Set Manipulation in Peras Certificates - (`File: ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Peras/Cert/V1.hs`)

---

### Summary

The `fromCBOR` instance for `PerasCertVoters` in `Cert/V1.hs` relies on `Bitmap.rawDeserialise` to validate the `votersBitmap`. Because `rawDeserialise` only checks that the byte string length equals `(maxIx `quot` 8) + 1`, multiple distinct `maxIx` values map to the same required byte length. An unprivileged peer can craft a `PerasCert` CBOR message with a reduced `maxIx` that passes the length check but causes `Bitmap.toIndices` to silently exclude high-index voters, reassigning non-persistent eligibility proofs (VRF outputs) to different voters than intended. This is the direct analog of the external report's non-injective decode: multiple byte sequences decode to different semantic values, and re-encoding the decoded value produces bytes that differ from the received bytes.

---

### Finding Description

**Root cause — `Bitmap.rawDeserialise` accepts multiple `maxIx` values for the same byte-string length:** [1](#0-0) 

```
expectedBytes = (fromIntegral maxIx `quot` 8) + 1
```

`maxIx = 8` → `expectedBytes = 2`
`maxIx = 15` → `expectedBytes = 2`

Both values pass the check with the same 2-byte payload. The `Bitmap` is constructed with the attacker-supplied `maxIx` stored verbatim.

**Root cause — `Bitmap.toIndices` uses `maxIx` as a hard filter:** [2](#0-1) 

```haskell
goBits !base !w =
  let !bitIx = countTrailingZeros w
      !i = base + bitIx
      ...
   in if i <= maxI
        then fromIntegral i : goBits base w'
        else []
```

If `maxIx` is reduced (e.g., from 15 to 8), any set bit at index > 8 is silently dropped from the returned index list, even though the byte string physically contains those bits and the `rawDeserialise` length check passed.

**Propagation into `fromCompactRepr`:** [3](#0-2) 

`fromCompactRepr` calls `Bitmap.toIndices votersBitmap` to obtain the ordered list of voter seat indices, then assigns the last `np` entries as non-persistent voters (paired with the `nonPersistentSigs` list). If a high-index voter is excluded by the manipulated `maxIx`, the non-persistent VRF outputs are re-assigned to different (lower-index) voters.

**Concrete example:**

| Field | Legitimate cert | Crafted cert |
|---|---|---|
| `maxIx` | 15 | 8 |
| Byte payload | `[0x0A, 0x81]` (bits 1,3,15 set) | same `[0x0A, 0x81]` |
| `rawDeserialise` check | passes (2 bytes) | passes (2 bytes) |
| `toIndices` result | {1, 3, 15} | {1, 3} (bit 15 excluded) |
| `nonPersistentSigs` | `[vrfOutput15]` | `[vrfOutput15]` (unchanged) |
| Decoded voters | {1→persistent, 3→persistent, 15→non-persistent(vrfOutput15)} | {1→persistent, 3→non-persistent(vrfOutput15)} |

Voter 3 is now incorrectly assigned voter 15's VRF eligibility proof.

**Re-encoding divergence (encode/decode round-trip failure):**

`toCompactRepr` sets `logicalUpperBound = unPerasSeatIndex (fst (NEMap.findMax voters))`. [4](#0-3) 

After decoding the crafted cert, `findMax` returns seat index 3 (not 15), so re-encoding produces `maxIx = 3` — a third distinct byte representation for the same decoded value. The encode/decode round-trip is broken.

---

### Impact Explanation

The `PerasCert` is received from an unprivileged peer via the `PerasCertDiffusion` miniprotocol and processed by `processCerts`: [5](#0-4) 

The `validatePerasCert` function called there is currently a stub that always returns `Right`: [6](#0-5) 

The `pcSignature` is described as covering only the election identifier (`pcRoundNo`) and certificate message (`pcBoostedBlock`), not `pcVoters`. Therefore, the BLS aggregate signature check does not detect voter set manipulation. A crafted certificate with a reduced `maxIx` passes deserialization, passes the current (stub) validation, and is stored in the `PerasCertDB` with an incorrect voter-to-eligibility-proof mapping. When proper eligibility verification is implemented, the non-injectivity structurally prevents correct verification because the decoded voter set and proof assignments differ from what was actually signed and transmitted.

This falls under: **Bypass of Peras voting or certificate checks that enables unauthorized certificate acceptance.**

---

### Likelihood Explanation

The attack requires only crafting a valid CBOR byte sequence with a modified `maxIx` field in the `votersBitmap`. The CBOR encoding scheme is public and the `Bitmap` format is straightforward. Any peer connected via the `PerasCertDiffusion` miniprotocol can send such a message. No keys, stake, or privileged access are required.

---

### Recommendation

**In `Bitmap.rawDeserialise`:** Enforce that `maxIx` is the *minimum* value consistent with the byte string length, i.e., reject any `maxIx` where `(fromIntegral maxIx `quot` 8) + 1` equals the byte string length but `maxIx` is not in the range `[nBytes*8 - 8, nBytes*8 - 1]`. Concretely:

```haskell
rawDeserialise maxIx bs
  | ByteString.length bs /= expectedBytes = Nothing
  | fromIntegral maxIx < (expectedBytes - 1) * 8 = Nothing  -- maxIx too small for byte count
  | otherwise = Just (Bitmap maxIx bs)
 where
  expectedBytes = (fromIntegral maxIx `quot` 8) + 1
```

**In `fromCBOR` for `Bitmap`:** After calling `rawDeserialise`, additionally verify that `maxIx` equals the actual highest set bit index in the byte string (or is within the last byte's range), ensuring the canonical form is enforced on inbound data.

**In `fromCompactRepr`:** Add an explicit check that `Bitmap.logicalUpperBound votersBitmap` equals the maximum seat index returned by `Bitmap.toIndices votersBitmap`, rejecting certificates where the stored `maxIx` does not match the actual highest voter index.

```haskell
toIndices :: Integral a => Bitmap a -> [a]
toIndices (Bitmap maxIx bitmap) =
  goBytes 0
 where
  !maxI = fromIntegral maxIx :: Int
  !nBytes = ByteString.length bitmap

  goBytes !byteIx
    | byteIx >= nBytes = []
    | otherwise =
        let !w = ByteString.index bitmap byteIx
         in goBits (byteIx * 8) w <> goBytes (byteIx + 1)

  goBits !_ 0 = []
  goBits !base !w =
    let !bitIx = countTrailingZeros w
        !i = base + bitIx
        !w' = w .&. (w - 1)
     in if i <= maxI
          then fromIntegral i : goBits base w'
          else []
```

```haskell
fromCompactRepr ::
  CompactPerasCertVoters ->
  Either String PerasCertVoters
fromCompactRepr
  CompactPerasCertVoters
    { votersBitmap
    , nonPersistentSigs
    } = do
    let voterSeatIndices =
          PerasSeatIndex <$> Bitmap.toIndices votersBitmap

    when (null voterSeatIndices) $
      throwError "Invalid Peras certificate: empty voters bitmap"

    when (length nonPersistentSigs > length voterSeatIndices) $
      throwError $
        unlines
          [ "Invalid Peras certificate:"
              <> " more non-persistent voter eligibility proofs were provided"
              <> " than the number of voters in the certificate"
          , " * number of voters: "
              <> show (length voterSeatIndices)
          , " * number of proofs: "
              <> show (length nonPersistentSigs)
          ]

    let numPersistentVoters =
          length voterSeatIndices - length nonPersistentSigs
    let persistentProofs =
          take numPersistentVoters (repeat PersistentPerasVoteEligibilityProof)
    let nonPersistentProofs =
          fmap NonPersistentPerasVoteEligibilityProof nonPersistentSigs
    let voters =
          NEMap.fromAscList
            . NonEmpty.fromList
            . zip voterSeatIndices
            $ persistentProofs <> nonPersistentProofs

    pure (PerasCertVoters voters)
```

```haskell
toCompactRepr ::
  PerasCertVoters ->
  CompactPerasCertVoters
toCompactRepr (PerasCertVoters voters) =
  CompactPerasCertVoters
    { votersBitmap
    , nonPersistentSigs
    }
 where
  logicalUpperBound =
    unPerasSeatIndex (fst (NEMap.findMax voters))
  votersByAscSeatIndex =
    NonEmpty.toList (NEMap.toAscList voters)
  votersSeatIndices =
    fmap (unPerasSeatIndex . fst) votersByAscSeatIndex
  votersBitmap =
    Bitmap.fromIndices logicalUpperBound votersSeatIndices
  nonPersistentSigs =
    catMaybes (fmap getNonPersistentSig votersByAscSeatIndex)
  getNonPersistentSig = \case
    (_, PersistentPerasVoteEligibilityProof) -> Nothing
    (_, NonPersistentPerasVoteEligibilityProof p) -> Just p
```

```haskell
  MonadSTM m =>
  SystemTime m ->
  STM m (Set PerasRoundNo) ->
  (PerasCert blk -> Either (PerasValidationErr blk) (ValidatedPerasCert blk)) ->
  (WithArrivalTime (ValidatedPerasCert blk) -> m ()) ->
  [PerasCert blk] ->
  m ()
processCerts systemTime alreadyInDbSTM validateCert addCert certs = do
  alreadyInDb <- atomically alreadyInDbSTM
  let certsNotAlreadyInDb = filter (not . (`Set.member` alreadyInDb) . getPerasCertRound) certs
  now <- systemTimeCurrent systemTime
  case partitionEithers (validateCert <$> certsNotAlreadyInDb) of
    -- All certs are valid => add them to the pool
    ([], validatedCerts) ->
      mapM_
        (addCert . WithArrivalTime now)
        validatedCerts
    -- Some certs are invalid => reject the whole batch

    -- N.B. it has been requested in PR review

    -- rather than just report the first error encountered.
```
