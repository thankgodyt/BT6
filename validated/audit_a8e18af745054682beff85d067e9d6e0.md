### Title
Peras Vote and Certificate Signature Verification Bypass Allows Unauthorized Chain Boosting — (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Block/SupportsPeras.hs`)

---

### Summary

The universal `BlockSupportsPeras` instance's `validatePerasCert` unconditionally accepts every certificate without any check, and `validatePerasVote` accepts any vote whose voter ID appears in the stake distribution without verifying the vote's cryptographic signature. This is the direct analog of the Adrena "owner-only check" pattern: a superficial identifier lookup replaces a proper cryptographic proof. An unprivileged peer can forge Peras votes for any registered stake pool and forge arbitrary Peras certificates, manipulating the Peras chain-boosting weight and causing honest nodes to prefer a non-canonical chain.

---

### Finding Description

**Root cause — `validatePerasCert` is a no-op:** [1](#0-0) 

```haskell
-- TODO: perform actual validation against all
-- possible 'PerasValidationErr' variants
validatePerasCert params cert =
  Right
    ValidatedPerasCert
      { vpcCert = cert
      , vpcCertBoost = perasWeight params
      }
```

Every certificate, regardless of content, is unconditionally accepted. No signature, no quorum proof, no round-number check.

**Root cause — `validatePerasVote` checks only a stake-distribution lookup, not the vote signature:** [2](#0-1) 

```haskell
-- TODO: perform actual validation against all
-- possible 'PerasValidationErr' variants
validatePerasVote _params stakeDistr vote
  | Just stake <- lookupPerasVoteStake vote stakeDistr =
      Right ValidatedPerasVote { vpvVote = vote, vpvVoteStake = stake }
  | otherwise =
      Left PerasValidationErr
```

`lookupPerasVoteStake` is a plain `Map.lookup` on `pvVoteVoterId vote`: [3](#0-2) 

The vote's cryptographic signature (`pvSignature` in the concrete `PerasVote` type) is never verified. Any peer that knows a registered pool's `PerasVoterId` (a public key hash, visible on-chain) can craft a vote that passes validation.

**This is the only instance — it is the catch-all for all block types:** [4](#0-3) 

```haskell
-- TODO: degenerate instance for all blks to get things to compile
instance StandardHash blk => BlockSupportsPeras blk where
```

No more-specific instance overrides this for `CardanoBlock` or `ShelleyBlock`.

**Production entry path — inbound votes from peers:** [5](#0-4) 

`makePerasVotePoolWriterFromChainDB` wires the Peras vote diffusion mini-protocol directly to `validatePerasVote`:

```haskell
(\vote -> getStakeDistrSTM >>= \sd -> pure $ validatePerasVote mkPerasParams sd vote)
```

`processVotes` then accepts every vote that passes this check and stores it in the `PerasVoteDB`: [6](#0-5) 

Once enough forged votes accumulate to satisfy `votesReachQuorum`, `forgePerasCert` is called and the resulting certificate is stored, ready to boost the attacker's chosen block. [7](#0-6) 

---

### Impact Explanation

**High — chain-selection bug via unauthorized Peras boosting.**

Peras certificates add `perasWeight` to a block's chain weight. An unprivileged peer that can inject forged votes for a quorum of registered pools causes an honest node to forge a certificate boosting an arbitrary block. Because chain selection is weight-based, the node will prefer the boosted (potentially non-canonical) chain over the honest chain, constituting a chain-selection error driven entirely by network input with no key compromise required.

---

### Likelihood Explanation

**Medium.** The Peras vote diffusion mini-protocol is reachable by any connected peer. Registered pool IDs (`PerasVoterId` = `KeyHash StakePool`) are public on-chain data. The attacker needs only to enumerate registered pools, craft votes with their IDs, and send them to a target node. No privileged keys, no stake majority, and no brute-force are required. The only limiting factor is that the Peras protocol must be active on the network.

---

### Recommendation

Replace the stub implementations with real cryptographic checks:

1. **`validatePerasVote`**: After the stake-distribution lookup, verify the vote's BLS signature (`pvSignature`) against the voter's registered public key for the claimed `(pvVoteRound, pvVoteBoostedBlock)` message, mirroring the `checkVoteSignature` logic already present in `WFALS.hs`. [8](#0-7) 

2. **`validatePerasCert`**: Verify the aggregate BLS signature and quorum proof before returning `Right`, mirroring `implVerifyCert` in `EveryoneVotes.hs` and `WFALS.hs`. [9](#0-8) 

The concrete cryptographic machinery (`CryptoSupportsAggregateVoteSigning`, `batchVerifyVRFOutputs`) is already implemented in `PerasBLSCrypto`; it only needs to be wired into the `BlockSupportsPeras` instance. [10](#0-9) 

---

### Proof of Concept

**Preconditions:** Attacker is a connected peer; target node has Peras active; attacker knows any `n` registered pool IDs that together exceed the quorum threshold (all public on-chain).

**Steps:**

1. For each target pool ID `pid_i`, construct a `PerasVote` with:
   - `pvVoteVoterId = pid_i` (registered pool, passes the map lookup)
   - `pvVoteRound` = current Peras round
   - `pvVoteBoostedBlock` = attacker's chosen block hash
   - `pvSignature` = any value (never checked)

2. Send the batch of forged votes to the target node via the Peras vote diffusion mini-protocol.

3. `processVotes` calls `validatePerasVote` for each vote. Each passes because `lookupPerasVoteStake` finds `pid_i` in the stake distribution.

4. Votes are stored in `PerasVoteDB`. Once accumulated stake exceeds `perasQuorumStakeThreshold`, `votesReachQuorum` returns `Just`, and `forgePerasCert` is called.

5. The resulting certificate boosts the attacker's chosen block. The node's chain-selection logic now assigns extra weight to that block, potentially causing it to prefer a non-canonical chain.

**Expected outcome:** Honest node accepts forged votes and produces a Peras certificate for an attacker-controlled block without any pool operator's private key being involved.

```haskell
-- | Smart constructor for 'ValidatedPerasVotesReachingQuorum'.
--
-- This function checks that all votes are for the same target, and that their
-- total stake is above the quorum threshold defined in the given 'PerasCfg'.
-- It returns 'Nothing' if either of these conditions is not met.
votesReachQuorum ::
  StandardHash blk =>
  PerasCfg blk ->
  [ValidatedPerasVote blk] ->
  Maybe (ValidatedPerasVotesWithQuorum blk)
votesReachQuorum cfg votes =
  case votes of
    -- We need at least one vote to determine who these votes are for, so we
    -- can't vacuously reach a quorum, even if the quorum threshold is 0.
    [] -> Nothing
    -- If we have at least one vote, we must check that all votes are for the
    -- same target, and that their total stake of is above the quorum threshold.
    (v0 : vs)
      | not (allVotesMatchTarget v0 vs) ->
          Nothing
      | not votesHaveEnoughStake ->
          Nothing
      | otherwise ->
          Just
            ValidatedPerasVotesWithQuorum
              { vpvqTarget = getPerasVoteTarget v0
              , vpvqVotes = v0 :| vs
              , vpvqPerasCfg = cfg
              }
 where
  totalVoteStake =
    mconcat (vpvVoteStake <$> votes)
  votesHaveEnoughStake =
    stakeAboveThreshold cfg totalVoteStake
```

```haskell
processVotes ::
  MonadSTM m =>
  SystemTime m ->
  STM m (Set (PerasVoteId blk)) ->
  (PerasVote blk -> STM m (Either (PerasValidationErr blk) (ValidatedPerasVote blk))) ->
  (WithArrivalTime (ValidatedPerasVote blk) -> m ()) ->
  [PerasVote blk] ->
  m ()
processVotes systemTime alreadyInDbSTM validateVote addVote votes = do
  validationResults <- atomically $ do
    alreadyInDb <- alreadyInDbSTM
    let votesNotAlreadyInDb = filter (not . (`Set.member` alreadyInDb) . getPerasVoteId) votes
    mapM validateVote votesNotAlreadyInDb
  now <- systemTimeCurrent systemTime
  case partitionEithers validationResults of
    -- All votes are valid => add them to the pool
    ([], validatedVotes) ->
      mapM_
        (addVote . WithArrivalTime now)
        validatedVotes
    -- Some votes are invalid => reject the whole batch
    --
    -- N.B. it has been requested in PR review
    -- https://github.com/IntersectMBO/ouroboros-consensus/pull/1768#discussion_r2747873186
    -- to gather all validation errors and report them together in the exception
    -- rather than just report the first error encountered.
    -- This assumes that vote validation is cheap, which may not be true in
    -- practice depending on the actual crypto/committee selection scheme.
    -- Hence we may revisit this to lazily abort validation upon the first error
    -- encountered.
    (errs, _) ->
      throw (PerasVoteValidationError errs)
```

```haskell
implVerifyCert committee = \case
  EveryoneVotesCert electionId candidate voters aggSig -> do
    -- Traverse the list of voters in ascending seat index order, collecting:
    -- 1. their membership status
    -- 2. their vote verification keys (to verify the aggregate vote signature)
    (members, voteVerificationKeys) <-
      fmap munzip . flip traverse (NESet.toAscList voters) $ \case
        seatIndex
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee) -> do
              let voterVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              case nonZero voterStake of
                Nothing ->
                  Left (PoolHasNoStake seatIndex)
                Just nonZeroVoterStake ->
                  pure
                    ( EveryoneVotesMember
                        seatIndex
                        nonZeroVoterStake
                    , voterVerificationKey
                    )
          | otherwise ->
              Left (MissingSeatIndex seatIndex)
    -- Verify aggregate signature
    aggVerificationKey <-
      bimap CryptoError id $ do
        aggregateVoteVerificationKeys
          (Proxy @crypto)
          voteVerificationKeys
    bimap InvalidCertSignature id $
      verifyAggregateVoteSignature
        (Proxy @crypto)
        aggVerificationKey
        electionId
        candidate
        aggSig
```
