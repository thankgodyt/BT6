### Title
Stub `validatePerasCert` Always Accepts Any Certificate, Enabling Unauthorized Peras Weight Boost Injection - (`File: ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Block/SupportsPeras.hs`)

---

### Summary

The production `BlockSupportsPeras` instance ships a stub `validatePerasCert` that unconditionally returns `Right` for every inbound certificate, performing zero cryptographic or quorum verification. An unprivileged peer can therefore inject a crafted `PerasCert` for any round, boosting any block of their choice. Because `PerasCertDB` stores only one certificate per round (first-writer wins), the adversary's certificate permanently displaces the legitimate one for that round, granting an arbitrary chain-weight boost that can flip chain selection toward a non-canonical fork.

---

### Finding Description

**Root cause — stub validation always succeeds**

The `BlockSupportsPeras` instance for all block types is explicitly marked as a degenerate placeholder:

```haskell
-- TODO: perform actual validation against all
-- possible 'PerasValidationErr' variants
-- see https://github.com/tweag/cardano-peras/issues/120
validatePerasCert params cert =
  Right
    ValidatedPerasCert
      { vpcCert = cert
      , vpcCertBoost = perasWeight params
      }
``` [1](#0-0) 

No signature, no quorum proof, no committee membership check, no round-number bounds check — every `PerasCert` received from any peer is immediately wrapped in a `ValidatedPerasCert` carrying the full configured `perasWeight` boost.

**Inbound path — object diffusion mini-protocol**

Certificates arrive via `processCerts`, which calls the stub validator and, on success, forwards the result to `addCert`:

```haskell
processCerts systemTime alreadyInDbSTM validateCert addCert certs = do
  alreadyInDb <- atomically alreadyInDbSTM
  let certsNotAlreadyInDb = filter (not . (`Set.member` alreadyInDb) . getPerasCertRound) certs
  now <- systemTimeCurrent systemTime
  case partitionEithers (validateCert <$> certsNotAlreadyInDb) of
    ([], validatedCerts) ->
      mapM_ (addCert . WithArrivalTime now) validatedCerts
    (errs, _) ->
      throw (PerasCertValidationError errs)
``` [2](#0-1) 

The validator passed here is `validatePerasCert mkPerasParams` — the hardcoded stub — not a real cryptographic check. [3](#0-2) 

**First-writer-wins in PerasCertDB**

`implAddCert` stores at most one certificate per round number. Once a round's slot is occupied, all subsequent certificates for that round are silently dropped as `PerasCertAlreadyInDB`:

```haskell
if Set.member roundNo (pcdsCertIds pcds)
  then pure PerasCertAlreadyInDB
  else do
    ...
    pure AddedPerasCertToDB
``` [4](#0-3) 

**Weight snapshot feeds chain selection**

`implGetWeightSnapshot` builds the `PerasWeightSnapshot` directly from every certificate stored in `pcdsCertsByTicket`, with no re-validation:

```haskell
let weights =
      mkPerasWeightSnapshot
        [ (getPerasCertBoostedBlock cert, getPerasCertBoost cert)
        | cert <- Map.elems (pcdsCertsByTicket pcds)
        ]
``` [5](#0-4) 

This snapshot is consumed by `chainSelectionForBlock` and `initialChainSelection` to compute `wsvTotalWeight`, which is the primary comparator in `preferCandidate`:

```haskell
wsvTotalWeight wsv =
  PerasWeight (unBlockNo (wsvBlockNo wsv)) <> wsvWeightBoost wsv
``` [6](#0-5)

### Impact Explanation

An adversary who races to send a forged `PerasCert` for round R, boosting a block on a minority fork, before the honest certificate arrives:

1. Occupies the round-R slot in `PerasCertDB` permanently (honest cert is rejected as duplicate).
2. Injects a `perasWeight`-sized boost (default 15, equivalent to 15 extra blocks) onto the fork's chain weight.
3. Causes the victim node to prefer the adversary's fork over the honest chain in `preferCandidate`.

This is a **Critical** bypass of Peras certificate verification that enables unauthorized certificate acceptance and chain-selection manipulation toward a non-canonical chain.

---

### Likelihood Explanation

- The object diffusion mini-protocol is reachable by any peer the node connects to.
- No stake, no keys, no quorum of votes is required — a single TCP connection suffices.
- The race window is the propagation delay between the adversary's message and the honest certificate; on a well-connected adversary this is easily winnable.
- The `PerasCertDB` first-writer-wins semantics make the attack permanent for the lifetime of that round's slot.

---

### Recommendation

1. **Implement real cryptographic validation** in `validatePerasCert`: verify the aggregate BLS/KES signature over the certificate, confirm the signing committee reached quorum against the epoch's stake snapshot, and check round-number bounds against the current slot.
2. **Do not use a hardcoded `mkPerasParams`** in `processCerts`; thread the node's live `PerasCfg` through the object-pool writer so validation uses the correct parameters.
3. **Consider equivocation handling**: if a certificate for round R already exists but the incoming certificate boosts a *different* block, this is equivocation and should be treated as a punishable offense rather than a silent duplicate drop.
4. Until (1) is complete, gate the object-diffusion inbound path behind a feature flag that is disabled by default.

---

### Proof of Concept

```
1. Node A connects to victim node V via the Peras certificate object-diffusion mini-protocol.
2. A crafts PerasCert { pcCertRound = R, pcCertBoostedBlock = Point(fork_block_hash) }.
3. A sends the cert before any honest node sends the legitimate cert for round R.
4. processCerts calls validatePerasCert mkPerasParams cert → Right (ValidatedPerasCert { vpcCertBoost = 15 }).
5. implAddCert stores the cert; pcdsCertIds now contains R.
6. Honest cert for round R arrives → Set.member R pcdsCertIds == True → PerasCertAlreadyInDB, discarded.
7. implGetWeightSnapshot returns a PerasWeightSnapshot with fork_block_hash → PerasWeight 15.
8. chainSelectionForBlock computes wsvTotalWeight(fork) = fork_length + 15 > honest_length.
9. preferCandidate returns ShouldSwitch; V adopts the adversary's fork.
```

  case partitionEithers (validateCert <$> certsNotAlreadyInDb) of
    -- All certs are valid => add them to the pool
