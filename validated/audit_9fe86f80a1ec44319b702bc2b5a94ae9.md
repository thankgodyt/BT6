### Title
Hardcoded `boundX = 3` in `taylorExpCmpFirstNonLower` Violates Required Error-Bound Invariant for Large `lambda`, Producing Incorrect Peras Committee Seat Counts - (`File: ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/LS.hs`)

---

### Summary

`localSortitionNumSeats` in `LS.hs` calls `taylorExpCmpFirstNonLower` with a hardcoded `boundX = 3`. The function's own invariant requires `boundX = e^{|x|}` for correct error estimation. The `x` argument is `-lambda`, so the invariant demands `boundX >= e^lambda`. When `lambda > ln(3) ≈ 1.099` — a routine condition for any voter holding more than `ln(3)/numNonPersistentVoters` of the non-persistent stake — the error term is underestimated, and the Taylor comparison returns an incorrect seat count. This incorrect count is used directly in `implVerifyVote` and `implVerifyCert` to gate Peras non-persistent committee membership, enabling either unauthorized vote acceptance or unjustified vote-weight inflation.

---

### Finding Description

`localSortitionNumSeats` computes how many non-persistent Peras committee seats a voter is granted via local sortition (a Poisson-CDF comparison against a normalized VRF output): [1](#0-0) 

The Poisson parameter `lambda` is:

```
lambda = numNonPersistentVoters * voterStake / totalNonPersistentStake
```

The seat count is then determined by: [2](#0-1) 

`taylorExpCmpFirstNonLower` approximates `e^x` via a Taylor series and uses `boundX` to bound the tail error: [3](#0-2) 

The tail error term is: [4](#0-3) 

The invariant `boundX = e^{|x|}` is required so that `errorTerm` is a valid upper bound on the remaining Taylor series. With `x = -lambda` and `boundX = 3`, this invariant holds only when `e^lambda <= 3`, i.e., `lambda <= ln(3) ≈ 1.099`.

For a committee with `numNonPersistentVoters = N`, any voter holding more than `ln(3)/N ≈ 1.099/N` of the non-persistent stake will have `lambda > ln(3)`. For `N = 10` this threshold is ~11%; for `N = 100` it is ~1.1%. Both are routine in production stake distributions.

When `lambda > ln(3)`, `errorTerm = abs(err' * 3)` underestimates the true Taylor remainder `abs(err' * e^lambda)`. The `decideOne` comparisons: [5](#0-4) 

...can then prematurely classify a threshold as "ABOVE" (returning `Stop`, i.e., granting a seat) when the true `e^{-lambda}` is actually below the threshold, or prematurely classify it as "BELOW" when it is not. The returned index becomes `expectedSeats`, which is wrong.

The code itself acknowledges the `boundX = 3` value is unvalidated: [6](#0-5)

### Impact Explanation

The incorrect `expectedSeats` value flows directly into the Peras vote and certificate verification paths:

**`implVerifyVote`** — a non-persistent voter's eligibility is gated on `nonZero numSeats`: [7](#0-6) 

**`implVerifyCert`** — the same check is repeated for each non-persistent voter in a certificate: [8](#0-7) 

Two failure modes arise:

1. **Unauthorized vote/certificate acceptance**: A voter whose true Poisson draw yields zero seats is incorrectly granted `numSeats > 0` due to the underestimated error bound. Their vote passes `implVerifyVote` and their contribution passes `implVerifyCert`, allowing an ineligible party to influence the Peras election outcome.

2. **Vote-weight inflation**: A voter legitimately entitled to `k` seats is incorrectly granted `k' > k` seats. Their vote weight is computed as `numSeats * stake / totalNonPersistentStake`: [9](#0-8) 

Both outcomes corrupt the Peras quorum calculation, potentially causing honest nodes to accept a certificate that does not represent a genuine supermajority, or to reject a valid one — a direct Peras voting integrity failure.

---

### Likelihood Explanation

The condition `lambda > ln(3)` is met whenever a voter's share of non-persistent stake exceeds `ln(3)/numNonPersistentVoters`. For any committee with more than a handful of non-persistent seats and any non-trivially concentrated stake pool, this threshold is crossed routinely. No special attacker capability is required: any non-persistent committee member with sufficient stake will trigger the incorrect branch on every election they participate in. The entry path is a standard `WFALSNonPersistentVote` message received over the Peras diffusion miniprotocol.

---

### Recommendation

Replace the hardcoded `3` with the mathematically correct bound. Since `x = -lambda` and `lambda > 0`, the correct value is `exp lambda` computed in `FixedPoint` arithmetic before calling `taylorExpCmpFirstNonLower`:

```haskell
expectedSeats =
  fromMaybe 0 $
    taylorExpCmpFirstNonLower
      (exp lambda)   -- correct: e^{|x|} = e^lambda
      orders
      (-lambda)
```

Alternatively, adopt the upstream `checkLeaderNatValue` pattern from `cardano-ledger`'s `Cardano.Ledger.NonIntegral`, which computes the bound correctly, and resolve the open TODO tracked at https://github.com/tweag/cardano-peras/issues/234.

---

### Proof of Concept

Let `numNonPersistentVoters = 20`, `voterStake / totalNonPersistentStake = 0.1` (10% of non-persistent stake). Then:

```
lambda = 20 * 0.1 = 2.0
e^lambda = e^2.0 ≈ 7.389
```

The correct `boundX` is `7.389`, but `3` is used. The error term is underestimated by a factor of `7.389/3 ≈ 2.46`. At iteration `n`, the algorithm believes the remaining error is at most `|err_n| * 3`, but the true bound is `|err_n| * 7.389`. The algorithm will prematurely declare convergence, returning an incorrect seat index. For a voter with `lambda = 2.0`, the Poisson CDF thresholds are well-separated, and the premature stop can shift the returned index by one or more seats, either granting eligibility to an ineligible voter or inflating a legitimate voter's seat count.   -- Decide current cmp by advancing the shared Taylor state as needed.
  -- If BELOW is established, returns the *advanced* state to continue with.
  -- If ABOVE is established or maxN reached, returns Stop.
  decideOne ::
    Int -> -- maxN
    Int -> -- n
    a -> -- err
    a -> -- acc
    a -> -- divisor
    a -> -- cmp
    Step a
  decideOne maxN n err acc divisor cmp
    | maxN == n = Stop
    | cmp >= acc' + errorTerm = Stop
    | cmp < acc' - errorTerm = Below (n + 1) err' acc' divisor'
    | otherwise = decideOne maxN (n + 1) err' acc' divisor' cmp
   where
    divisor' = divisor + 1
    nextX = err
    acc' = acc + nextX
    err' = (err * x) / divisor'
    errorTerm = abs (err' * boundX)
