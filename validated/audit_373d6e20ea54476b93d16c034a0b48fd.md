### Title
Peras Vote Signature Bypass via Degenerate `BlockSupportsPeras` Instance — (`File: ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Block/SupportsPeras.hs`)

---

### Summary

The catch-all `BlockSupportsPeras` instance for all `StandardHash blk` defines a `PerasVote blk` type with **no signature field** and a `validatePerasVote` implementation that performs **no BLS signature verification**. Any unprivileged peer can submit votes claiming to be any committee member in the stake distribution without possessing the corresponding BLS private key. Because this degenerate instance is the only one in the codebase, it is the production instance used by the live vote-diffusion path.

---

### Finding Description

The `BlockSupportsPeras` typeclass declares `validatePerasVote` as the gate that must authenticate inbound Peras votes before they are stored and counted toward quorum. [1](#0-0) 

The only concrete instance in the repository is the degenerate catch-all: [2](#0-1) 

This instance defines `PerasVote blk` with **no signature field** — only a round number, a target block, and a voter ID: [3](#0-2) 

Its `validatePerasVote` implementation only checks whether the supplied `PerasVoterId` (`KeyHash StakePool`) appears in the stake distribution. It performs **no cryptographic verification**: [4](#0-3) 

Similarly, `validatePerasCert` unconditionally returns `Right` for every certificate: [5](#0-4) 

The production vote-diffusion writer (`makePerasVotePoolWriterFromChainDB` and `makePerasVotePoolWriterFromVoteDB`) calls `validatePerasVote mkPerasParams sd vote` directly, resolving to this degenerate instance: [6](#0-5) 

`processVotes` — the network-facing inbound handler — accepts any vote that passes `validatePerasVote` and adds it to the `PerasVoteDB`: [7](#0-6) 

Once enough fake votes accumulate, `implAddVote` in the `PerasVoteDB` calls `updatePerasRoundVoteStates`, which triggers `forgePerasCert` — also a no-op validator in the degenerate instance — producing a `ValidatedPerasCert` that boosts the attacker's chosen block: [8](#0-7) 

The concrete `V1.PerasVote` type (in `Ouroboros.Consensus.Peras.Vote.V1`) does carry a BLS signature and the WFALS committee (`implVerifyVote`) does perform full signature + VRF verification, but neither is wired into the `BlockSupportsPeras` instance used by the diffusion layer. [9](#0-8) [10](#0-9) 

---

### Impact Explanation

An attacker who knows the current stake distribution (public on-chain data) can:

1. Enumerate all `PerasVoterId` values (stake-pool key hashes) in the distribution.
2. Craft `PerasVote blk` objects claiming to be those voters, targeting any block of their choice, with no signature field required.
3. Submit them via the Peras object-diffusion mini-protocol.
4. `validatePerasVote` accepts each vote because the voter ID is present in the distribution.
5. Once the accumulated fake stake exceeds the quorum threshold, `forgePerasCert` produces a `ValidatedPerasCert` boosting the attacker's block.
6. The boosted block gains extra Peras chain weight, causing honest nodes running `preferAnchoredCandidate` to switch to the adversarial chain.

This is a **Critical** bypass of Peras certificate/vote verification that lets an unprivileged peer cause honest nodes to accept and prefer an invalid or adversarial chain — a direct consensus safety failure.

---

### Likelihood Explanation

- The stake distribution is public; no privileged information is needed.
- The `PerasVote blk` type in the degenerate instance carries no signature, so there is nothing to forge.
- The attack requires only a standard peer connection to the object-diffusion endpoint.
- No Cardano-specific override of `BlockSupportsPeras` exists in the repository, so the degenerate instance is active for all block types.

Likelihood is **High** for any deployment that activates the Peras vote-diffusion protocol.

---

### Recommendation

1. **Remove the catch-all `instance StandardHash blk => BlockSupportsPeras blk`** or restrict it to a clearly non-production newtype wrapper so it cannot be resolved for real Cardano block types.
2. **Wire `V1.PerasVote` and `implVerifyVote` (WFALS)** into a concrete `BlockSupportsPeras CardanoBlock` instance that performs full BLS signature verification and VRF eligibility proof checking before a vote is accepted.
3. **Add a compile-time guard** (e.g., a type-level assertion or a `OVERLAPPABLE`/`OVERLAPPING` pragma audit) ensuring the degenerate instance is never selected for production block types.
4. Until the above is done, gate the Peras vote-diffusion writer behind a feature flag that is disabled in production builds.

-- and submit fake votes for an adversarial block.

import Ouroboros.Consensus.Peras.Params (mkPerasParams)

-- 1. Obtain the current PerasVoteStakeDistr from the chain (public).
--    Enumerate all PerasVoterId keys in the distribution.

-- 2. For each voterId in the distribution, craft a vote for the adversarial block:
fakeVote :: PerasRoundNo -> Point blk -> PerasVoterId -> PerasVote blk
fakeVote roundNo advBlock voterId =
  PerasVote          -- degenerate instance: no signature field
    { pvVoteRound  = roundNo
    , pvVoteBlock  = advBlock
    , pvVoteVoterId = voterId
    }

-- 3. Send [fakeVote r b v | v <- allVoterIds] via the object-diffusion protocol.
--    processVotes calls:
--      validatePerasVote mkPerasParams stakeDistr vote
--    which resolves to the degenerate instance and returns Right for every
--    vote whose voterId is in the distribution — no signature checked.

-- 4. Once total fake stake >= quorum threshold, PerasVoteDB calls forgePerasCert,
--    producing a ValidatedPerasCert that boosts advBlock.
--    Honest nodes switch to the adversarial chain.

implVerifyVote ::
  forall crypto.
  ( CryptoSupportsVoteSigning crypto
  , CryptoSupportsVRF crypto
  ) =>
  VotingCommittee crypto WFALS ->
  Vote crypto WFALS ->
  Either
    (VotingCommitteeError crypto WFALS)
    (EligibilityWitness crypto WFALS)
implVerifyVote committee = \case
  WFALSPersistentVote seatIndex electionId candidate sig
    | Just (_, voterPublicKey, voterStake, _) <-
        getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
    , isPersistentMember seatIndex committee -> do
        let voterVerificationKey =
              getVoteVerificationKey (Proxy @crypto) voterPublicKey
        checkVoteSignature voterVerificationKey electionId candidate sig
        pure $
          WFALSPersistentMember
            seatIndex
            voterStake
    | otherwise -> do
        Left (NotAPersistentMember seatIndex)
  WFALSNonPersistentVote seatIndex electionId message vrfOutput sig
    | Just (_, voterPublicKey, voterStake, _) <-
        getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
    , not (isPersistentMember seatIndex committee) -> do
        let voterVoteVerificationKey =
              getVoteVerificationKey (Proxy @crypto) voterPublicKey
        bimap InvalidVoteSignature id $ do
          verifyVoteSignature
            voterVoteVerificationKey
            electionId
            message
            sig
        let voterVRFVerificationKey =
              getVRFVerificationKey (Proxy @crypto) voterPublicKey
        let vrfContext =
              VRFVerifyContext voterVRFVerificationKey vrfOutput
        void $ bimap InvalidVoterEligibilityProof id $ do
          evalVRF
            vrfContext
            ( mkVRFElectionInput
                @crypto
                (epochNonce committee)
                electionId
            )
        let numSeats =
              localSortitionNumSeats
                (nonPersistentCommitteeSize committee)
                (totalNonPersistentStake committee)
                voterStake
                (normalizeVRFOutput vrfOutput)
        case nonZero numSeats of
          Nothing ->
            Left (ZeroNonPersistentSeats seatIndex)
          Just nonZeroNumSeats ->
            pure $
              WFALSNonPersistentMember
                seatIndex
                voterStake
                vrfOutput
                nonZeroNumSeats
    | otherwise ->
        Left (NotANonPersistentMember seatIndex)
