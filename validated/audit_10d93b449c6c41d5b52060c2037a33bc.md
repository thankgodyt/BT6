### Title
Hardcoded `boundX = 3` in `localSortitionNumSeats` Produces Incorrect Taylor Error Bounds, Enabling Unauthorized Peras Vote Acceptance - (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/LS.hs`)

---

### Summary

`localSortitionNumSeats` in `LS.hs` computes how many non-persistent committee seats a voter is granted via local sortition. It calls `taylorExpCmpFirstNonLower 3 orders (-lambda)`, passing the hardcoded constant `3` as the `boundX` parameter. The function's own documentation states `boundX` must equal `e^{|x|}` for correct error bounds. Since `x = -lambda`, the correct value is `e^lambda`. When `lambda > ln(3) ≈ 1.099`, the hardcoded `3` is smaller than the true bound, causing the error term to be underestimated and the algorithm to make incorrect seat-count decisions. This function is called inside `implVerifyVote` and `implVerifyCert` in `WFALS.hs` to gate acceptance of non-persistent committee votes and certificates. An incorrect positive seat count for a voter who should receive zero seats causes an unauthorized Peras vote or certificate to be accepted.

---

### Finding Description

`localSortitionNumSeats` models local sortition as a Poisson process with parameter `lambda = numNonPersistentVoters * voterStake / totalNonPersistentStake`. It uses `taylorExpCmpFirstNonLower` to compare the cumulative distribution function of the Poisson distribution against the voter's normalized VRF output, determining how many seats the voter wins. [1](#0-0) 

The `taylorExpCmpFirstNonLower` helper computes a Taylor expansion of `e^x` and uses `boundX` to bound the truncation error:

```
errorTerm = abs (err' * boundX)
``` [2](#0-1) 

The parameter contract is explicit: `boundX` must equal `e^{|x|}`. Here `x = -lambda`, so `|x| = lambda`, and the correct value is `e^lambda`. The call site passes the constant `3` instead:

```haskell
taylorExpCmpFirstNonLower
  3          -- ← should be e^lambda, not 3
  orders
  (-lambda)
``` [3](#0-2) 

When `lambda > ln(3) ≈ 1.099`, `e^lambda > 3`, so `boundX` is too small. The `errorTerm` is underestimated, making the algorithm overconfident. Specifically, the guard `cmp >= acc' + errorTerm` (line 167) fires prematurely on a `Stop` branch, returning a seat count that is too high. A voter whose true Poisson CDF comparison should yield 0 seats can instead receive ≥1 seats.

The code itself acknowledges the uncertainty with an open TODO tracked at https://github.com/tweag/cardano-peras/issues/234:

> TODO(peras): evaluate whether the limit used below (3) makes sense in this context. [4](#0-3) 

`localSortitionNumSeats` is called in two security-critical verification paths in `WFALS.hs`:

**`implVerifyVote`** — verifies a non-persistent committee member's vote received from a peer:

```haskell
let numSeats =
      localSortitionNumSeats
        (nonPersistentCommitteeSize committee)
        (totalNonPersistentStake committee)
        voterStake
        (normalizeVRFOutput vrfOutput)
case nonZero numSeats of
  Nothing ->
    Left (ZeroNonPersistentSeats seatIndex)   -- vote rejected
  Just nonZeroNumSeats ->
    pure $ WFALSNonPersistentMember ...        -- vote accepted
``` [5](#0-4) 

**`implVerifyCert`** — verifies a certificate aggregating multiple non-persistent votes: [6](#0-5) 

If `localSortitionNumSeats` returns a non-zero value when the correct answer is zero, both paths accept the vote/certificate without error.

---

### Impact Explanation

An unauthorized non-persistent committee vote or certificate is accepted by an honest node. In the Peras protocol, committee votes determine which block is boosted and whether a certificate is formed. Accepting votes from ineligible voters inflates the apparent voting weight of an attacker, potentially allowing them to:

- Force certificate formation for a block that would not otherwise reach quorum, boosting a non-canonical chain.
- Corrupt the Peras voting outcome, breaking the fast-finality guarantee and causing chain-selection divergence between nodes that apply the incorrect seat count and those that do not.

This maps to the allowed impact: **Critical — Bypass of Peras voting or certificate checks that enables unauthorized vote or certificate acceptance.**

---

### Likelihood Explanation

The condition `lambda > ln(3) ≈ 1.099` is reached whenever:

```
voterStake / totalNonPersistentStake > ln(3) / numNonPersistentVoters
```

With a committee of 10 non-persistent voters, any voter holding more than ~11% of the non-persistent stake satisfies this. Stake pools with moderate concentration routinely exceed this threshold. The attacker does not need a stake majority; they only need to be a non-persistent committee candidate (appear in the stake distribution) with sufficient relative stake. The VRF output is determined by the attacker's own key and the election nonce, so the attacker can observe their own `lambda` and know when the incorrect `boundX` will produce a wrong result. No external oracle or privileged access is required.

---

### Recommendation

Replace the hardcoded `3` with the mathematically correct bound `e^lambda`:

```haskell
expectedSeats =
  fromMaybe 0 $
    taylorExpCmpFirstNonLower
      (exp lambda)   -- correct: e^{|x|} where x = -lambda
      orders
      (-lambda)
```

This matches the documented contract of `taylorExpCmpFirstNonLower` and ensures the error bound is valid for all values of `lambda`, not just those below `ln(3)`. The fix should be applied before the Peras committee selection code is activated on any network where vote/certificate verification is enforced.

---

### Proof of Concept

**Setup:** Committee with `numNonPersistentVoters = 10`, voter holds 15% of non-persistent stake → `lambda = 10 * 0.15 = 1.5`.

**Correct bound:** `e^1.5 ≈ 4.48`. **Used bound:** `3`.

**Effect:** `errorTerm = abs(err' * 3)` instead of `abs(err' * 4.48)`. The error term is underestimated by factor ~1.49. For a VRF output near the Poisson CDF boundary between 0 and 1 seats, the algorithm declares convergence to "1 seat" before enough Taylor terms have been computed to confirm this. The voter's vote passes `implVerifyVote` with `nonZero numSeats = Just 1` when the correct answer is `Nothing` (0 seats), and the vote is accepted. [7](#0-6) [8](#0-7)

-- IMPORTANT: boundX must be e^{|x|} for correct error bounds (see taylorExpCmp).
taylorExpCmpFirstNonLower ::
  forall a.
  RealFrac a =>
  -- | boundX = e^{|x|} for correct error estimation
  a ->
  -- | list of cmp thresholds (checked in order)
  [a] ->
  -- | x in e^x
  a ->
  Maybe Int
taylorExpCmpFirstNonLower boundX cmps x =
  goList 1000 0 x 1 1 0 cmps
 where
  -- Traverse the list of cmps, advancing the Taylor state as needed while
  -- checking if the current cmp is ABOVE or BELOW. If ABOVE, return the index.
  goList ::
    Int -> -- maxN
    Int -> -- n
    a -> -- err
    a -> -- acc
    a -> -- divisor
    Int -> -- current index
    [a] -> -- remaining cmps
    Maybe Int
  goList _ _ _ _ _ _ [] = Nothing
  goList maxN n err acc divisor i (cmp : rest) =
    case decideOne maxN n err acc divisor cmp of
      Stop ->
        Just i
      Below n' err' acc' divisor' ->
        goList maxN n' err' acc' divisor' (i + 1) rest

  -- Decide current cmp by advancing the shared Taylor state as needed.
  -- If BELOW is established, returns the *advanced* state to continue with.
  -- If ABOVE is established or maxN reached, returns Stop.
  decideOne ::
    Int -> -- maxN
    Int -> -- n
    a -> -- err
    a -> -- acc
    a -> -- divisor
    a -> -- cmp
    Step a
  decideOne maxN n err acc divisor cmp
    | maxN == n = Stop
    | cmp >= acc' + errorTerm = Stop
    | cmp < acc' - errorTerm = Below (n + 1) err' acc' divisor'
    | otherwise = decideOne maxN (n + 1) err' acc' divisor' cmp
   where
    divisor' = divisor + 1
    nextX = err
    acc' = acc + nextX
    err' = (err * x) / divisor'
    errorTerm = abs (err' * boundX)
```
