### Title
Missing Pause Guard on `logMetadata` and `logMetadata1155` Allows Pause Bypass for Deployer-Equivalent Actions — (File: `evm/src/omni-bridge/contracts/OmniBridge.sol`)

---

### Summary

`OmniBridge.sol` applies `whenNotPaused` to every critical bridge operation except `logMetadata` and `logMetadata1155`. Both functions are publicly callable with no access control and no pause check, allowing any unprivileged caller to invoke them even when the bridge is fully paused. `logMetadata1155` additionally writes to the `multiTokens` state mapping that governs ERC-1155 token routing in `finTransfer`.

---

### Finding Description

`OmniBridge.sol` uses a selective pause system with three flags:

```solidity
uint256 constant PAUSED_INIT_TRANSFER = 1 << 0;
uint256 constant PAUSED_FIN_TRANSFER  = 1 << 1;
uint256 constant PAUSED_DEPLOY_TOKEN  = 1 << 2;
```

Every state-changing bridge entry point is guarded:

| Function | Guard |
|---|---|
| `initTransfer` | `whenNotPaused(PAUSED_INIT_TRANSFER)` |
| `initTransfer1155` | `whenNotPaused(PAUSED_INIT_TRANSFER)` |
| `finTransfer` | `whenNotPaused(PAUSED_FIN_TRANSFER)` |
| `deployToken` | `whenNotPaused(PAUSED_DEPLOY_TOKEN)` |

However, `logMetadata` and `logMetadata1155` carry **no pause modifier**:

---

### Impact Explanation

**`logMetadata` pause bypass:** When the EVM bridge is paused (e.g., emergency halt due to a security incident), any unprivileged caller can still invoke `logMetadata` with an arbitrary `tokenAddress`, including a malicious contract returning crafted `name`/`symbol`/`decimals`. This emits a `LogMetadata` event. If the NEAR hub is not simultaneously paused, a relayer will deliver this event to the NEAR bridge, which will deploy a token on NEAR with the attacker-controlled metadata. This is a deployer-equivalent action executed in violation of the EVM bridge's paused state.

**`logMetadata1155` pause bypass:** While the bridge is paused, an attacker can call `logMetadata1155` to write a new entry into the `multiTokens` mapping for any previously unmapped `deterministicToken` address. Once the bridge is unpaused, `finTransfer` will use this mapping to route ERC-1155 token releases — the mapping entry set during the pause period will govern which ERC-1155 contract is called for `safeTransferFrom`, affecting token delivery to recipients.

---

### Likelihood Explanation

High. Both functions are `external payable` with no role check and no pause check. Any EOA or contract can call them at any time, including during an active pause. No special privilege, front-running, or off-chain coordination is required.

---

### Recommendation

Add `whenNotPaused` guards to both functions. Since `logMetadata` is semantically a prerequisite for token deployment, `PAUSED_DEPLOY_TOKEN` is the appropriate flag. Alternatively, introduce a dedicated `PAUSED_LOG_METADATA` flag and include it in `pauseAll()`:
