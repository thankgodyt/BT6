### Title
Incorrect `boundX` constant in `taylorExpCmpFirstNonLower` produces wrong Peras non-persistent voting seat count for high-stake committee members — (`File: ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/LS.hs`)

---

### Summary

`localSortitionNumSeats` in `LS.hs` calls `taylorExpCmpFirstNonLower` with a hardcoded `boundX = 3`. The function's own contract requires `boundX = e^{|x|}` for correct error bounds. With `x = -lambda`, the required value is `e^lambda`. For any non-persistent committee member whose expected seat count `lambda > ln(3) ≈ 1.099`, the error bound is underestimated, causing the Taylor expansion to declare a comparison result as "certain" when it is not, and returning an incorrect seat count. The code itself carries an unresolved TODO acknowledging the value has never been verified for this context.

---

### Finding Description

`localSortitionNumSeats` determines how many non-persistent Peras voting seats a voter receives by comparing a normalized VRF output against Poisson distribution thresholds:

```haskell
lambda =
  fromRational $
    fromIntegral numNonPersistentVoters
      * voterStake
      / totalNonPersistentStake

orders =
  (fromRational normalizedVRFOutput / lambda)
    : zipWith (\k prev -> k * prev / lambda) [2 ..] orders

expectedSeats =
  fromMaybe 0 $
    taylorExpCmpFirstNonLower
      3          -- ← hardcoded; should be e^lambda
      orders
      (-lambda)
``` [1](#0-0) 

`taylorExpCmpFirstNonLower` computes the Taylor expansion of `e^x` and uses `boundX` to bound the tail error at each step:

```haskell
errorTerm = abs (err' * boundX)
``` [2](#0-1) 

The function's own contract is explicit:

```
-- IMPORTANT: boundX must be e^{|x|} for correct error bounds (see taylorExpCmp).
``` [3](#0-2) 

With `x = -lambda`, the required value is `e^lambda`. The hardcoded `3` is valid only when `lambda <= ln(3) ≈ 1.099`. The code's own TODO acknowledges this was never verified:

```
-- TODO(peras): evaluate whether the limit used below (3) makes sense in
-- this context. One possible starting point would be to understand why
-- @checkLeaderNatValue@ (in Ledger) also uses 3 as its own limit when
-- computing slot leadership proofs.
``` [4](#0-3) 

The `3` was copied from the Praos leader-eligibility check (`checkLeaderNatValue`), where it is valid because `|x| = sigma * |ln(1-f)| <= |ln(19/20)| ≈ 0.051`, giving `e^{0.051} ≈ 1.05 << 3`. For local sortition, `lambda` is proportional to the voter's share of non-persistent stake and can far exceed `ln(3)`.

When `boundX < e^lambda`, `errorTerm` is smaller than the true tail bound. The `decideOne` loop:

```haskell
| cmp >= acc' + errorTerm = Stop   -- declares ABOVE (returns this index)
| cmp < acc' - errorTerm  = Below  -- declares BELOW (advances to next)
``` [5](#0-4) 

…may prematurely declare a comparison as "certain" when the true Taylor remainder is still larger than `errorTerm`. This causes the function to return an incorrect index, granting the voter a wrong number of seats.

---

### Impact Explanation

`localSortitionNumSeats` is called on every non-persistent vote and certificate verification path:

- `implVerifyVote` in `WFALS.hs` (lines 375–390) calls it to determine `numSeats` for an incoming non-persistent vote; if `numSeats == 0` the vote is rejected, otherwise it is accepted with that seat count as voting weight.
- `implVerifyCert` in `WFALS.hs` (lines 528–546) calls it for every non-persistent voter in a certificate. [6](#0-5) [7](#0-6) 

An incorrect seat count means:

- **Inflated seats**: a voter is accepted with more voting power than their stake warrants, bypassing the Peras voting authorization check. A voter who should receive `k` seats receives `k+1` or more, contributing excess weight toward a quorum.
- **Deflated seats**: a voter whose correct seat count is `>= 1` is computed as `0`, causing `ZeroNonPersistentSeats` rejection of a legitimately eligible voter.

Both directions corrupt the Peras quorum calculation and break the security guarantees of the wFA^LS committee selection scheme.

---

### Likelihood Explanation

`lambda = numNonPersistentVoters * voterStake / totalNonPersistentStake`. With a committee of 10 non-persistent voters and a voter holding 15% of non-persistent stake, `lambda = 1.5 > ln(3) ≈ 1.099`. This is a routine scenario for any moderately large stake pool participating as a non-persistent committee member. The threshold is crossed whenever a single voter holds more than `ln(3) / numNonPersistentVoters` of the non-persistent stake, which for a 10-member committee is ~11%. No special adversarial capability is required; any eligible non-persistent voter with sufficient stake triggers the incorrect path on every election they participate in.

---

### Recommendation

Replace the hardcoded `3` with the mathematically correct value `exp lambda`:

```haskell
expectedSeats =
  fromMaybe 0 $
    taylorExpCmpFirstNonLower
      (exp lambda)   -- correct: e^{|x|} = e^lambda since x = -lambda
      orders
      (-lambda)
```

This matches the contract stated in the `taylorExpCmpFirstNonLower` documentation and is consistent with how `checkLeaderNatValue` in the ledger correctly uses `e^{sigma * |c|}` as its bound for the Praos leader check.

---

### Proof of Concept

**Parameters**: `numNonPersistentVoters = 10`, `voterStake / totalNonPersistentStake = 0.20`, giving `lambda = 2.0`.

- Correct `boundX = e^2.0 ≈ 7.389`
- Actual `boundX = 3`
- Ratio: `3 / 7.389 ≈ 0.406` — the error bound is underestimated by ~59%

At iteration `n`, `errorTerm_correct = |err_n| * 7.389` vs `errorTerm_used = |err_n| * 3`. The used error term is less than half the correct one. The `decideOne` loop will declare comparisons as "certain" far earlier than warranted. For a VRF output `v` where `orders[i]` is within the true uncertainty band around `e^{-2.0} ≈ 0.1353`, the function returns index `i` (granting `i` seats) when the correct answer may be `i-1` or `i+1`.

Concretely: a non-persistent voter with `lambda = 2.0` and a VRF output placing `orders[1]` within `[e^{-2} - errorTerm_correct, e^{-2} + errorTerm_correct]` but outside `[e^{-2} - errorTerm_used, e^{-2} + errorTerm_used]` will receive 1 seat under the incorrect formula when the correct answer is 0 (or vice versa). Since `implVerifyVote` and `implVerifyCert` both use the same `localSortitionNumSeats`, a vote claiming 1 seat will pass verification even though the correct Poisson threshold would reject it, constituting unauthorized vote acceptance in the Peras protocol.

```haskell
-- IMPORTANT: boundX must be e^{|x|} for correct error bounds (see taylorExpCmp).
taylorExpCmpFirstNonLower ::
  forall a.
  RealFrac a =>
  -- | boundX = e^{|x|} for correct error estimation
  a ->
  -- | list of cmp thresholds (checked in order)
  [a] ->
  -- | x in e^x
  a ->
  Maybe Int
taylorExpCmpFirstNonLower boundX cmps x =
  goList 1000 0 x 1 1 0 cmps
 where
  -- Traverse the list of cmps, advancing the Taylor state as needed while
  -- checking if the current cmp is ABOVE or BELOW. If ABOVE, return the index.
  goList ::
    Int -> -- maxN
    Int -> -- n
    a -> -- err
    a -> -- acc
    a -> -- divisor
    Int -> -- current index
    [a] -> -- remaining cmps
    Maybe Int
  goList _ _ _ _ _ _ [] = Nothing
  goList maxN n err acc divisor i (cmp : rest) =
    case decideOne maxN n err acc divisor cmp of
      Stop ->
        Just i
      Below n' err' acc' divisor' ->
        goList maxN n' err' acc' divisor' (i + 1) rest

  -- Decide current cmp by advancing the shared Taylor state as needed.
  -- If BELOW is established, returns the *advanced* state to continue with.
  -- If ABOVE is established or maxN reached, returns Stop.
  decideOne ::
    Int -> -- maxN
    Int -> -- n
    a -> -- err
    a -> -- acc
    a -> -- divisor
    a -> -- cmp
    Step a
  decideOne maxN n err acc divisor cmp
    | maxN == n = Stop
    | cmp >= acc' + errorTerm = Stop
    | cmp < acc' - errorTerm = Below (n + 1) err' acc' divisor'
    | otherwise = decideOne maxN (n + 1) err' acc' divisor' cmp
   where
    divisor' = divisor + 1
    nextX = err
    acc' = acc + nextX
    err' = (err * x) / divisor'
    errorTerm = abs (err' * boundX)
```
