### Title
Unprotected Public Initializer on `OmniBridgeWormhole` Proxy Allows Attacker to Seize Admin Role and Forge Transfer Signatures — (`evm/src/omni-bridge/contracts/OmniBridge.sol` / `OmniBridgeWormhole.sol`)

---

### Summary

`OmniBridge.initialize()` is declared `public initializer`. When `OmniBridgeWormhole` is deployed as a proxy, this function remains publicly callable by any address before the legitimate deployer calls `initializeWormhole()`. An attacker who calls `initialize()` first becomes `DEFAULT_ADMIN_ROLE` holder and sets `nearBridgeDerivedAddress` to an address they control, enabling them to forge the ECDSA signatures that gate both `finTransfer()` (token minting) and `deployToken()` (token registry).

---

### Finding Description

`OmniBridge.initialize()` carries the `public` visibility and the OpenZeppelin `initializer` modifier: [1](#0-0) 

The `initializer` modifier allows the function to execute exactly once on a given proxy's storage slot. There is no caller restriction — no `onlyOwner`, no `onlyRole`, no `msg.sender == deployer` check.

`OmniBridgeWormhole` inherits `OmniBridge` and declares its own separate initializer: [2](#0-1) 

Both `initializeWormhole()` and `initialize()` carry the `initializer` modifier. Because OpenZeppelin's `initializer` modifier sets `_initialized = 1` and `_initializing = true` on the first top-level call, a nested call from `initializeWormhole()` into `initialize()` (where `isTopLevelCall = false` and `_initialized` is already `1`) fails the guard condition and reverts. This means the only callable path to initialize the proxy's storage is `initialize()` directly — which is `public` and unrestricted.

The critical state written by `initialize()` is: [3](#0-2) 

- `nearBridgeDerivedAddress` — the address whose ECDSA signature is required by both `finTransfer()` and `deployToken()`.
- `DEFAULT_ADMIN_ROLE` — granted to `_msgSender()`, giving full administrative control.

`finTransfer()` and `deployToken()` both verify: [4](#0-3) [5](#0-4) 

If an attacker controls `nearBridgeDerivedAddress`, they can produce valid signatures for arbitrary `finTransfer` payloads, minting unlimited bridge tokens to any recipient.

---

### Impact Explanation

An attacker who calls `initialize()` before the deployer:

1. Becomes `DEFAULT_ADMIN_ROLE` holder — can call `upgradeToken`, `setNearBridgeDerivedAddress`, `addCustomToken`, `pause`, etc.
2. Sets `nearBridgeDerivedAddress` to a key they control.
3. Can call `finTransfer()` with a self-signed payload, minting arbitrary amounts of any `isBridgeToken` ERC-20 to any address.
4. Can call `deployToken()` with a self-signed metadata payload, registering malicious token mappings.
5. Blocks the legitimate deployer from ever calling `initializeWormhole()` (the `initializer` guard is already consumed).

This constitutes unauthorized minting of bridged funds and a complete authorization bypass of the bridge's signing authority.

---

### Likelihood Explanation

The proxy must be deployed in a two-step process (deploy implementation → deploy proxy → call initializer) for the window to exist. If the proxy is deployed without atomic init data (i.e., `ERC1967Proxy` constructed with empty `_data`), the window is open for any block until the deployer's initialization transaction is mined. A mempool observer can front-run this transaction. The `OmniBridge` constructor correctly calls `_disableInitializers()` on the implementation: [6](#0-5) 

But this only protects the implementation contract's own storage — the proxy's storage remains unprotected until `initialize()` is called on it.

---

### Recommendation

1. Change `OmniBridge.initialize()` visibility from `public` to `internal`, or rename it and mark it `onlyInitializing` so it can only be invoked from within another `initializer`-guarded function.
2. Ensure `OmniBridgeWormhole` (and any future subclass) deploys its proxy atomically with `initializeWormhole()` call data passed to the `ERC1967Proxy` constructor, leaving no uninitialized window.
3. If `OmniBridge` must remain deployable standalone, introduce a separate `internal` `_initialize()` helper with `onlyInitializing` modifier, called by both the public `initialize()` and `initializeWormhole()`.

---

// Attacker script (runs before deployer's initializeWormhole tx is mined)

// 1. Deployer broadcasts: new ERC1967Proxy(wormholeImpl, "")  ← no init data
// 2. Attacker observes mempool, front-runs with:

OmniBridge(proxyAddress).initialize(
    address(0),          // tokenImplementationAddress (can be set later via admin)
    attackerECDSAAddr,   // nearBridgeDerivedAddress  ← attacker controls this key
    chainId
);
// Attacker is now DEFAULT_ADMIN_ROLE; nearBridgeDerivedAddress = attackerECDSAAddr

// 3. Deployer's initializeWormhole() reverts (initializer already consumed)

// 4. Attacker signs a finTransfer payload with attackerECDSAKey:

    originChain: ...,
    originNonce: 1,
    tokenAddress: victimBridgeToken,
    amount: 1_000_000e18,
    recipient: attacker,
    feeRecipient: "",
    message: ""
});
bytes memory sig = sign(attackerECDSAKey, keccak256(borshEncode(payload)));

OmniBridge(proxyAddress).finTransfer(sig, payload);
// → mints 1,000,000 tokens to attacker

    function finTransfer(
        bytes calldata signatureData,
        BridgeTypes.TransferMessagePayload calldata payload
    ) external payable whenNotPaused(PAUSED_FIN_TRANSFER) {
        if (completedTransfers[payload.destinationNonce]) {
            revert NonceAlreadyUsed(payload.destinationNonce);
        }

        completedTransfers[payload.destinationNonce] = true;

        bytes memory borshEncoded = bytes.concat(
            bytes1(uint8(BridgeTypes.PayloadType.TransferMessage)),
            Borsh.encodeUint64(payload.destinationNonce),
            bytes1(payload.originChain),
            Borsh.encodeUint64(payload.originNonce),
            bytes1(omniBridgeChainId),
            Borsh.encodeAddress(payload.tokenAddress),
            Borsh.encodeUint128(payload.amount),
            bytes1(omniBridgeChainId),
            Borsh.encodeAddress(payload.recipient),
            bytes(payload.feeRecipient).length == 0 // None or Some(String) in rust
                ? bytes("\x00")
                : bytes.concat(
                    bytes("\x01"),
                    Borsh.encodeString(payload.feeRecipient)
                ),
            bytes(payload.message).length == 0
                ? bytes("")
                : Borsh.encodeBytes(payload.message)
        );
        bytes32 hashed = keccak256(borshEncoded);

        if (ECDSA.recover(hashed, signatureData) != nearBridgeDerivedAddress) {
            revert InvalidSignature();
        }
