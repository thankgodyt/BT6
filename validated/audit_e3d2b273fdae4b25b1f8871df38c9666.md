### Title
Incorrect `boundX` Constant in `taylorExpCmpFirstNonLower` Causes Unreliable Poisson Seat-Count Comparison in Local Sortition — (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/LS.hs`)

### Summary

In `localSortitionNumSeats`, the function `taylorExpCmpFirstNonLower` is called with a hardcoded `boundX = 3`. The function's own contract states that `boundX` **must** equal `e^{|x|}` for the error bound to be valid. The `x` argument is `-lambda`, so the required value is `e^lambda`. For any voter whose `lambda > ln(3) ≈ 1.099`, the hardcoded `3` is strictly less than the required `e^lambda`, making the Taylor-series error bound too small. This causes the comparison to produce incorrect results — either granting a non-persistent committee member more Peras voting seats than the Poisson distribution entitles them to (false positive / eligibility bypass), or fewer (false negative / liveness failure). The code itself acknowledges the value is unvalidated via an open TODO.

`errorTerm = abs(err' * boundX)` is the Lagrange remainder bound. For it to be a valid upper bound on the tail of the series, `boundX` must satisfy `boundX >= e^{|x|}`. Here `x = -lambda`, so the required value is `e^lambda`.
