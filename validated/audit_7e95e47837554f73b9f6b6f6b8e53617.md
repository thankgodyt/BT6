### Title
Uncapped Caller-Supplied `gas_fee` in Refund Requests Allows Griefing of Depositors - (File: contracts/satoshi-bridge/src/refund.rs)

### Summary

`request_refund_callback` accepts a caller-supplied `gas_fee` and enforces only that it is strictly less than the deposit amount. There is no upper-bound cap analogous to the `config.max_btc_gas_fee` guard that protects the withdrawal path. Any unprivileged NEAR account that observes a Bitcoin deposit can race the depositor to call `request_refund` with `gas_fee = amount − 1`, locking the depositor's BTC in a refund request that pays 1 satoshi back to the user and burns the rest as miner fees. The DAO must manually reject the request within `unsafe_refund_timelock_sec` (14 days) to prevent execution.

### Finding Description

In `request_refund_callback`, the resolved gas fee is validated only against the deposit amount: [1](#0-0) 

```rust
let resolved_gas_fee = gas_fee.unwrap_or_else(|| self.get_refund_gas_fee());
require!(
    resolved_gas_fee < amount,
    "Gas fee must be less than deposit amount"
);
```

No maximum is enforced. By contrast, the withdrawal PSBT validation enforces a hard ceiling: [2](#0-1) 

```rust
require!(
    gas_fee >= config.min_btc_gas_fee && gas_fee <= config.max_btc_gas_fee,
    ...
);
```

The refund path has no equivalent `gas_fee <= config.max_btc_gas_fee` (or any other cap). The stored `gas_fee` is later used directly to compute the amount returned to the depositor: [3](#0-2) 

```rust
let refund_amount = refund_request
    .amount
    .checked_sub(refund_request.gas_fee)
    .expect("Deposit amount too small to cover gas fee");
require!(refund_amount > 0, "Refund amount is zero after gas fee");
```

`request_refund` is publicly callable by any NEAR account. The caller supplies `tx_bytes` (the raw deposit transaction), a Merkle inclusion proof, and an optional `gas_fee`. When `deposit_msg.refund_address` is `None` (the common case for users who did not pre-authorize a refund address), the caller also freely chooses `refund_address`. [4](#0-3) 

### Impact Explanation

An attacker who observes a Bitcoin deposit transaction can call `request_refund` before the depositor with `gas_fee = deposit_amount − 1`. The resulting `RefundRequest` is stored on-chain with `refund_amount = 1 satoshi`. After `unsafe_refund_timelock_sec` elapses (14 days by default), `execute_refund` can be called to build and sign a Bitcoin transaction that returns 1 satoshi to the depositor and pays the remainder to Bitcoin miners. The depositor's BTC is effectively destroyed. The DAO must call `internal_reject_refund` within the 14-day window to prevent this; if it fails to act, the loss is permanent and irreversible.

This matches the allowed Medium impact: **attacker-triggered temporary locking of bridged funds** and **harmful smart-contract behavior requiring operator intervention**. [5](#0-4) 

### Likelihood Explanation

Bitcoin deposit transactions are publicly visible on-chain. Any NEAR account can submit a valid Merkle proof for any confirmed deposit. The attacker only needs to pay a small NEAR storage deposit (`required_balance_for_request_refund`) and submit the call before the depositor. The 14-day `unsafe_refund_timelock_sec` gives the DAO time to reject, but the window is long and the DAO may not monitor every refund request in time. [6](#0-5) 

### Recommendation

Add a maximum gas fee check in `request_refund_callback` mirroring the withdrawal path:

```rust
require!(
    resolved_gas_fee <= config.max_btc_gas_fee,
    "Gas fee exceeds maximum allowed"
);
```

Alternatively, ignore the caller-supplied `gas_fee` entirely and always use `self.get_refund_gas_fee()`, which is the protocol-determined safe default. [1](#0-0) 

### Proof of Concept

1. Alice sends 1 BTC (100,000,000 satoshis) to the bridge deposit address with `deposit_msg.refund_address = None`.
2. Bob observes the confirmed Bitcoin transaction and obtains the Merkle proof.
3. Bob calls `request_refund(deposit_msg, refund_address=alice_btc_addr, tx_bytes, vout, proof, gas_fee=99_999_999)` on NEAR, attaching the required storage deposit.
4. `request_refund_callback` passes the only check (`99_999_999 < 100_000_000`) and stores a `RefundRequest` with `gas_fee = 99_999_999` and `amount = 100_000_000`.
5. The DAO must call `internal_reject_refund` within 14 days. If it does not, Bob (or anyone) calls `execute_refund` after the timelock.
6. `refund_execution_inputs` computes `refund_amount = 100_000_000 − 99_999_999 = 1 satoshi`.
7. A Bitcoin transaction is constructed paying 1 satoshi to Alice and 99,999,999 satoshis to miners. Alice loses essentially all her BTC. [7](#0-6)

    #[allow(clippy::too_many_arguments)]
    pub(crate) fn internal_request_refund(
        &self,
        deposit_msg: DepositMsg,
        refund_address: String,
        tx_bytes: Base64VecU8,
        vout: usize,
        proof: TxInclusionProof,
        gas_fee: Option<u128>,
    ) -> Promise {
        require!(
            env::attached_deposit() >= self.required_balance_for_request_refund(),
            "Insufficient deposit for storage"
        );
        require!(
            tx_bytes.0.len() <= MAX_REQUEST_REFUND_TX_BYTES,
            "tx_bytes too large for refund request"
        );
        if let Some(msg_refund_address) = &deposit_msg.refund_address {
            require!(
                msg_refund_address == &refund_address,
                "refund_address does not match deposit_msg.refund_address"
            );
        }

        let transaction =
            crate::WrappedTransaction::decode(&tx_bytes.0, &self.internal_config().chain)
                .expect("Deserialization tx_bytes failed");
        let tx_id = transaction.compute_txid().to_string();

        let config = self.internal_config();
        let deposit_amount = u128::from(transaction.output()[vout].value.to_sat());
        let confirmations = self.get_confirmations(config, deposit_amount);

        self.verify_transaction_inclusion_promise(
            config.btc_light_client_account_id.clone(),
            tx_id,
            proof.tx_block_blockhash,
            proof.tx_index,
            proof.merkle_proof,
            Some((proof.coinbase_tx_id, proof.coinbase_merkle_proof)),
            confirmations,
        )
        .then(
            Self::ext(env::current_account_id())
                .with_static_gas(GAS_FOR_REQUEST_REFUND_CALLBACK)
                .request_refund_callback(deposit_msg, refund_address, tx_bytes, vout, gas_fee),
        )
    }

    /// Reject a pending refund request.
    pub(crate) fn internal_reject_refund(&mut self, utxo_storage_key: String) {
        require!(
            self.data_mut()
                .refund_requests
                .remove(&utxo_storage_key)
                .is_some(),
            "Refund request not found"
        );
        Event::RefundRejected { utxo_storage_key }.emit();
    }

    /// Parse the original deposit transaction and compute the refund economics.
    pub(crate) fn refund_execution_inputs(
        &self,
        refund_request: &RefundRequest,
    ) -> RefundExecutionInputs {
        let config = self.internal_config();
        let transaction =
            crate::WrappedTransaction::decode(&refund_request.tx_bytes.0, &config.chain)
                .expect("Deserialization tx_bytes failed");
        let txid = transaction.compute_txid();
        let outpoint = OutPoint {
            txid,
            vout: u32::try_from(refund_request.vout)
                .unwrap_or_else(|_| env::panic_str("vout overflow")),
        };
        let deposit_output = transaction.output()[refund_request.vout].clone();

        let refund_amount = refund_request
            .amount
            .checked_sub(refund_request.gas_fee)
            .expect("Deposit amount too small to cover gas fee");
        require!(refund_amount > 0, "Refund amount is zero after gas fee");

        RefundExecutionInputs {
            outpoint,
            deposit_output,
            refund_amount,
        }
    }
