### Title
Missing Quorum Sufficiency Check in `implVerifyCert` Allows Sub-Quorum Certificate Acceptance - (`File: ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/WFALS.hs`)

### Summary

`implVerifyCert` in the WFALS committee implementation validates each voter's individual eligibility and the aggregate cryptographic signature, but never checks that the voters' collective stake meets the quorum threshold. A malicious committee member can craft a `WFALSCert` containing only their own valid vote — far below quorum — and have it accepted as a valid certificate by any receiving node.

### Finding Description

The `WFALSCert` certificate type carries a non-empty map of voters (`NE (Map SeatIndex (Maybe (VRFOutput crypto)))`), an election ID, a vote candidate, and an aggregate BLS signature. [1](#0-0) 

`implVerifyCert` performs three checks:

1. Each voter's seat index is within bounds and they are a valid persistent or non-persistent committee member.
2. The aggregate BLS signature verifies against the aggregated verification keys of all listed voters.
3. VRF outputs for non-persistent voters are valid. [2](#0-1) 

**What is absent**: there is no check that the total stake represented by the listed voters exceeds the quorum threshold (`perasQuorumStakeThreshold + perasQuorumStakeThresholdSafetyMargin`). The function simply returns `Right members` after the cryptographic checks pass.

Compare this to the quorum check that *is* performed when forging a certificate locally: [3](#0-2) [4](#0-3) 

The quorum gate exists only on the *forging* path, not on the *verification* path.

### Impact Explanation

A `WFALSCert` accepted by `verifyCert` is used to boost a block in Peras chain selection. The boost weight (`vpcCertBoost`) is a fixed protocol parameter applied unconditionally once the certificate is accepted. [5](#0-4) 

If a sub-quorum certificate is accepted, an honest node will apply the full Peras boost to a block that was never actually endorsed by a quorum of stake. This directly corrupts chain selection: the node will prefer a boosted non-canonical chain over the honest canonical chain, constituting a **bypass of Peras voting/certificate checks enabling unauthorized certificate acceptance and incorrect chain selection**.

### Likelihood Explanation

Any participant holding at least one valid committee seat (persistent or non-persistent) can execute this attack. They need only:

- Their own valid seat index (assigned deterministically by the wFA scheme).
- Their own BLS vote signing key (a normal operational key).
- For non-persistent seats: a valid VRF output (computed locally).

A single-voter `WFALSCert` is cryptographically indistinguishable from a quorum certificate under `implVerifyCert`. No stake majority, no key compromise, and no external dependency is required. Any stake pool operator assigned a committee seat in a given epoch can mount this attack against any peer that calls `verifyCert`.

### Recommendation

Add a quorum sufficiency check inside `implVerifyCert`, after collecting the eligibility witnesses, by summing the stake of all returned members and verifying it exceeds the threshold:

```haskell
-- After collecting `members`:
let totalStake = foldMap (eligiblePartyVoteWeight committee) members
unless (stakeAboveThreshold perasParams totalStake) $
  Left QuorumNotReached
```

The `stakeAboveThreshold` predicate already exists and is used on the forging path. [3](#0-2) 

### Proof of Concept

**Setup**: Epoch with committee of 100 pools; quorum threshold = 75% of total stake. Attacker controls pool `P` with 0.1% stake (seat index 42, persistent member).

**Step 1 — Craft sub-quorum cert**:
```
voters = NEMap.singleton (SeatIndex 42) Nothing   -- persistent, no VRF needed
aggSig = signVote P.privateKey electionId candidate  -- single-voter aggregate
cert   = WFALSCert electionId candidate voters aggSig
```

**Step 2 — Send to victim node**: Victim calls `verifyCert committee cert`.

**Step 3 — `implVerifyCert` traversal**:
- `getCandidateIfSeatWithinBounds 42 distr` → `Just (P, pubKey, 0.001, ...)`
- `isPersistentMember 42 committee` → `True`
- Aggregate key = `P.pubKey`; `verifyAggregateVoteSignature` → passes (single-voter aggregate)
- No non-persistent voters → VRF check skipped
- Returns `Right [WFALSPersistentMember 42 0.001]`

**Step 4 — Certificate accepted**: Victim node applies full Peras boost to attacker's chosen block. Total stake represented: 0.1% — far below the 75% quorum threshold. No error is raised. [6](#0-5)

```haskell
-- | Verify a certificate attesting the winner of a given election
implVerifyCert ::
  forall crypto.
  ( CryptoSupportsAggregateVoteSigning crypto
  , CryptoSupportsBatchVRFVerification crypto
  ) =>
  VotingCommittee crypto WFALS ->
  Cert crypto WFALS ->
  Either
    (VotingCommitteeError crypto WFALS)
    (NE [EligibilityWitness crypto WFALS])
implVerifyCert committee = \case
  WFALSCert electionId candidate voters aggSig -> do
    -- Traverse the list of voters in ascending seat index order, collecting:
    -- 1. their membership status
    -- 2. their vote verification keys (to verify the aggregate vote signature)
    -- 3. optionally, their VRF verification keys and outputs (to verify the
    --    aggregate VRF output for non-persistent voters, if any)
    (members, voteVerificationKeys, optionalVRFKeysAndOutputs) <-
      fmap nonEmptyUnzip3 . flip traverse (NEMap.toAscList voters) $ \case
        -- Persistent voter
        (seatIndex, Nothing)
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
          , isPersistentMember seatIndex committee -> do
              let voterVoteVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              pure
                ( WFALSPersistentMember
                    seatIndex
                    voterStake
                , voterVoteVerificationKey
                , Nothing
                )
          | otherwise ->
              Left (NotAPersistentMember seatIndex)
        -- Non-persistent voter
        (seatIndex, Just vrfOutput)
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
          , not (isPersistentMember seatIndex committee) -> do
              let voterVoteVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              let voterVRFVerificationKey =
                    getVRFVerificationKey (Proxy @crypto) voterPublicKey
              let numSeats =
                    localSortitionNumSeats
                      (nonPersistentCommitteeSize committee)
                      (totalNonPersistentStake committee)
                      voterStake
                      (normalizeVRFOutput vrfOutput)
              case nonZero numSeats of
                Nothing ->
                  Left (ZeroNonPersistentSeats seatIndex)
                Just nonZeroNumSeats ->
                  pure
                    ( WFALSNonPersistentMember
                        seatIndex
                        voterStake
                        vrfOutput
                        nonZeroNumSeats
                    , voterVoteVerificationKey
                    , Just (voterVRFVerificationKey, vrfOutput)
                    )
          | otherwise ->
              Left (NotANonPersistentMember seatIndex)

    -- Verify aggregate signature
    aggVerificationKey <-
      bimap CryptoError id $
        aggregateVoteVerificationKeys
          (Proxy @crypto)
          voteVerificationKeys
    bimap InvalidCertSignature id $
      verifyAggregateVoteSignature
        (Proxy @crypto)
        aggVerificationKey
        electionId
        candidate
        aggSig

    -- Verify VRF outputs for non-persistent voters (if any)
    case catMaybes (NonEmpty.toList optionalVRFKeysAndOutputs) of
      -- No non-persistent voters => no VRF outputs to verify
      [] -> do
        pure ()
      -- Some non-persistent voters => verify their aggregate VRF outputs
      vrfKeysAndOutputs -> do
        let (vrfVerificationKeys, vrfOutputs) =
              munzip
                . NonEmpty.fromList -- safe 'vrfKeysAndOutputs' /= []
                $ vrfKeysAndOutputs
        bimap InvalidCertSignature id $
          batchVerifyVRFOutputs
            vrfVerificationKeys
            ( mkVRFElectionInput
                @crypto
                (epochNonce committee)
                electionId
            )
            vrfOutputs

    -- Return the list of voters attesting the election winner
    pure members
```
