### Title
Relayer Stakes Permanently Frozen After Migration — (`near/omni-bridge/src/migrate.rs`)

### Summary

The `migrate()` function reads `OldState` (which includes `relayers: LookupMap<AccountId, RelayerState>` and `relayer_config: RelayerConfig`) but silently drops both fields without migrating them or providing any withdrawal path. Any NEAR staked by relayers before migration is permanently locked in the contract balance with no accessor.

### Finding Description

`OldState` captures the full pre-migration contract state, including the relayer stake map: [1](#0-0) 

The `migrate()` function constructs the new `Contract` from `old_state` but omits both `relayers` and `relayer_config` entirely: [2](#0-1) 

The new `Contract` struct does not declare a `relayers` field directly — it is injected by the `#[trusted_relayer]` proc-macro: [3](#0-2) 

The `StorageKey` enum retains `_Relayers` (underscore prefix = deprecated/unused), confirming the old relayer storage key is being abandoned: [4](#0-3) 

The macro-injected `relayers` field uses its own internal storage key prefix (not `StorageKey::_Relayers`). After migration, the macro's `relayers` map is empty. All pre-migration relayer entries remain in raw contract storage under the old `_Relayers` prefix but are unreachable by any post-migration method (`resign_trusted_relayer`, `get_relayer_stake`, etc.), because those methods operate on the macro's new empty map.

### Impact Explanation

Any NEAR staked via `apply_for_trusted_relayer` before migration is transferred to the contract account balance. After migration, the `RelayerState` records tracking those stakes are orphaned. No post-migration call path can read or refund them. The NEAR remains in the contract's balance permanently, with no accessor. This is a permanent freezing of relayer-staked NEAR.

### Likelihood Explanation

The precondition is realistic: the relayer staking system was active before this migration (evidenced by the full test suite in `near/omni-tests/src/relayer_staking.rs`), and relayers are required to stake 1,000 NEAR by default: [5](#0-4) 

Any relayer who staked before the migration runs loses their stake with no recourse.

### Recommendation

Before dropping `old_state.relayers`, iterate over all entries and refund each relayer's stake:

```rust
// In migrate(), before constructing Self:
for (account_id, state) in old_state.relayers.iter() {
    Promise::new(account_id).transfer(NearToken::from_yoctonear(state.stake));
}
```

Alternatively, carry `old_state.relayers` into the new contract under the macro's expected storage key, or add a dedicated pre-migration withdrawal window.

### Proof of Concept

1. Deploy the contract and call `set_relayer_config` with `stake_required = 1000 NEAR`.
2. Call `apply_for_trusted_relayer` with 1000 NEAR attached; fast-forward past the waiting period so the relayer becomes active.
3. Verify `get_relayer_stake` returns `Some(1000 NEAR)`.
4. Call `migrate()` (as the contract owner).
5. Call `get_relayer_stake` — returns `None` (macro's new map is empty).
6. Call `resign_trusted_relayer` — panics or returns without refund (relayer not found in new map).
7. Verify the relayer's account balance has not increased; the 1000 NEAR remains locked in the contract balance permanently. [6](#0-5)

    #[rstest]
    #[tokio::test]
    async fn test_resign_relayer(
        #[from(locker_wasm)] locker: Vec<u8>,
        #[from(mock_prover_wasm)] prover: Vec<u8>,
    ) -> anyhow::Result<()> {
        let env = TestEnv::new(locker, prover).await?;

        // Set a short waiting period
        env.bridge_contract
            .call("set_relayer_config")
            .args_json(json!({
                "stake_required": U128(1_000 * 10u128.pow(24)),
                "waiting_period_ns": U64(1_000_000_000),
            }))
            .max_gas()
            .transact()
            .await?
            .into_result()?;

        let applicant = env.create_funded_account("applicant", 2000).await?;

        // Apply
        applicant
            .call(env.bridge_contract.id(), "apply_for_trusted_relayer")
            .deposit(NearToken::from_near(1000))
            .max_gas()
            .transact()
            .await?
            .into_result()?;

        // Wait past activation period
        env.worker.fast_forward(100).await?;

        // Verify relayer is now trusted
        let is_trusted: bool = env
            .bridge_contract
            .view("is_trusted_relayer")
            .args_json(json!({"account_id": applicant.id()}))
            .await?
            .json()?;
        assert!(is_trusted);

        let balance_before_resign = applicant.view_account().await?.balance;

        // Resign
        applicant
            .call(env.bridge_contract.id(), "resign_trusted_relayer")
            .max_gas()
            .transact()
            .await?
            .into_result()?;

        // Verify relayer is no longer trusted
        let is_trusted: bool = env
            .bridge_contract
            .view("is_trusted_relayer")
            .args_json(json!({"account_id": applicant.id()}))
            .await?
            .json()?;
        assert!(!is_trusted);

        // Verify NEAR was returned
        let balance_after_resign = applicant.view_account().await?.balance;
        assert!(balance_after_resign.as_yoctonear() > balance_before_resign.as_yoctonear());

        // Verify stake is removed
        let stake: Option<U128> = env
            .bridge_contract
            .view("get_relayer_stake")
            .args_json(json!({"account_id": applicant.id()}))
            .await?
            .json()?;
        assert!(stake.is_none());

        Ok(())
