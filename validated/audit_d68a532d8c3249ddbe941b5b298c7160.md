### Title
Pause Flag Replacement in `_pause` Silently Clears Existing Flags, Bypassing Emergency Pause — (`evm/src/omni-bridge/contracts/SelectivePausableUpgradable.sol`)

---

### Summary

`SelectivePausableUpgradable._pause` uses direct assignment (`$._pausedFlags = flags`) rather than bitwise OR-assignment (`$._pausedFlags |= flags`). Any call to `pause(X)` after `pauseAll()` replaces the full pause bitmap with only `X`, silently unpausing every operation not represented in `X`. A `DEFAULT_ADMIN_ROLE` holder acting in good faith during an emergency can inadvertently re-enable `initTransfer` and `deployToken` while believing those operations remain paused.

---

### Finding Description

**Root cause — `_pause` overwrites instead of accumulates:** [1](#0-0) 

```solidity
function _pause(uint256 flags) internal virtual {
    SelectivePausableStorage storage $ = _getSelectivePausableStorage();
    $._pausedFlags = flags;          // ← assignment, not |=
    emit Paused(_msgSender(), $._pausedFlags);
}
```

**Flag constants:** [2](#0-1) 

```
PAUSED_INIT_TRANSFER = 1 << 0  = 0x1
PAUSED_FIN_TRANSFER  = 1 << 1  = 0x2
PAUSED_DEPLOY_TOKEN  = 1 << 2  = 0x4
```

**`pauseAll` sets all three bits (0x7):** [3](#0-2) 

**`pause(flags)` then replaces the entire bitmap:** [4](#0-3) 

**Exact state transition:**

| Step | Call | `_pausedFlags` after |
|---|---|---|
| 1 | `pauseAll()` | `0x7` (all paused) |
| 2 | `pause(PAUSED_FIN_TRANSFER)` | `0x2` (only finTransfer paused) |

After step 2, `paused(PAUSED_INIT_TRANSFER)` returns `false` and `paused(PAUSED_DEPLOY_TOKEN)` returns `false`.

**Guards on the affected functions:** [5](#0-4) [6](#0-5) 

Both `initTransfer` and `deployToken` gate solely on `whenNotPaused(flag)`, which reads `($._pausedFlags & flag) != 0`. Once the flag is cleared, the modifier passes unconditionally. [7](#0-6) 

---

### Impact Explanation

During an active emergency pause window, `initTransfer` becomes callable, allowing any user to lock tokens into the bridge and emit cross-chain transfer events. If the emergency was triggered precisely because the bridge's finalization path is compromised (e.g., a signature-verification bypass or double-spend vector on the NEAR side), users locking funds during this window face permanent loss or double-spend exposure. `deployToken` being re-enabled simultaneously allows unauthorized token deployments that could pollute the token registry. This is a concrete **pause bypass** enabling unauthorized bridge and token-deployment actions — squarely within the Critical impact scope.

---

### Likelihood Explanation

The scenario does **not** require admin compromise or malicious intent. It requires only that a `DEFAULT_ADMIN_ROLE` holder calls `pause(PAUSED_FIN_TRANSFER)` — a semantically reasonable action ("ensure finTransfer is paused") — after `PAUSABLE_ADMIN_ROLE` has already called `pauseAll()`. The function name `pause` implies additive semantics; nothing in the interface signals that it replaces the entire bitmap. There is no `unpause()` function, so operators must use `pause(0)` to clear flags, making the replacement semantics non-obvious. This is a realistic operational mistake under time pressure during an incident.

---

### Recommendation

Change `_pause` to accumulate flags rather than replace them:

```solidity
function _pause(uint256 flags) internal virtual {
    SelectivePausableStorage storage $ = _getSelectivePausableStorage();
    $._pausedFlags |= flags;          // accumulate, never clear
    emit Paused(_msgSender(), $._pausedFlags);
}
```

Introduce a separate `_unpause(uint256 flags)` that clears specific bits:

```solidity
function _unpause(uint256 flags) internal virtual {
    SelectivePausableStorage storage $ = _getSelectivePausableStorage();
    $._pausedFlags &= ~flags;
    emit Unpaused(_msgSender(), $._pausedFlags);
}
```

Expose `unpause(uint256 flags)` gated on `DEFAULT_ADMIN_ROLE` and update `OmniBridge` accordingly.

### Proof of Concept

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import "forge-std/Test.sol";
import "../contracts/OmniBridge.sol";

contract PauseFlagClearTest is Test {
    OmniBridge bridge;
    address admin    = address(0xA1);
    address pauseAdmin = address(0xA2);
    address user     = address(0xB1);

    function setUp() public {
        bridge = new OmniBridge();
        // initialize with admin as deployer
        vm.prank(admin);
        bridge.initialize(address(1), address(2), 1);
        // grant PAUSABLE_ADMIN_ROLE to pauseAdmin
        vm.prank(admin);
        bridge.grantRole(bridge.PAUSABLE_ADMIN_ROLE(), pauseAdmin);
    }

    function testPauseFlagCleared() public {
        // Step 1: emergency — pause everything
        vm.prank(pauseAdmin);
        bridge.pauseAll();
        assertTrue(bridge.paused(1 << 0), "INIT_TRANSFER should be paused");
        assertTrue(bridge.paused(1 << 2), "DEPLOY_TOKEN should be paused");

        // Step 2: admin intends to keep finTransfer paused
        vm.prank(admin);
        bridge.pause(1 << 1);   // PAUSED_FIN_TRANSFER only

        // Bug: INIT_TRANSFER and DEPLOY_TOKEN are now unpaused
        assertFalse(bridge.paused(1 << 0), "INIT_TRANSFER silently unpaused!");
        assertFalse(bridge.paused(1 << 2), "DEPLOY_TOKEN silently unpaused!");

        // Step 3: user can now call initTransfer during the emergency window
        // (call will revert for other reasons like token setup, but the pause
        //  gate itself no longer blocks it — confirmed by paused() == false)
    }
}
```
