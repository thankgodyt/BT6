### Title
Missing Callback Rollback in `claim_lost_found` Causes Permanent Loss of User Funds — (File: `contracts/satoshi-bridge/src/api/bridge.rs`)

---

### Summary

The `claim_lost_found` function removes a user's entry from the `lost_found` map **before** the cross-contract nBTC transfer completes, with no failure callback to restore the state. If the nBTC transfer fails, the user's funds are permanently erased from bridge accounting and never delivered.

---

### Finding Description

In `claim_lost_found`:

```rust
pub fn claim_lost_found(&mut self) -> Promise {
    assert_one_yocto();
    let account_id = env::predecessor_account_id();
    let amount = self
        .data_mut()
        .lost_found
        .remove(&account_id)          // ← state mutated here, committed immediately
        .expect("The account does not have lostfound");
    self.internal_transfer_nbtc(&account_id, amount)  // ← XCC, no failure callback
}
