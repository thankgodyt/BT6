### Title
`localSortitionNumSeats` does not cap granted seats at `numNonPersistentVoters`, enabling inflated non-persistent vote weight in Peras committee elections — (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/LS.hs`)

---

### Summary

`localSortitionNumSeats` computes the number of non-persistent seats a voter receives via local sortition using a Poisson distribution approximation with a **hardcoded Taylor-expansion limit of 3**. The result is returned directly as `LocalSortitionNumSeats (fromIntegral expectedSeats)` with no cap against `numNonPersistentVoters` — the actual total non-persistent committee size. When `numNonPersistentVoters < 3`, a voter's `expectedSeats` can exceed the total non-persistent committee size, inflating their vote weight. Both `implVerifyVote` and `implVerifyCert` in `WFALS.hs` call `localSortitionNumSeats` to determine eligibility and store the uncapped seat count in the `EligibilityWitness`, which is then used by `implEligiblePartyVoteWeight` to compute voting power. This is the direct analog of the ERC1155 partial-fill bug: the ERC721 path had `min(numItemsToFill, numIdsFound)`, but the ERC1155 path was missing `min(numItemsToFill, erc1155.balanceOf(pair))`; here, the persistent-seat path has `assert (numPersistentVoters <= unTargetCommitteeSize totalSeats)` but the non-persistent path is missing `min(expectedSeats, numNonPersistentVoters)`.

### Finding Description

In `LS.hs`, `localSortitionNumSeats` computes:

```haskell
expectedSeats :: Int
expectedSeats =
  fromMaybe 0 $
    taylorExpCmpFirstNonLower
      3          -- hardcoded upper bound on Taylor iterations
      orders
      (-lambda)
``` [1](#0-0) 

The function returns `LocalSortitionNumSeats (fromIntegral expectedSeats)` with no check against `numNonPersistentVoters`. [2](#0-1) 

`lambda` is bounded by `numNonPersistentVoters` (achieved when the voter holds all non-persistent stake), but individual Poisson realizations can exceed `lambda`. With the Taylor limit of 3, `expectedSeats` can be 1, 2, or 3 regardless of `numNonPersistentVoters`. When `numNonPersistentVoters = 1` or `2`, `expectedSeats` can exceed the total non-persistent committee size.
