## Tracing `perasRoundNoToSlot`

The function is a `Qry` composed of three sequential `qryFromExpr` calls: [1](#0-0) 

`runQuery` tries each era in order, and critically, **all expressions in a single `Qry` are evaluated in the same era** — if any expression fails in era N, the entire query retries from scratch in era N+1: [2](#0-1) 

## The `ERelToAbsSlot` Guard Is the Decisive Check

The second expression in `perasRoundNoToSlot` is `ERelToAbsSlot`, which has this guard: [3](#0-2) 

Since `TimeInSlot 0` is passed, the condition reduces to `absSlot <= boundSlot end`. This means:

- If round R's computed start slot (using era N's round length) **exceeds** era N's end slot → `ERelToAbsSlot` **fails** in era N → `runQuery` retries in era N+1.
- If round R's computed start slot is **within** era N's bounds → era N succeeds and returns the correct slot.

There is no path where era N succeeds for `perasRoundNoToSlot R` while round R's true start slot is in era N+1. The guard structurally prevents it.

runQuery ::
  forall a xs.
  HasCallStack =>
  Qry a -> Summary xs -> Either PastHorizonException a
runQuery qry (Summary summary) = go summary
 where
  go :: NonEmpty xs' EraSummary -> Either PastHorizonException a
  go (NonEmptyOne era) = tryEra era qry
  go (NonEmptyCons era eras) = case tryEra era qry of
    Left _ -> go eras
    Right x -> Right x

  tryEra :: forall b. EraSummary -> Qry b -> Either PastHorizonException b
  tryEra era = \case
    QPure x -> Right x
    QExpr e k ->
      case evalExprInEra era e of
        Just x ->
          tryEra era (k x)
        Nothing ->
          Left $ PastHorizon callStack (Some e) (toList summary)
