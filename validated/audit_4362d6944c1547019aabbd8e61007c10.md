### Title
Solana `deploy_token` Instruction Bypasses Pause Mechanism — (`solana/programs/bridge_token_factory/src/lib.rs`)

---

### Summary

The Solana `bridge_token_factory` program implements a selective pause mechanism via a bitmask stored in `Config.paused`. When the `pausable_admin` or `admin` calls the `pause` instruction, it sets `ALL_PAUSED = INIT_TRANSFER_PAUSED | FINALIZE_TRANSFER_PAUSED`. However, the `deploy_token` instruction contains no pause check, so it remains callable even when the bridge is fully paused. This is inconsistent with the EVM implementation, which explicitly gates `deployToken` behind `whenNotPaused(PAUSED_DEPLOY_TOKEN)` and includes `PAUSED_DEPLOY_TOKEN` in its `pauseAll()` bitmask.

---

### Finding Description

The `constants.rs` file defines the pause bitmask constants:

```
INIT_TRANSFER_PAUSED  = 1 << 0
FINALIZE_TRANSFER_PAUSED = 1 << 1
ALL_PAUSED = INIT_TRANSFER_PAUSED | FINALIZE_TRANSFER_PAUSED
``` [1](#0-0) 

The `pause` instruction sets `config.paused = ALL_PAUSED`: [2](#0-1) 

`init_transfer`, `init_transfer_sol`, `finalize_transfer`, and `finalize_transfer_sol` all correctly check the pause flag before proceeding: [3](#0-2) [4](#0-3) 

However, `deploy_token` performs no pause check whatsoever: [5](#0-4) 

There is no `DEPLOY_TOKEN_PAUSED` bit defined in `constants.rs`, and `ALL_PAUSED` does not cover token deployment. By contrast, the EVM `OmniBridge.sol` defines `PAUSED_DEPLOY_TOKEN = 1 << 2`, includes it in `pauseAll()`, and gates `deployToken` with `whenNotPaused(PAUSED_DEPLOY_TOKEN)`: [6](#0-5) [7](#0-6) [8](#0-7) 

---

### Impact Explanation

When the `pausable_admin` pauses the Solana bridge in response to a security incident, the intent is to halt all externally-triggered bridge operations. Because `deploy_token` is not gated by the pause flag, any party holding a valid MPC-signed `DeployTokenPayload` (e.g., a relayer who obtained the signature from the NEAR side before or after the pause) can still call `deploy_token` on Solana. This constitutes a **pause bypass** that allows execution of token-deployer actions the admin explicitly intended to block. If the pause was triggered because a flaw in the token deployment path was discovered, the vulnerable path remains open on Solana while it is correctly closed on EVM.

---

### Likelihood Explanation

A relayer who has received a valid signed `DeployTokenPayload` from the NEAR bridge (via `log_metadata` → MPC signing) can submit it to the Solana program at any time, including after the Solana bridge is paused. The NEAR-side `log_metadata` is itself pause-gated (`#[pause(except(roles(Role::DAO)))]`), but signatures obtained before the pause remain valid indefinitely. The attacker-controlled entry path is the public `deploy_token` instruction, callable by any Solana account. [9](#0-8) 

---

### Recommendation

1. Add a `DEPLOY_TOKEN_PAUSED: u8 = 1 << 2` constant to `constants.rs`.
2. Update `ALL_PAUSED` to `INIT_TRANSFER_PAUSED | FINALIZE_TRANSFER_PAUSED | DEPLOY_TOKEN_PAUSED`.
3. Add a pause check at the top of the `deploy_token` handler in `lib.rs`, mirroring the pattern used for `init_transfer`:

```rust
pub fn deploy_token(ctx: Context<DeployToken>, data: SignedPayload<DeployTokenPayload>) -> Result<()> {
    require!(
        ctx.accounts.common.config.paused & DEPLOY_TOKEN_PAUSED == 0,
        error::ErrorCode::Paused
    );
    // ...
}
``` [1](#0-0) 

---

### Proof of Concept

1. `pausable_admin` calls `pause` on the Solana bridge; `config.paused` is set to `ALL_PAUSED = 0x03`.
2. Admin's intent: no bridge operations should proceed on Solana.
3. A relayer holds a valid MPC-signed `DeployTokenPayload` (obtained from the NEAR bridge's `log_metadata` → MPC signing flow, either before or after the pause).
4. The relayer calls `deploy_token` on the Solana program with the signed payload.
5. `deploy_token` verifies the MPC signature and calls `initialize_token_metadata` — no pause check is ever evaluated.
6. A new bridged token is deployed on Solana despite the bridge being in a fully paused state, bypassing the administrator's emergency halt. [5](#0-4)
