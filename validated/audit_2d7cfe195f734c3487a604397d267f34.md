### Title
Missing Quorum Threshold Enforcement in Peras Certificate Verification — (`File: ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/WFALS.hs`)

### Summary

The `implVerifyCert` function in both `WFALS.hs` and `EveryoneVotes.hs` verifies individual voter eligibility and the aggregate cryptographic signature, but never checks that the total stake of the certificate's voters meets the quorum threshold. This is the direct analog to `amountOutMinimum = 0`: the minimum bound (quorum) is simply absent from the verification path. Any committee-eligible pool can craft a certificate backed by a single vote — far below quorum — and honest nodes will accept it as valid, allowing unauthorized chain-weight boosts.

### Finding Description

**Root cause.** The quorum check lives exclusively in `votesReachQuorum` (called at certificate-forging time) and in the vote-aggregation helpers `updateCandidateVoteState` / `updateLoserVoteState`. Neither `WFALS.implVerifyCert` nor `EveryoneVotes.implVerifyCert` calls `stakeAboveThreshold` or any equivalent check.

`WFALS.implVerifyCert` (lines 494–586) performs three steps:
1. For each voter in the certificate, confirm committee membership and collect verification keys.
2. Verify the aggregate BLS vote signature.
3. Batch-verify VRF outputs for non-persistent voters.

It then returns `pure members` — with no check that `sum(memberStake) >= perasQuorumStakeThreshold + perasQuorumStakeThresholdSafetyMargin`. [1](#0-0) 

`EveryoneVotes.implVerifyCert` (lines 301–340) has the identical omission: it checks per-voter non-zero stake and the aggregate signature, then returns `pure members` without any quorum check. [2](#0-1) 

By contrast, the forging path calls `votesReachQuorum`, which does enforce the threshold:

```haskell
votesHaveEnoughStake = stakeAboveThreshold cfg totalVoteStake
``` [3](#0-2) 

The quorum parameters themselves (`PerasQuorumStakeThreshold`, `PerasQuorumStakeThresholdSafetyMargin`) are plain `Rational` newtypes with no lower-bound invariant enforced by the type system, making the gap between forging and verification even more dangerous. [4](#0-3) 

The default `mkPerasParams` sets `perasQuorumStakeThreshold = 3/4` and `perasQuorumStakeThresholdSafetyMargin = 2/100`, but these values are never re-validated inside `verifyCert`. [5](#0-4) 

**Exploit flow.**

1. Attacker operates a stake pool with any positive stake.
2. At the start of an epoch, the attacker checks whether their pool qualifies as a persistent committee member (deterministic via weighted Fait-Accompli) or as a non-persistent member (via local sortition on their own VRF key — `implCheckShouldVote` returns `Just witness`).
3. The attacker constructs a `WFALSCert` (or `EveryoneVotesCert`) containing only their own seat index and VRF output, signs it with their BLS key, and broadcasts it to honest peers.
4. Honest peers call `verifyCert` (via `validatePerasCert`). The aggregate signature over a single voter verifies correctly; the VRF output is valid; `nonZero voterStake` passes. `verifyCert` returns `Right members`.
5. The certificate is accepted as a `ValidatedPerasCert` with `vpcCertBoost = perasWeight params` (default: 15 weight units).
6. The boosted block gains 15 extra chain-weight units, causing honest nodes to prefer it over the canonical chain. [6](#0-5) 

### Impact Explanation

A single committee-eligible pool — holding far less than the 3/4 + 2% quorum stake — can forge a cryptographically valid certificate for any block of its choice. Honest nodes accept the certificate and apply the `perasWeight` boost to that block's chain weight. Repeated across rounds (one certificate per round, subject to cooldown), the attacker can accumulate boosts on a minority fork, causing honest nodes to permanently prefer a non-canonical chain. This is a **High** chain-selection bug: an unprivileged peer with minimal stake can make honest nodes diverge from the canonical chain without needing a stake majority.

### Likelihood Explanation

Any stake pool operator who qualifies for even one committee seat (persistent or non-persistent) can execute this attack. Persistent seats are granted to the top-staked pools; non-persistent eligibility is determined per-election by local sortition, so any pool with positive stake has a non-zero probability of eligibility each round. The attack requires only standard pool operation and knowledge of one's own VRF key — no special access, no key compromise, no social engineering.

### Recommendation

Add a quorum check inside `implVerifyCert` for both `WFALS` and `EveryoneVotes`. After collecting `members`, compute the total stake and assert it meets the threshold before returning `Right members`:

```haskell
let totalStake = foldMap memberVoteStake members
unless (stakeAboveThreshold params totalStake) $
  Left QuorumNotReached
```

Additionally, enforce a lower-bound invariant on `PerasQuorumStakeThreshold` (e.g., require `> 1/2`) via a smart constructor, mirroring how `SecurityParam` uses `NonZero`.

-- | Verify a certificate attesting the winner of a given election
implVerifyCert ::
  forall crypto.
  ( CryptoSupportsAggregateVoteSigning crypto
  , CryptoSupportsBatchVRFVerification crypto
  ) =>
  VotingCommittee crypto WFALS ->
  Cert crypto WFALS ->
  Either
    (VotingCommitteeError crypto WFALS)
    (NE [EligibilityWitness crypto WFALS])
implVerifyCert committee = \case
  WFALSCert electionId candidate voters aggSig -> do
    -- Traverse the list of voters in ascending seat index order, collecting:
    -- 1. their membership status
    -- 2. their vote verification keys (to verify the aggregate vote signature)
    -- 3. optionally, their VRF verification keys and outputs (to verify the
    --    aggregate VRF output for non-persistent voters, if any)
    (members, voteVerificationKeys, optionalVRFKeysAndOutputs) <-
      fmap nonEmptyUnzip3 . flip traverse (NEMap.toAscList voters) $ \case
        -- Persistent voter
        (seatIndex, Nothing)
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
          , isPersistentMember seatIndex committee -> do
              let voterVoteVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              pure
                ( WFALSPersistentMember
                    seatIndex
                    voterStake
                , voterVoteVerificationKey
                , Nothing
                )
          | otherwise ->
              Left (NotAPersistentMember seatIndex)
        -- Non-persistent voter
        (seatIndex, Just vrfOutput)
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
          , not (isPersistentMember seatIndex committee) -> do
              let voterVoteVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              let voterVRFVerificationKey =
                    getVRFVerificationKey (Proxy @crypto) voterPublicKey
              let numSeats =
                    localSortitionNumSeats
                      (nonPersistentCommitteeSize committee)
                      (totalNonPersistentStake committee)
                      voterStake
                      (normalizeVRFOutput vrfOutput)
              case nonZero numSeats of
                Nothing ->
                  Left (ZeroNonPersistentSeats seatIndex)
                Just nonZeroNumSeats ->
                  pure
                    ( WFALSNonPersistentMember
                        seatIndex
                        voterStake
                        vrfOutput
                        nonZeroNumSeats
                    , voterVoteVerificationKey
                    , Just (voterVRFVerificationKey, vrfOutput)
                    )
          | otherwise ->
              Left (NotANonPersistentMember seatIndex)

    -- Verify aggregate signature
    aggVerificationKey <-
      bimap CryptoError id $
        aggregateVoteVerificationKeys
          (Proxy @crypto)
          voteVerificationKeys
    bimap InvalidCertSignature id $
      verifyAggregateVoteSignature
        (Proxy @crypto)
        aggVerificationKey
        electionId
        candidate
        aggSig

    -- Verify VRF outputs for non-persistent voters (if any)
    case catMaybes (NonEmpty.toList optionalVRFKeysAndOutputs) of
      -- No non-persistent voters => no VRF outputs to verify
      [] -> do
        pure ()
      -- Some non-persistent voters => verify their aggregate VRF outputs
      vrfKeysAndOutputs -> do
        let (vrfVerificationKeys, vrfOutputs) =
              munzip
                . NonEmpty.fromList -- safe 'vrfKeysAndOutputs' /= []
                $ vrfKeysAndOutputs
        bimap InvalidCertSignature id $
          batchVerifyVRFOutputs
            vrfVerificationKeys
            ( mkVRFElectionInput
                @crypto
                (epochNonce committee)
                electionId
            )
            vrfOutputs

    -- Return the list of voters attesting the election winner
    pure members
