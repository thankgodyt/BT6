### Title
Fixed-Point Underflow in `localSortitionNumSeats` Silently Denies Legitimate Non-Persistent Voters Committee Seats - (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/LS.hs`)

---

### Summary

In `localSortitionNumSeats`, the Poisson parameter `lambda` is computed as a `FixedPoint` value via `fromRational`. When a voter's stake is small relative to the total non-persistent stake, the rational value underflows to zero upon conversion to `FixedPoint`. The code explicitly acknowledges this at lines 57–60 and silently returns `LocalSortitionNumSeats 0`. This causes a legitimate non-persistent voter with positive stake to be denied all committee seats, and any vote or certificate they submit is subsequently rejected with `ZeroNonPersistentSeats` — a false rejection of a cryptographically valid vote.

---

### Finding Description

`localSortitionNumSeats` computes:

```haskell
lambda :: FixedPoint
lambda =
  fromRational $
    fromIntegral numNonPersistentVoters
      * voterStake
      / totalNonPersistentStake
``` [1](#0-0) 

`LedgerStake` wraps a `Rational`, so the intermediate computation is exact. However, `fromRational :: Rational -> FixedPoint` truncates to the fixed-point precision (34 decimal bits, ≈ 5.8 × 10⁻¹¹). When:

```
numNonPersistentVoters * voterStake / totalNonPersistentStake < 5.8e-11
```

`lambda` becomes exactly `0 :: FixedPoint`. The guard at line 60 then returns `LocalSortitionNumSeats 0`:

```haskell
| lambda <= 0 = LocalSortitionNumSeats 0
``` [2](#0-1) 

`LedgerStake` is `Rational` under the hood: [3](#0-2) 

The zero-seat result propagates into both `implVerifyVote` and `implVerifyCert` in `WFALS.hs`:

```haskell
case nonZero numSeats of
  Nothing ->
    Left (ZeroNonPersistentSeats seatIndex)
``` [4](#0-3) 

The same pattern appears during certificate verification: [5](#0-4) 

---

### Impact Explanation

A non-persistent voter with positive but small stake submits a cryptographically valid vote (correct VRF proof, correct signature, correct seat index). Every verifying node independently recomputes `localSortitionNumSeats` and obtains `0` due to the underflow, then rejects the vote with `ZeroNonPersistentSeats`. The vote is permanently excluded from any Peras certificate quorum count. If enough small-stake non-persistent voters are affected, the effective quorum threshold is silently raised relative to the protocol's design, materially weakening Peras vote and certificate authorization.

---

### Likelihood Explanation

With Cardano mainnet total stake ≈ 35 × 10¹⁵ lovelace and a committee of ~100 non-persistent voters, the underflow threshold is approximately:

```
voterStake < 5.8e-11 × (35e15 / 100) ≈ 20,300 lovelace ≈ 0.02 ADA
```

Any non-persistent candidate with less than ~0.02 ADA of stake triggers the underflow. While this is a small absolute amount, the condition is deterministic and reproducible: every node independently reaches the same wrong conclusion, so the rejection is consensus-consistent but protocol-incorrect. The code comment at lines 57–60 confirms the developers are aware of the underflow but treat it as an acceptable guard rather than a correctness fix.

---

### Recommendation

Perform the `lambda` comparison in exact `Rational` arithmetic before converting to `FixedPoint`:

```haskell
let lambdaRational =
      fromIntegral numNonPersistentVoters
        * voterStake
        / totalNonPersistentStake
| lambdaRational <= 0 = LocalSortitionNumSeats 0
| otherwise =
    let lambda = fromRational lambdaRational :: FixedPoint
    in ...
```

This preserves the division-by-zero guard while ensuring that a voter with positive rational stake is never silently denied seats due to fixed-point truncation.

---

### Proof of Concept

Parameters:
- `numNonPersistentVoters` = 100
- `totalNonPersistentStake` = 35 × 10¹⁵ lovelace (≈ full Cardano mainnet non-persistent stake)
- `voterStake` = 20,000 lovelace (0.02 ADA — positive, above the `voterStake <= 0` guard)

Computation:
```
lambdaRational = 100 * 20000 / 35e15 = 2e6 / 35e15 ≈ 5.71e-11
```

`FixedPoint` precision ≈ 5.8 × 10⁻¹¹, so `fromRational 5.71e-11 = 0 :: FixedPoint`.

Guard fires: `lambda <= 0` → `LocalSortitionNumSeats 0`.

In `implVerifyVote`/`implVerifyCert`: `nonZero 0 = Nothing` → `Left (ZeroNonPersistentSeats seatIndex)`.

The voter's cryptographically valid vote is rejected on every honest node. [6](#0-5)
