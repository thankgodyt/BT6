### Title
P2PKH Sighash Mismatch in `get_hash_to_sign` Permanently Breaks All Dogecoin Withdrawals and Refunds — (`contracts/satoshi-bridge/src/bitcoin_utils/psbt_wrapper.rs`)

### Summary

`PsbtWrapper::get_hash_to_sign` in the non-Zcash build unconditionally calls `p2wpkh_signature_hash` regardless of the actual script type stored in `witness_utxo.script_pubkey`. For Dogecoin (and any other chain where `get_segwit_hrp` returns `None`), deposit addresses are P2PKH, so `witness_utxo.script_pubkey` is a P2PKH script. The bitcoin crate's `p2wpkh_signature_hash` returns `Err(P2wpkhError::NotP2wpkhScript)` for non-P2WPKH scripts, causing the `.expect()` to panic. Every call to `sign_btc_transaction` for a Dogecoin UTXO panics and reverts, leaving the pending sign state permanently stuck. **Zcash is not affected** — it compiles a completely separate `zcash_utils/psbt_wrapper.rs` with a correct sighash implementation.

---

### Finding Description

**Feature-flag module selection** (`lib.rs` lines 21–77): [1](#0-0) [2](#0-1) 

When compiled without `feature = "zcash"` (i.e., for Bitcoin, Litecoin, and Dogecoin), the contract uses `bitcoin_utils::psbt_wrapper::PsbtWrapper`.

**Dogecoin generates P2PKH addresses** (`network.rs` lines 259–278): [3](#0-2) [4](#0-3) 

`get_segwit_hrp` returns `None` for Dogecoin, so `Address::from_pubkey` falls into the `else` branch and produces `Address::P2pkh`. Its `script_pubkey()` returns `bitcoin::ScriptBuf::new_p2pkh(hash)` — a legacy P2PKH script.

**`generate_vutxos` sets P2PKH script as `witness_utxo`** (`psbt.rs` lines 266–283): [5](#0-4) 

The P2PKH `script_pubkey` is stored in `psbt.inputs[i].witness_utxo`.

**`get_hash_to_sign` unconditionally calls `p2wpkh_signature_hash`** (`bitcoin_utils/psbt_wrapper.rs` lines 137–154): [6](#0-5) 

The bitcoin crate's `SighashCache::p2wpkh_signature_hash` validates that the script is P2WPKH. When given a P2PKH script, it returns `Err(P2wpkhError::NotP2wpkhScript)`. The `.expect("ERR_SIGHASH: failed to compute signature hash")` panics, reverting the NEAR transaction.

**`sign_btc_transaction` is publicly callable** (`api/chain_signatures.rs` lines 20–43): [7](#0-6) 

No `#[trusted_relayer]` guard. Any account can call it. The panic occurs inside `internal_sign_btc_transaction` → `get_psbt().get_hash_to_sign(...)`. [8](#0-7) 

**Zcash is unaffected**: `zcash_utils/psbt_wrapper.rs::get_hash_to_sign` uses `zcash_primitives::transaction::sighash::signature_hash`, which is the correct Zcash transparent sighash algorithm. [9](#0-8) 

---

### Impact Explanation

Every Dogecoin withdrawal and refund that reaches the signing stage panics unconditionally. The NEAR transaction reverts, the `BTCPendingInfo` remains in `PendingSign` state, and the locked UTXOs cannot be spent. All Dogecoin bridge withdrawals and refunds are permanently broken at the signing step. Funds deposited to the Dogecoin bridge cannot be retrieved without direct contract upgrade/migration by the DAO.

---

### Likelihood Explanation

This is a systemic, deterministic failure — not probabilistic. Every single Dogecoin withdrawal or refund triggers the panic. No special attacker action is required; any legitimate user attempting to withdraw triggers it. The only precondition is that the bridge is deployed on Dogecoin (a supported chain per `network.rs`).

---

### Recommendation

In `bitcoin_utils/psbt_wrapper.rs::get_hash_to_sign`, branch on the actual script type:

- If `witness_utxo.script_pubkey.is_p2wpkh()` → use `p2wpkh_signature_hash` (BIP143 segwit sighash).
- If `witness_utxo.script_pubkey.is_p2pkh()` → use `legacy_signature_hash` with `SighashCache` (BIP143 does not apply; use the classic double-SHA256 sighash over the serialized transaction with the script replaced by the scriptPubKey).

Also fix `save_signature` (line 162–163): it unconditionally sets `final_script_witness` (a segwit field). For P2PKH inputs, the signature must go into `final_script_sig`, not the witness.

---

### Proof of Concept

```
1. Deploy bridge with `#[cfg(not(feature = "zcash"))]` targeting Dogecoin.
2. User deposits DOGE to a P2PKH address (generated by generate_utxo_chain_address for DogecoinMainnet).
3. verify_deposit records the UTXO.
4. User calls ft_on_transfer (withdraw) → create_btc_pending_info → generate_vutxos sets
   witness_utxo.script_pubkey = ScriptBuf::new_p2pkh(...) for the Dogecoin input.
5. Anyone calls sign_btc_transaction(btc_pending_sign_id, 0, 0).
6. internal_sign_btc_transaction → get_psbt().get_hash_to_sign(0, &public_keys)
7. p2wpkh_signature_hash(..., &p2pkh_script, ...) returns Err(NotP2wpkhScript)
8. .expect("ERR_SIGHASH: ...") panics → NEAR tx reverts.
9. Repeat for any sign_index: always panics.
10. UTXO permanently stuck in PendingSign state; user funds unrecoverable without DAO upgrade.
```

    pub fn get_hash_to_sign(&self, vin: usize, public_keys: &[bitcoin::PublicKey]) -> [u8; 32] {
        let tx = self.psbt.unsigned_tx.clone();
        let mut cache = SighashCache::new(tx);
        let witness_utxo = self.psbt.inputs[vin]
            .witness_utxo
            .as_ref()
            .expect("ERR_MISSING_WITNESS_UTXO: input missing witness UTXO data");
        cache
            .p2wpkh_signature_hash(
                vin,
                &witness_utxo.script_pubkey,
                witness_utxo.value,
                bitcoin::EcdsaSighashType::All,
            )
            .expect("ERR_SIGHASH: failed to compute signature hash")
            .to_raw_hash()
            .to_byte_array()
    }

    #[allow(unused_variables)]
    pub fn get_hash_to_sign(&self, vin: usize, public_keys: &[bitcoin::PublicKey]) -> [u8; 32] {
        let tx_data = WrappedTransaction::to_zcash_tx(
            &self.vin,
            &self.vout,
            &self.inputs_utxo,
            self.expiry_height,
            public_keys,
            self.branch_id,
        );
        let txid_parts =
            self.tx_digest(&tx_data, zcash_primitives::transaction::txid::TxIdDigester);

        let script = self.inputs_utxo[vin].script_pubkey();
        let transparent_bundle = tx_data.transparent_bundle().unwrap_or_else(|| {
            env::panic_str("ERR_NO_TRANSPARENT_BUNDLE: missing transparent bundle")
        });
        let sig_input = zcash_primitives::transaction::sighash::SignableInput::Transparent(
            zcash_transparent::sighash::SignableInput::from_parts(
                transparent_bundle,
                SighashType::ALL,
                vin,
                script,
                script,
                self.inputs_utxo[vin].value(),
            )
            .unwrap_or_else(|_| env::panic_str("ERR_SIGNABLE_INPUT: invalid input index")),
        );

        *zcash_primitives::transaction::sighash::signature_hash(&tx_data, &sig_input, &txid_parts)
            .as_ref()
    }
