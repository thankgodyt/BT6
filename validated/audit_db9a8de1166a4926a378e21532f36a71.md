### Title
Peras Vote Verification Bypass via Stub `validatePerasVote` Allows Unprivileged Peer to Forge Votes and Block Legitimate Voters - (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Block/SupportsPeras.hs`)

---

### Summary

The production `validatePerasVote` implementation is a stub that only checks whether a voter's ID exists in the stake distribution. It performs no cryptographic signature verification, no VRF eligibility proof check, and no seat-index validation. An unprivileged peer can craft a `PerasVote` carrying any legitimate voter's `PerasVoterId` and any block target, have it accepted into the `PerasVoteDB`, and thereby (a) pre-empt that voter's real vote for the round, and (b) accumulate enough forged stake to trigger false certificate forging — directly analogous to the Oracle double-vote / voter-blocking bug caused by stale index-based state.

---

### Finding Description

`validatePerasVote` is the sole validation gate called on every inbound vote before it is admitted to the `PerasVoteDB`. Its current production body is:

```haskell
-- TODO: perform actual validation against all
-- possible 'PerasValidationErr' variants
-- see https://github.com/tweag/cardano-peras/issues/120
validatePerasVote _params stakeDistr vote
  | Just stake <- lookupPerasVoteStake vote stakeDistr =
      Right ValidatedPerasVote { vpvVote = vote, vpvVoteStake = stake }
  | otherwise =
      Left PerasValidationErr
``` [1](#0-0) 

`lookupPerasVoteStake` only performs a `Map.lookup` on the voter's key hash:

```haskell
lookupPerasVoteStake vote distr =
  Map.lookup (pvVoteVoterId vote) (unPerasVoteStakeDistr distr)
``` [2](#0-1) 

This stub is wired directly into the inbound vote processing path via `makePerasVotePoolWriterFromVoteDB` and `makePerasVotePoolWriterFromChainDB`:

```haskell
(\vote -> getStakeDistrSTM >>= \sd -> pure $ validatePerasVote mkPerasParams sd vote)
``` [3](#0-2) 

`processVotes` filters out already-seen vote IDs, then calls `validateVote` on the remainder, and adds all that pass: [4](#0-3) 

Inside `implAddVote`, deduplication is keyed on `PerasVoteId = (roundNo, voterId)`:

```haskell
addOrIgnoreVote pvds voteId
  | Set.member voteId (pvdsVoteIds pvds) = voteAlreadyInDB pvds
  | otherwise = tryAddVote pvds voteId
``` [5](#0-4) 

Once `(roundNo, voterId)` is in `pvdsVoteIds`, any subsequent vote from that voter for that round — including the voter's own legitimate vote — is silently dropped as `PerasVoteAlreadyInDB`. [6](#0-5) 

The `PerasVoteId` type confirms the deduplication key is `(pviRoundNo, pviVoterId)`: [7](#0-6) 

The stake distribution is public (`PerasVoteStakeDistr` is a plain `Map PerasVoterId PerasVoteStake`): [8](#0-7) 

---

### Impact Explanation

**Critical — Bypass of Peras vote/certificate checks enabling unauthorized certificate acceptance.**

An attacker who knows the epoch's stake distribution (which is public) can:

1. **Block any legitimate voter**: Craft a `PerasVote` with `pvVoteVoterId = V` (a real pool's key hash) and any `pvVoteBlock`. `validatePerasVote` accepts it because V is in the stake distribution. `(roundNo, V)` is inserted into `pvdsVoteIds`. V's real vote for that round is now permanently rejected as a duplicate.

2. **Forge a false quorum certificate**: By sending forged votes for enough pools whose combined `PerasVoteStake` exceeds the quorum threshold, `updateCandidateVoteState` calls `votesReachQuorum`, which succeeds, and `forgePerasCert` produces a `ValidatedPerasCert` for an attacker-chosen block. This certificate is then used in chain selection to boost that block's weight. [9](#0-8) 

The `updateTargetVoteTally` function correctly deduplicates by `PerasVoteId` within a tally, but since the forged votes carry distinct voter IDs, each one adds its full stake: [10](#0-9) 

---

### Likelihood Explanation

**High.** The stake distribution is public on-chain. Any connected peer can enumerate all `PerasVoterId` values and their stakes. No key material, admin access, or stake majority is required. The attack requires only crafting well-formed `PerasVote` messages with valid voter IDs and sending them over the existing vote diffusion mini-protocol before legitimate voters do. The window is an entire Peras round.

---

### Recommendation

Replace the stub with full cryptographic validation before a vote is admitted to the `PerasVoteDB`:

1. **Signature verification**: Verify the BLS vote signature against the voter's public key (retrieved from the committee's `ExtWFAStakeDistr` via the seat index).
2. **Eligibility proof**: For non-persistent members, verify the VRF output proves the voter was selected for this election.
3. **Seat-index consistency**: Confirm the `pvSeatIndex` in the wire vote matches the `PerasVoterId` in the stake distribution.
4. **Round validity**: Reject votes for rounds that are not currently open.

The committee-level `verifyVote` functions in `EveryoneVotes` and `WFALS` already implement the correct cryptographic checks and should be invoked here: [11](#0-10) [12](#0-11)

### Proof of Concept

```
Setup:
  - Epoch stake distribution: { V1: 0.4, V2: 0.4, V3: 0.2 }
  - Quorum threshold: 0.75
  - Current round: R

Attack sequence (attacker is an unprivileged peer):
  1. Attacker sends PerasVote { pvVoteRound=R, pvVoteBlock=B_attacker,
       pvVoteVoterId=V1, pvSignature=<garbage> }
     → validatePerasVote: V1 ∈ stakeDistr → accepted, stake=0.4
     → pvdsVoteIds ∋ (R, V1)

  2. Attacker sends PerasVote { pvVoteRound=R, pvVoteBlock=B_attacker,
       pvVoteVoterId=V2, pvSignature=<garbage> }
     → validatePerasVote: V2 ∈ stakeDistr → accepted, stake=0.4
     → total stake for B_attacker = 0.8 > 0.75 → certificate forged for B_attacker

  3. Legitimate V1 sends real vote for B_canonical:
     → implAddVote: (R, V1) ∈ pvdsVoteIds → PerasVoteAlreadyInDB → dropped

  4. Legitimate V2 sends real vote for B_canonical:
     → implAddVote: (R, V2) ∈ pvdsVoteIds → PerasVoteAlreadyInDB → dropped

Result: False certificate for B_attacker is in the PerasVoteDB and will be
        used in chain selection to boost B_attacker's weight. B_canonical
        receives no certificate. Honest nodes may prefer the attacker's chain.
```

  forall crypto.
  ( CryptoSupportsVoteSigning crypto
  , CryptoSupportsVRF crypto
  ) =>
  VotingCommittee crypto WFALS ->
  Vote crypto WFALS ->
  Either
    (VotingCommitteeError crypto WFALS)
    (EligibilityWitness crypto WFALS)
implVerifyVote committee = \case
  WFALSPersistentVote seatIndex electionId candidate sig
    | Just (_, voterPublicKey, voterStake, _) <-
        getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
    , isPersistentMember seatIndex committee -> do
        let voterVerificationKey =
              getVoteVerificationKey (Proxy @crypto) voterPublicKey
        checkVoteSignature voterVerificationKey electionId candidate sig
        pure $
          WFALSPersistentMember
            seatIndex
            voterStake
    | otherwise -> do
        Left (NotAPersistentMember seatIndex)
  WFALSNonPersistentVote seatIndex electionId message vrfOutput sig
    | Just (_, voterPublicKey, voterStake, _) <-
        getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
    , not (isPersistentMember seatIndex committee) -> do
        let voterVoteVerificationKey =
              getVoteVerificationKey (Proxy @crypto) voterPublicKey
        bimap InvalidVoteSignature id $ do
          verifyVoteSignature
            voterVoteVerificationKey
            electionId
            message
            sig
        let voterVRFVerificationKey =
              getVRFVerificationKey (Proxy @crypto) voterPublicKey
        let vrfContext =
              VRFVerifyContext voterVRFVerificationKey vrfOutput
        void $ bimap InvalidVoterEligibilityProof id $ do
          evalVRF
            vrfContext
            ( mkVRFElectionInput
                @crypto
                (epochNonce committee)
                electionId
            )
        let numSeats =
              localSortitionNumSeats
                (nonPersistentCommitteeSize committee)
                (totalNonPersistentStake committee)
                voterStake
                (normalizeVRFOutput vrfOutput)
        case nonZero numSeats of
          Nothing ->
            Left (ZeroNonPersistentSeats seatIndex)
          Just nonZeroNumSeats ->
            pure $
              WFALSNonPersistentMember
                seatIndex
                voterStake
                vrfOutput
                nonZeroNumSeats
    | otherwise ->
        Left (NotANonPersistentMember seatIndex)
