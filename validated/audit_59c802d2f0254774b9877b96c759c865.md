### Title
`pcdsLatestCertSeen` Never Cleared on Garbage Collection, Causing Stale Peras Voting-Rule Evaluation - (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Storage/PerasCertDB/Impl.hs`)

---

### Summary

`implGarbageCollect` in `PerasCertDB/Impl.hs` removes certificates from `pcdsCertsByTicket` and `pcdsCertIds` but never updates `pcdsLatestCertSeen`. After GC, `getLatestCertSeen` returns a certificate that no longer exists in the database. All Peras voting rules (VR-1A, VR-1B, VR-2A) and certificate-inclusion rules that consume `latestCertSeen` then operate on a phantom certificate, causing a node to vote or include certificates under conditions the protocol does not permit.

---

### Finding Description

`PerasCertDbState` holds four fields:

- `pcdsCertIds` — the set of round numbers of live certificates
- `pcdsCertsByTicket` — the live certificates indexed by ticket
- `pcdsLastTicketNo` — the highest ticket number ever issued
- `pcdsLatestCertSeen` — the certificate with the highest round number ever added [1](#0-0) 

`implGarbageCollect` filters `pcdsCertsByTicket` and recomputes `pcdsCertIds` from the survivors, but passes `pcdsLatestCertSeen` through **unchanged**: [2](#0-1) 

The GC predicate removes any certificate whose boosted block's slot is strictly below the threshold: [3](#0-2) 

A certificate can be the highest-round-number certificate ever seen (`pcdsLatestCertSeen`) while boosting a block whose slot falls below the GC threshold — for example, a certificate for a recent round that boosts a block deep in the immutable chain. After GC, `pcdsCertIds` no longer contains that round number, but `pcdsLatestCertSeen` still points to the removed certificate.

The `invariantForPerasCertDbState` checker does not verify consistency between `pcdsLatestCertSeen` and `pcdsCertIds`/`pcdsCertsByTicket`, so the invariant machinery does not catch this divergence: [4](#0-3) 

`getLatestCertSeen` reads `pcdsLatestCertSeen` directly: [5](#0-4) 

The stale value is consumed by every Peras voting rule. VR-1A checks whether the latest cert seen is from the previous round and arrived within the threshold window: [6](#0-5) 

VR-1B checks whether the candidate block extends the boosted block of the latest cert seen: [7](#0-6) 

VR-2A checks whether the latest cert seen is old enough to exit a cooldown period: [8](#0-7) 

Certificate-inclusion rules `latestCertSeenIsNotExpired` and `latestCertSeenIsNewerThanLatestCertOnChain` also consume the stale value when deciding whether to embed a certificate in a freshly forged block: [9](#0-8) [10](#0-9) 

---

### Impact Explanation

**High — Peras voting-rule bypass and invalid certificate inclusion in forged blocks.**

A node evaluating VR-1A against a stale `latestCertSeen` may conclude it has seen the previous round's certificate (satisfying the precondition for voting) when in fact that certificate has been removed. This causes the node to cast a vote it is not entitled to cast under the Peras protocol, potentially contributing to a quorum that the protocol would otherwise not reach. Conversely, a node that should vote may be blocked because the stale cert makes VR-2A appear unsatisfied.

More critically, the certificate-inclusion path (`needCert`) uses `latestCertSeen` to select which certificate to embed in a forged block. If the selected certificate has been GC'd, the node may embed a reference to a certificate it can no longer serve to peers, breaking the Peras chain-quality and common-prefix guarantees that depend on certificate propagation. [11](#0-10) 

---

### Likelihood Explanation

**Medium-High.** GC is triggered routinely as blocks become immutable. Any certificate that boosts a block in the immutable chain will eventually be GC'd. Because `pcdsLatestCertSeen` tracks the highest-round-number certificate ever seen — not the most recently GC-surviving one — the divergence is a normal operational outcome, not an edge case. An unprivileged peer can accelerate the condition by diffusing a valid certificate for a high round number that boosts a block with a low slot number, ensuring it becomes `latestCertSeen` and is then promptly GC'd.

---

### Recommendation

In `implGarbageCollect`, after filtering `pcdsCertsByTicket`, recompute `pcdsLatestCertSeen` from the surviving certificates:

```haskell
pcdsLatestCertSeen' =
  if maybe True (\c -> getPerasCertRound c `Set.notMember` pcdsCertIds') pcdsLatestCertSeen
    then
      -- The previous latestCertSeen was GC'd; find the new maximum among survivors
      fmap snd $
        Map.lookupMax $
          Map.mapKeys getPerasCertRound $
            Map.fromList
              [ (getPerasCertRound c, c)
              | c <- Map.elems pcdsCertsByTicket'
              ]
    else pcdsLatestCertSeen
```

Alternatively, extend `invariantForPerasCertDbState` to assert that `pcdsLatestCertSeen`, when `Just`, has its round number present in `pcdsCertIds`, so any future regression is caught immediately.

---

### Proof of Concept

1. Node starts; `pcdsLatestCertSeen = Nothing`, `pcdsCertIds = {}`.
2. Peer diffuses a valid `ValidatedPerasCert` for round 42 boosting block at slot 100. `implAddCert` stores it: `pcdsCertIds = {42}`, `pcdsLatestCertSeen = Just cert42`.
3. Chain advances; GC is called with `slotNo = 101`. `pcdsCertsByTicket` is filtered: cert42's boosted block slot (100) < 101, so it is removed. `pcdsCertIds` is recomputed as `{}`. `pcdsLatestCertSeen` is **not updated** and remains `Just cert42`.
4. Node calls `getLatestCertSeen` → returns `Just cert42`. Node calls `getCertIds` → returns `{}`. The two are inconsistent.
5. Voting rules evaluate VR-1A with `latestCertSeen = NotOrigin cert42` (round 42). If `currRoundNo = 43`, VR-1A's first sub-condition (`currRoundNo == getPerasCertRound cert + 1`) is satisfied by the phantom certificate, and the node votes in round 43 without a legitimately live certificate backing the decision.
6. `needCert` evaluates `latestCertSeenIsNewerThanLatestCertOnChain` using the phantom cert42 and decides to include it in the next forged block, embedding a reference to a certificate the node can no longer retrieve or serve. [12](#0-11)

implGarbageCollect ::
  forall m blk.
  IOLike m =>
  PerasCertDbEnv m blk ->
  SlotNo ->
  STM m (m ())
implGarbageCollect PerasCertDbEnv{pcdbTracer, pcdbState} slotNo = do
  -- No need to update the 'Fingerprint' as we only remove certificates that do
  -- not matter for comparing interesting chains.
  modifyTVar pcdbState (fmap gc)
  pure $ traceWith pcdbTracer (GarbageCollected slotNo)
 where
  gc :: PerasCertDbState blk -> PerasCertDbState blk
  gc
    PerasCertDbState
      { pcdsCertsByTicket
      , pcdsLastTicketNo
      , pcdsLatestCertSeen
      } =
      let pcdsCertsByTicket' =
            Map.filter
              (\cert -> pointSlot (getPerasCertBoostedBlock cert) >= NotOrigin slotNo)
              pcdsCertsByTicket
          pcdsCertIds' =
            Set.fromList (getPerasCertRound <$> Map.elems pcdsCertsByTicket')
       in PerasCertDbState
            { pcdsCertIds = pcdsCertIds'
            , pcdsCertsByTicket = pcdsCertsByTicket'
            , pcdsLastTicketNo = pcdsLastTicketNo
            , pcdsLatestCertSeen = pcdsLatestCertSeen
            }

perasVR1A ::
  HasPerasCertRound cert =>
  PerasVotingView cert ->
  Pred PerasVotingRule
perasVR1A
  PerasVotingView
    { perasParams
    , currRoundNo
    , latestCertSeen
    } =
    VR1A := vr1a1 :/\: vr1a2
   where
    -- The latest certificate seen is from the previous round
    vr1a1 =
      case latestCertSeen of
        -- We have seen a certificate ==> check its round number
        NotOrigin cert ->
          currRoundNo :==: getPerasCertRound (lcsCert cert) + 1
        -- We have never seen a certificate ==> check if we are voting in round 0
        Origin ->
          currRoundNo :==: PerasRoundNo 0

    -- The latest certificate seen was received within X slots from the start
    -- of its round
    vr1a2 =
      case latestCertSeen of
        -- We have seen a certificate ==> check its arrival time
        NotOrigin cert ->
          lcsArrivalSlot cert :<=: lcsRoundStartSlot cert + _X
        -- We have never seen a certificate ==> vacuously true
        Origin ->
          Bool True

    _X =
      SlotNo $
        unPerasCertArrivalThreshold $
          perasCertArrivalThreshold perasParams
