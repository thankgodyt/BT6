### Title
Blacklisted EVM Recipient Permanently Freezes Bridged Funds With No Recovery Path - (`evm/src/omni-bridge/contracts/OmniBridge.sol`)

### Summary
When a user initiates a NEAR → EVM transfer, the source-chain tokens are burned or locked immediately. The EVM-side `finTransfer` hardcodes the payout to `payload.recipient` with no fallback or alternative-recipient mechanism. If that EVM address is blacklisted by the token contract (e.g., USDC) between initiation and finalization, every `finTransfer` attempt reverts, and the source-chain tokens are permanently frozen with no refund path.

### Finding Description
In `OmniBridge.sol`, the `finTransfer` function unconditionally calls `safeTransfer` to `payload.recipient`:

```solidity
} else {
    IERC20(payload.tokenAddress).safeTransfer(
        payload.recipient,
        payload.amount
    );
}
``` [1](#0-0) 

The `payload.recipient` is fixed at transfer-initiation time on NEAR and is embedded in the MPC-signed `TransferMessagePayload`. There is no on-chain mechanism to substitute a different recipient after signing.

On the NEAR side, `init_transfer_internal` burns or locks the tokens immediately upon a successful `init_transfer`:

```rust
self.burn_tokens_if_needed(token_id.clone(), transfer_message.amount);
self.lock_tokens_if_needed(...);
``` [2](#0-1) 

`sign_transfer` signs the stored `TransferMessage` (which contains the fixed recipient) and, when the fee is zero, removes the pending transfer record — leaving no on-chain state to trigger a refund:

```rust
if fee.is_zero() {
    self.remove_transfer_message(message_payload.transfer_id);
}
``` [3](#0-2) 

There is no `cancel_transfer`, `change_recipient`, or refund function anywhere in the NEAR bridge contract. [4](#0-3) 

### Impact Explanation
If the EVM recipient address is blacklisted by the token contract after the NEAR-side tokens are burned/locked but before `finTransfer` succeeds:

1. Every `finTransfer` call reverts (USDC/USDT `safeTransfer` to a blacklisted address always reverts).
2. The MPC-signed payload cannot be altered — the recipient is part of the signed hash.
3. No new signature can be obtained for a different recipient because the stored `TransferMessage` on NEAR has a fixed recipient and there is no update path.
4. The source-chain tokens are already destroyed or locked with no refund mechanism.

Result: **permanent, irrecoverable freezing of bridged funds**.

### Likelihood Explanation
Token blacklisting (USDC, USDT, BUSD) is a real, documented occurrence. The window of exposure is the time between `init_transfer` on NEAR and `finTransfer` on EVM — which can span minutes to hours depending on relayer latency and MPC signing time. The probability is low but non-zero, matching the medium-severity classification of the reference report.

### Recommendation
Add an optional `recipient_override` parameter to `finTransfer` that can only be used when the primary `payload.recipient` is provably unable to receive tokens (e.g., via a failed transfer attempt), or add a `cancel_transfer` / `refund_transfer` function on NEAR that allows the original sender to reclaim tokens when a transfer has been pending beyond a timeout threshold. Analogously to the reference fix, allow the beneficiary to specify an alternative recipient address.

### Proof of Concept

1. Alice holds 10,000 USDC on NEAR and calls `ft_transfer_call` → `init_transfer` with `recipient = 0xAliceEVM`. Tokens are locked in the NEAR bridge. [5](#0-4) 
2. A relayer calls `sign_transfer` on NEAR; the MPC signs a payload committing to `recipient = 0xAliceEVM`. The pending transfer record is removed (zero-fee path). [6](#0-5) 
3. Before the relayer submits `finTransfer` on Ethereum, USDC's admin blacklists `0xAliceEVM`.
4. The relayer calls `finTransfer` on Ethereum. `IERC20(usdc).safeTransfer(0xAliceEVM, amount)` reverts. [1](#0-0) 
5. No alternative recipient can be specified. No refund path exists on NEAR. Alice's 10,000 USDC is permanently frozen.

    fn init_transfer(
        &mut self,
        sender_id: AccountId,
        signer_id: AccountId,
        token_id: AccountId,
        amount: U128,
        init_transfer_msg: InitTransferMsg,
    ) -> PromiseOrPromiseIndexOrValue<U128> {
        require!(
            init_transfer_msg.recipient.get_chain() != ChainKind::Near,
            BridgeError::InvalidRecipientChain.as_ref()
        );

        self.current_origin_nonce += 1;
        let destination_nonce =
            self.get_next_destination_nonce(init_transfer_msg.get_destination_chain());

        let transfer_message = TransferMessage {
            origin_nonce: self.current_origin_nonce,
            token: OmniAddress::Near(token_id),
            amount,
            recipient: init_transfer_msg.recipient,
            fee: Fee {
                fee: init_transfer_msg.fee,
                native_fee: init_transfer_msg.native_token_fee,
            },
            sender: OmniAddress::Near(sender_id),
            msg: init_transfer_msg.msg.map(String::from).unwrap_or_default(),
            destination_nonce,
            origin_transfer_id: None,
        };
        require!(
            transfer_message.fee.fee < transfer_message.amount,
            BridgeError::InvalidFee.as_ref()
        );

        let required_storage_balance =
            self.required_balance_for_init_transfer_message(transfer_message.clone());

        let message_storage_account_id = transfer_message
            .calculate_storage_account_id(init_transfer_msg.external_id.map(String::from));

        // Choose storage payer or whether to yield execution until storage is available
        if self
            .try_to_transfer_balance_from_message_account(
                &message_storage_account_id,
                NearToken::from_yoctonear(init_transfer_msg.native_token_fee.0),
                &signer_id,
                required_storage_balance,
            )
            .is_ok()
            || (self.has_storage_balance(
                &signer_id,
                required_storage_balance.saturating_add(NearToken::from_yoctonear(
                    init_transfer_msg.native_token_fee.0,
                )),
            ) && (init_transfer_msg.native_token_fee.0 == 0
                || !self.acl_has_role(Role::NativeFeeRestricted.into(), signer_id.clone())))
        {
            PromiseOrPromiseIndexOrValue::Value(
                self.init_transfer_internal(transfer_message, signer_id),
            )
        } else {
            let promise_index = env::promise_yield_create(
                "init_transfer_resume",
                json!({
                    "transfer_message": transfer_message,
                    "message_storage_account_id": message_storage_account_id,
                    "storage_owner": signer_id,
                })
                .to_string()
                .as_bytes(),
                INIT_TRANSFER_RESUME_GAS,
                GasWeight(0),
                PROMISE_REGISTER_ID,
            );

            let yield_id: CryptoHash = env::read_register(PROMISE_REGISTER_ID)
                .near_expect(BridgeError::ReadPromiseRegister)
                .try_into()
                .near_expect(BridgeError::ReadPromiseYieldId);

            let required_storage_balance = self.add_promise(&message_storage_account_id, &yield_id);

            self.update_storage_balance(
                env::current_account_id(),
                required_storage_balance,
                NearToken::from_yoctonear(0),
            );

            env::log_str(&format!(
                "Yield init transfer until storage is available at {message_storage_account_id}"
            ));

            PromiseOrPromiseIndexOrValue::PromiseIndex(promise_index)
        }
    }

    fn init_transfer_internal(
        &mut self,
        transfer_message: TransferMessage,
        storage_owner: AccountId,
    ) -> U128 {
        let required_storage_balance = self
            .add_transfer_message(transfer_message.clone(), storage_owner.clone())
            .saturating_add(NearToken::from_yoctonear(transfer_message.fee.native_fee.0));

        if self
            .try_update_storage_balance(
                storage_owner,
                required_storage_balance,
                NearToken::from_yoctonear(0),
            )
            .is_err()
        {
            self.remove_transfer_message_without_refund(transfer_message.get_transfer_id());
            return transfer_message.amount;
        }

        if let OmniAddress::Near(token_id) = transfer_message.token.clone() {
            self.burn_tokens_if_needed(token_id.clone(), transfer_message.amount);

            self.lock_tokens_if_needed(
                transfer_message.get_destination_chain(),
                &token_id,
                transfer_message.amount.0,
            );
        } else {
            self.remove_transfer_message_without_refund(transfer_message.get_transfer_id());
            return transfer_message.amount;
        }

        env::log_str(&OmniBridgeEvent::InitTransferEvent { transfer_message }.to_log_string());
        U128(0)
    }
