### Title
`reject_refund` Missing `#[pause]` Guard Allows State Mutation During Emergency Pause - (File: contracts/satoshi-bridge/src/api/bridge.rs)

### Summary
The `reject_refund` function in `bridge.rs` is the only state-mutating public bridge function that lacks the `#[pause]` macro. Every other non-view, non-privileged function in the same file is decorated with `#[pause(except(roles(Role::DAO)))]`, but `reject_refund` is not. This means any unprivileged caller can invoke it and mutate contract state even when the contract is in a paused emergency state.

### Finding Description
The bridge uses the `near-plugins` `Pausable` trait. Individual functions are protected by the `#[pause]` procedural macro. Examining `bridge.rs`, every state-changing public function carries the guard:

- `verify_deposit` [1](#0-0) 
- `verify_deposit_v2` [2](#0-1) 
- `request_refund` [3](#0-2) 
- `execute_refund` [4](#0-3) 
- `verify_refund_finalize` [5](#0-4) 
- `claim_lost_found` [6](#0-5) 

`reject_refund`, however, has no `#[pause]` annotation at all: [7](#0-6) 

The function's own access check allows two caller classes:
1. **Privileged** – accounts holding `Role::DAO` or `Role::Operator`.
2. **Unprivileged** – anyone, when `is_already_deposited` is true: the UTXO is present in `verified_deposit_utxo` **and** the stored `RefundRequest.executed` flag is `false`.

    pub fn reject_refund(&mut self, utxo_storage_key: String) {
        let caller = env::predecessor_account_id();
        let is_privileged = self.acl_has_role(Role::DAO.into(), caller.clone())
            || self.acl_has_role(Role::Operator.into(), caller);
        // `execute_refund` also inserts the UTXO into `verified_deposit_utxo` (to block a
        // later deposit) while keeping the request with `executed == true`. That membership
        // must NOT open the permissionless reject path, otherwise anyone could cancel an
        // in-flight refund — so only treat the UTXO as "already deposited" when the request
        // was not executed by us, i.e. a real `verify_deposit` finalized it.
        let executed = self
            .data()
            .refund_requests
            .get(&utxo_storage_key)
            .map(|r| RefundRequest::from(r).executed)
            .unwrap_or(false);
        let is_already_deposited = !executed
            && self
                .data()
                .verified_deposit_utxo
                .contains(&utxo_storage_key);
        require!(
            is_privileged || is_already_deposited,
            "Only DAO/Operator can reject, or UTXO must be already verified via deposit"
        );
        self.internal_reject_refund(utxo_storage_key);
    }
