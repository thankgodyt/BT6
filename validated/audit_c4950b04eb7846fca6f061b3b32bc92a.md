### Title
Unconditional Peras Certificate and Vote Acceptance Bypasses All Cryptographic Verification, Enabling Unauthorized Chain Boosting — (`File: ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Block/SupportsPeras.hs`)

---

### Summary

The production `BlockSupportsPeras` instance ships a stub `validatePerasCert` that unconditionally returns `Right` for every inbound certificate, and a stub `validatePerasVote` that performs no cryptographic check whatsoever. Both stubs are wired directly into the live ObjectDiffusion inbound path. Any unprivileged peer can therefore inject arbitrarily crafted Peras certificates and votes that are accepted without any signature, eligibility, or quorum verification, causing the victim node to apply attacker-chosen chain-selection boosts.

---

### Finding Description

**Root cause — `validatePerasCert` is a no-op stub:** [1](#0-0) 

```haskell
-- TODO: perform actual validation against all
-- possible 'PerasValidationErr' variants
-- see https://github.com/tweag/cardano-peras/issues/120
validatePerasCert params cert =
  Right
    ValidatedPerasCert
      { vpcCert = cert
      , vpcCertBoost = perasWeight params
      }
```

Every `PerasCert` received from any peer is unconditionally wrapped in `ValidatedPerasCert` and returned as `Right`. No aggregate BLS signature is checked, no quorum threshold is verified, no round/slot bounds are enforced, and no boosted-block existence is confirmed.

**Root cause — `validatePerasVote` performs no cryptographic check:** [2](#0-1) 

```haskell
-- TODO: perform actual validation against all
-- possible 'PerasValidationErr' variants
validatePerasVote _params stakeDistr vote
  | Just stake <- lookupPerasVoteStake vote stakeDistr =
      Right ValidatedPerasVote { vpvVote = vote, vpvVoteStake = stake }
  | otherwise =
      Left PerasValidationErr
```

The degenerate `PerasVote` type carries no signature field at all: [3](#0-2) 

Validation only checks whether the claimed `pvVoteVoterId` appears in the stake distribution. Pool IDs are public on-chain data, so any peer can impersonate any registered pool and have its vote accepted.

**This instance is the universal production instance for all block types:** [4](#0-3) 

```haskell
-- TODO: degenerate instance for all blks to get things to compile
instance StandardHash blk => BlockSupportsPeras blk where
```

**Attacker-controlled entry path — `processCerts` in the ObjectDiffusion inbound handler:** [5](#0-4) 

`makePerasCertPoolWriterFromChainDB` wires `validatePerasCert mkPerasParams` directly as the validation callback passed to `processCerts`. The `processCerts` function calls this callback for every inbound certificate not already in the DB: [6](#0-5) 

Because `validatePerasCert` always returns `Right`, every cert passes and is stored in `PerasCertDB` with its `vpcCertBoost` weight applied.

The analogous vote path uses `validatePerasVote mkPerasParams` in `makePerasVotePoolWriterFromChainDB`: [7](#0-6) 

**Chain-selection impact — the boost weight is consumed directly:** [8](#0-7) 

`getWeightSnapshot` is read during chain selection to compare candidate chains. Injected certificates with attacker-chosen `pcCertBoostedBlock` values directly alter which chain the node considers heaviest.

### Impact Explanation

**Severity: Critical — Bypass of certificate/signature validation enabling unauthorized certificate acceptance and chain-selection manipulation.**

An unprivileged peer that speaks the ObjectDiffusion mini-protocol can:

1. Craft a `PerasCert` naming any block point as `pcCertBoostedBlock` and any round number as `pcCertRound`.
2. Send it to a victim node. `processCerts` calls `validatePerasCert`, which returns `Right` unconditionally.
3. The cert is stored in `PerasCertDB` with `vpcCertBoost = perasWeight params`.
4. Chain selection reads `getWeightSnapshot`, finds the attacker-injected boost, and may prefer the attacker's chosen chain over the honest canonical chain.

This maps directly to the allowed impact: *"Critical. Bypass of … certificate … validation … that enables unauthorized … certificate acceptance."* and *"High. Chain selection … bug that lets an unprivileged peer make an honest node prefer a non-canonical or less-secure chain."*

---

### Likelihood Explanation

**High.** The ObjectDiffusion mini-protocol is a standard node-to-node protocol reachable by any peer without authentication. The stub is the universal instance for all block types. No special keys, stake, or operator access are required — only the ability to open a connection and speak the protocol.

---

### Recommendation

1. Replace the stub `validatePerasCert` with a real implementation that verifies the aggregate BLS signature over the claimed voters, checks quorum threshold against the epoch stake distribution, and validates round/slot bounds before returning `Right`.
2. Replace the stub `validatePerasVote` with an implementation that verifies the per-voter cryptographic signature (once the `PerasVote` type is enriched with a signature field, tracked in issue #120).
3. Until real validation is implemented, gate the ObjectDiffusion inbound handlers for Peras objects behind a feature flag that is disabled on any network where Peras is not yet active, so the stubs are never reachable from untrusted peers.

---

### Proof of Concept

Connect to a victim node as an unprivileged peer and send a batch of `PerasCert` objects via the ObjectDiffusion mini-protocol. Each cert can name any block point and any round number. The following deterministic reasoning reproduces the acceptance:

```
-- Attacker constructs:
craftedCert = PerasCert
  { pcCertRound      = <any PerasRoundNo>
  , pcCertBoostedBlock = <Point of attacker-chosen block>
  }

-- Node receives it via ObjectDiffusion inbound handler.
-- processCerts calls:
validatePerasCert mkPerasParams craftedCert
-- => unconditionally returns:
Right (ValidatedPerasCert { vpcCert = craftedCert, vpcCertBoost = perasWeight mkPerasParams })

-- The cert is stored in PerasCertDB.
-- getWeightSnapshot now includes the boost for the attacker's block.
-- Chain selection prefers the attacker's chain.
```

Repeat for as many rounds as desired. Each injected certificate costs only the gas of a network message, directly analogous to the zero-cost unlimited NFT minting in the reference report.

```haskell
processCerts systemTime alreadyInDbSTM validateCert addCert certs = do
  alreadyInDb <- atomically alreadyInDbSTM
  let certsNotAlreadyInDb = filter (not . (`Set.member` alreadyInDb) . getPerasCertRound) certs
  now <- systemTimeCurrent systemTime
  case partitionEithers (validateCert <$> certsNotAlreadyInDb) of
    -- All certs are valid => add them to the pool
    ([], validatedCerts) ->
      mapM_
        (addCert . WithArrivalTime now)
        validatedCerts
```
