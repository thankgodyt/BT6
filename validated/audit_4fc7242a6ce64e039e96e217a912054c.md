### Title
`implVerifyCert` Accepts Sub-Quorum Certificates Without Stake Threshold Check - (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/EveryoneVotes.hs` and `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/WFALS.hs`)

---

### Summary

Both `implVerifyCert` implementations in `EveryoneVotes` and `WFALS` verify that each voter in a certificate is a valid committee member and that the aggregate BLS signature is cryptographically valid, but neither checks that the total stake represented by those voters meets the Peras quorum threshold. An unprivileged pool operator with any positive stake can craft a certificate containing only their own vote, produce a valid single-key aggregate signature, and have it accepted by `verifyCert`. Because Peras certificates directly influence chain-weight boosting, accepting a sub-quorum certificate allows unauthorized chain-weight manipulation.

---

### Finding Description

`implVerifyCert` in `EveryoneVotes.hs` traverses the voter set, confirms each `SeatIndex` maps to a valid committee member with positive stake, aggregates their verification keys, and checks the aggregate BLS signature: [1](#0-0) 

The function returns `Right members` on success. There is no call to `stakeAboveThreshold` or any equivalent quorum check anywhere in this path.

The identical structural omission exists in `WFALS.implVerifyCert`: [2](#0-1) 

The quorum check (`stakeAboveThreshold`) exists only during certificate **forging**, inside `votesReachQuorum`, which is called from `updateCandidateVoteState`: [3](#0-2) 

This check is entirely absent from the verification path. The `verifyCert` method in the `CryptoSupportsVotingCommittee` class is the sole interface for certificate verification: [4](#0-3) 

The analog to the `WithdrawTrieVerifier` report is exact: the report's verifier does not check proof **length** (number of Merkle nodes), allowing a shortened proof terminating at an intermediate node to pass. Here, `implVerifyCert` does not check voter **stake total** against the quorum threshold, allowing a certificate with an arbitrarily small voter set to pass.

---

### Impact Explanation

Peras certificates boost the chain weight of the block they certify: [5](#0-4) 

A certificate accepted by `verifyCert` without a quorum check can be used to boost a block that was never actually endorsed by a quorum of stake. This allows an attacker to make an honest node prefer a non-canonical chain by artificially inflating its Peras weight, constituting a chain-selection manipulation. This falls under the **High** impact category: a chain-selection bug that lets an unprivileged peer make an honest node prefer a non-canonical or less-secure chain beyond the intended security assumptions.

---

### Likelihood Explanation

Any pool operator with positive stake is a valid committee member in `EveryoneVotes` (all pools with positive stake are eligible). Such an operator can:
1. Construct a `EveryoneVotesCert` containing only their own `SeatIndex`.
2. Produce a valid single-key BLS aggregate signature (degenerate aggregate = their own signature).
3. Transmit this certificate to a peer via the Peras certificate diffusion miniprotocol (`processCerts` / `ObjectDiffusion`).

The attack requires no privileged access, no key compromise, and no stake majority. Any registered pool operator can execute it. Likelihood is **High**.

---

### Recommendation

Add a quorum check inside `implVerifyCert` in both `EveryoneVotes.hs` and `WFALS.hs`, after collecting the `members` list, by summing the stake of all verified voters and asserting it exceeds the configured quorum threshold (analogous to `stakeAboveThreshold` used in `votesReachQuorum`). The `VotingCommittee` context already carries the stake distribution needed to perform this check. The `verifyCert` interface in `Class.hs` should be documented to require that implementations enforce the quorum invariant, not merely the cryptographic validity of individual voter entries.

---

### Proof of Concept

1. Pool `P` has stake `s` where `s < quorumThreshold`.
2. `P` is a valid member of the `EveryoneVotes` committee (positive stake suffices).
3. `P` constructs:
   ```
   cert = EveryoneVotesCert
     electionId
     candidate
     (NESet.singleton seatIndex_P)   -- only P's seat
     (aggregateVoteSignatures [sig_P]) -- single-key aggregate = P's own sig
   ```
4. `P` sends `cert` to an honest node via the Peras cert diffusion path.
5. `implVerifyCert committee cert` succeeds:
   - `getCandidateIfSeatWithinBounds seatIndex_P` returns `Just (_, pubKey_P, s, _)` ✓
   - `nonZero s` succeeds (s > 0) ✓
   - `aggregateVoteVerificationKeys [vk_P]` succeeds ✓
   - `verifyAggregateVoteSignature aggVK electionId candidate aggSig` succeeds ✓
   - **No quorum check is performed.**
6. The certificate is accepted and stored; the targeted block receives a Peras weight boost, influencing chain selection in favour of the attacker's preferred chain without genuine quorum. [1](#0-0) [6](#0-5) [7](#0-6)

-- | Verify a certificate attesting the winner of a given election
implVerifyCert ::
  forall crypto.
  ( CryptoSupportsAggregateVoteSigning crypto
  , CryptoSupportsBatchVRFVerification crypto
  ) =>
  VotingCommittee crypto WFALS ->
  Cert crypto WFALS ->
  Either
    (VotingCommitteeError crypto WFALS)
    (NE [EligibilityWitness crypto WFALS])
implVerifyCert committee = \case
  WFALSCert electionId candidate voters aggSig -> do
    -- Traverse the list of voters in ascending seat index order, collecting:
    -- 1. their membership status
    -- 2. their vote verification keys (to verify the aggregate vote signature)
    -- 3. optionally, their VRF verification keys and outputs (to verify the
    --    aggregate VRF output for non-persistent voters, if any)
    (members, voteVerificationKeys, optionalVRFKeysAndOutputs) <-
      fmap nonEmptyUnzip3 . flip traverse (NEMap.toAscList voters) $ \case
        -- Persistent voter
        (seatIndex, Nothing)
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
          , isPersistentMember seatIndex committee -> do
              let voterVoteVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              pure
                ( WFALSPersistentMember
                    seatIndex
                    voterStake
                , voterVoteVerificationKey
                , Nothing
                )
          | otherwise ->
              Left (NotAPersistentMember seatIndex)
        -- Non-persistent voter
        (seatIndex, Just vrfOutput)
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
          , not (isPersistentMember seatIndex committee) -> do
              let voterVoteVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              let voterVRFVerificationKey =
                    getVRFVerificationKey (Proxy @crypto) voterPublicKey
              let numSeats =
                    localSortitionNumSeats
                      (nonPersistentCommitteeSize committee)
                      (totalNonPersistentStake committee)
                      voterStake
                      (normalizeVRFOutput vrfOutput)
              case nonZero numSeats of
                Nothing ->
                  Left (ZeroNonPersistentSeats seatIndex)
                Just nonZeroNumSeats ->
                  pure
                    ( WFALSNonPersistentMember
                        seatIndex
                        voterStake
                        vrfOutput
                        nonZeroNumSeats
                    , voterVoteVerificationKey
                    , Just (voterVRFVerificationKey, vrfOutput)
                    )
          | otherwise ->
              Left (NotANonPersistentMember seatIndex)

    -- Verify aggregate signature
    aggVerificationKey <-
      bimap CryptoError id $
        aggregateVoteVerificationKeys
          (Proxy @crypto)
          voteVerificationKeys
    bimap InvalidCertSignature id $
      verifyAggregateVoteSignature
        (Proxy @crypto)
        aggVerificationKey
        electionId
        candidate
        aggSig

    -- Verify VRF outputs for non-persistent voters (if any)
    case catMaybes (NonEmpty.toList optionalVRFKeysAndOutputs) of
      -- No non-persistent voters => no VRF outputs to verify
      [] -> do
        pure ()
      -- Some non-persistent voters => verify their aggregate VRF outputs
      vrfKeysAndOutputs -> do
        let (vrfVerificationKeys, vrfOutputs) =
              munzip
                . NonEmpty.fromList -- safe 'vrfKeysAndOutputs' /= []
                $ vrfKeysAndOutputs
        bimap InvalidCertSignature id $
          batchVerifyVRFOutputs
            vrfVerificationKeys
            ( mkVRFElectionInput
                @crypto
                (epochNonce committee)
                electionId
            )
            vrfOutputs

    -- Return the list of voters attesting the election winner
    pure members

-- | Check whether a given vote stake is above the quorum threshold.
--
-- TODO: this function assumes that the 'PerasVoteStake' and the quorum
-- threshold used in 'PerasParams' are expressed in the same units. That is,
-- both are either absolute or relative (normalized) values. Under the current
-- current implementation of 'PerasParams', this function only makes sense when
-- both values are relative (normalized) values, so we should either normalize
-- the 'PerasVoteStake' before calling this function, or change this function to
-- accept a stake distribution and perform the normalization internally.
stakeAboveThreshold :: PerasParams -> PerasVoteStake -> Bool
stakeAboveThreshold params voteStake =
  stake >= quorumThreshold + safetyMargin
 where
  stake =
    unPerasVoteStake voteStake
  quorumThreshold =
    unPerasQuorumStakeThreshold
      (perasQuorumStakeThreshold params)
  safetyMargin =
    unPerasQuorumStakeThresholdSafetyMargin
      (perasQuorumStakeThresholdSafetyMargin params)

votesReachQuorum ::
  StandardHash blk =>
  PerasCfg blk ->
  [ValidatedPerasVote blk] ->
  Maybe (ValidatedPerasVotesWithQuorum blk)
votesReachQuorum cfg votes =
  case votes of
    -- We need at least one vote to determine who these votes are for, so we
    -- can't vacuously reach a quorum, even if the quorum threshold is 0.
    [] -> Nothing
    -- If we have at least one vote, we must check that all votes are for the
    -- same target, and that their total stake of is above the quorum threshold.
    (v0 : vs)
      | not (allVotesMatchTarget v0 vs) ->
          Nothing
      | not votesHaveEnoughStake ->
          Nothing
      | otherwise ->
          Just
            ValidatedPerasVotesWithQuorum
              { vpvqTarget = getPerasVoteTarget v0
              , vpvqVotes = v0 :| vs
              , vpvqPerasCfg = cfg
              }
 where
  totalVoteStake =
    mconcat (vpvVoteStake <$> votes)
  votesHaveEnoughStake =
    stakeAboveThreshold cfg totalVoteStake
