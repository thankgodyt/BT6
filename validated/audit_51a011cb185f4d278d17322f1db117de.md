### Title
Peras Certificate and Vote Validation Unconditionally Accepts Any Input Without Cryptographic Verification - (`File: ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Block/SupportsPeras.hs`)

---

### Summary

The universal `BlockSupportsPeras` instance provides stub implementations of `validatePerasCert` and `validatePerasVote` that skip all cryptographic and semantic validation. `validatePerasCert` unconditionally returns `Right` for any certificate, and `validatePerasVote` only checks stake-distribution membership without verifying the BLS vote signature. An unprivileged peer can inject crafted Peras certificates or votes over the network that will be accepted and stored, allowing manipulation of Peras-boosted chain selection.

---

### Finding Description

In `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Block/SupportsPeras.hs`, a universal `instance StandardHash blk => BlockSupportsPeras blk` is declared as a compilation placeholder. Its `validatePerasCert` implementation unconditionally returns `Right` regardless of the certificate's content:

```haskell
-- TODO: perform actual validation against all
-- possible 'PerasValidationErr' variants
-- see https://github.com/tweag/cardano-peras/issues/120
validatePerasCert params cert =
  Right
    ValidatedPerasCert
      { vpcCert = cert
      , vpcCertBoost = perasWeight params
      }
```

No signature is verified, no quorum threshold is checked, and no voter eligibility is confirmed. Any `PerasCert` value, regardless of its cryptographic content, is promoted to a `ValidatedPerasCert` and assigned a full chain-selection boost weight. [1](#0-0) 

Similarly, `validatePerasVote` only checks whether the voter ID appears in the stake distribution; it never verifies the BLS vote signature:

```haskell
validatePerasVote _params stakeDistr vote
  | Just stake <- lookupPerasVoteStake vote stakeDistr =
      Right ValidatedPerasVote { vpvVote = vote, vpvVoteStake = stake }
  | otherwise =
      Left PerasValidationErr
``` [2](#0-1) 

This universal instance (`instance StandardHash blk => BlockSupportsPeras blk`) applies to all block types for which no more-specific instance exists. [3](#0-2) 

The same gap is acknowledged in `PerasVoteDB/Impl.hs` and `PerasCertDB/Impl.hs`, both of which carry the same TODO referencing issue #120: [4](#0-3) [5](#0-4) 

---

### Impact Explanation

Peras certificates directly influence chain selection by assigning a configurable `PerasWeight` boost to the block they reference. A `ValidatedPerasCert` produced by the stub `validatePerasCert` carries the full `perasWeight params` boost. An attacker who injects a crafted certificate pointing to an adversarial block causes the local node to prefer that block over the honest canonical chain, constituting a chain-selection safety failure.

For votes: fake votes with valid voter IDs but forged BLS signatures pass `validatePerasVote` and are aggregated into `PerasRoundVoteState`. If enough fake votes accumulate, `updatePerasRoundVoteStates` will forge a certificate for an adversary-chosen block, again corrupting chain selection. [6](#0-5) 

---

### Likelihood Explanation

The network-facing entry point is `processVotes` in `ObjectPool/PerasVote.hs`, which is called for every batch of inbound Peras votes received from a peer. It calls `validatePerasVote` directly and, on success, timestamps and stores each vote. No additional cryptographic gate exists between the network and the vote store. [7](#0-6) 

For certificates, `validatePerasCert` is the sole validation gate before a certificate is stored and its boost applied. Any peer that can send a `PerasCert` message can trigger this path. No stake majority, key compromise, or operator action is required.

---

### Recommendation

1. **`validatePerasCert`**: Implement full cryptographic verification using the committee's `implVerifyCert` (already implemented for both `EveryoneVotes` and `WFALS` schemes). Verify the aggregate BLS signature, confirm each voter's eligibility, and check that the voter set meets the quorum threshold before returning `Right`. [8](#0-7) 

2. **`validatePerasVote`**: Verify the BLS vote signature against the voter's public key (retrieved from the committee's stake distribution) before accepting the vote as `ValidatedPerasVote`. [9](#0-8) 

3. Remove or gate the universal `instance StandardHash blk => BlockSupportsPeras blk` so that block types without a proper implementation cannot silently fall through to the stub.

---

### Proof of Concept

1. Connect to a node running the Peras-enabled code as an unprivileged peer.
2. Construct a `PerasCert` with `pcCertRound = <target round>` and `pcCertBoostedBlock = <adversarial block point>`. The `PerasCert` data type in the universal instance carries no BLS signature field, so no valid cryptographic material is needed. [10](#0-9) 
3. Send the certificate to the node. `validatePerasCert` returns `Right ValidatedPerasCert{vpcCertBoost = perasWeight params}` unconditionally.
4. The certificate is stored in `PerasCertDB` and its boost is applied to chain selection, causing the node to prefer the adversarial block over the honest canonical tip.

updatePerasRoundVoteStates ::
  forall blk.
  StandardHash blk =>
  WithArrivalTime (ValidatedPerasVote blk) ->
  PerasCfg blk ->
  Map PerasRoundNo (PerasRoundVoteState blk) ->
  Either
    (UpdateRoundVoteStateError blk)
    (PerasRoundVoteState blk, Map PerasRoundNo (PerasRoundVoteState blk))
updatePerasRoundVoteStates vote cfg =
  alterMapAndReturnUpdatedValue
    updateMaybePerasRoundVoteState
    (getPerasVoteRound vote)
 where
  -- We use the Functor instance of `Compose (Either e) ((,) s)` ≅
  -- `λt. Either e (s, t)` in `Map.alterF`. That way, we can return both the
  -- updated map and the updated leaf in one pass, and still handle errors.
  alterMapAndReturnUpdatedValue ::
    Ord k =>
    (Maybe a -> Either e (a, a)) ->
    k ->
    Map k a ->
    Either e (a, Map k a)
  alterMapAndReturnUpdatedValue f k =
    getCompose . Map.alterF (fmap Just . (Compose . f)) k

  -- If there is no existing state for the vote's round, create a fresh one.
  existingOrFreshRoundVoteState ::
    Maybe (PerasRoundVoteState blk) ->
    PerasRoundVoteState blk
  existingOrFreshRoundVoteState =
    fromMaybe (freshRoundVoteState (getPerasVoteRound vote))

  -- Update the round state, creating a fresh one if necessary, and returning
  -- the updated state.
  updateMaybePerasRoundVoteState ::
    Maybe (PerasRoundVoteState blk) ->
    Either
      (UpdateRoundVoteStateError blk)
      (PerasRoundVoteState blk, PerasRoundVoteState blk)
  updateMaybePerasRoundVoteState mRoundState = do
    let roundState = existingOrFreshRoundVoteState mRoundState
    newRoundState <- updatePerasRoundVoteState vote cfg roundState
    pure (newRoundState, newRoundState)

processVotes ::
  MonadSTM m =>
  SystemTime m ->
  STM m (Set (PerasVoteId blk)) ->
  (PerasVote blk -> STM m (Either (PerasValidationErr blk) (ValidatedPerasVote blk))) ->
  (WithArrivalTime (ValidatedPerasVote blk) -> m ()) ->
  [PerasVote blk] ->
  m ()
processVotes systemTime alreadyInDbSTM validateVote addVote votes = do
  validationResults <- atomically $ do
    alreadyInDb <- alreadyInDbSTM
    let votesNotAlreadyInDb = filter (not . (`Set.member` alreadyInDb) . getPerasVoteId) votes
    mapM validateVote votesNotAlreadyInDb
  now <- systemTimeCurrent systemTime
  case partitionEithers validationResults of
    -- All votes are valid => add them to the pool
    ([], validatedVotes) ->
      mapM_
        (addVote . WithArrivalTime now)
        validatedVotes
    -- Some votes are invalid => reject the whole batch
    --
    -- N.B. it has been requested in PR review
    -- https://github.com/IntersectMBO/ouroboros-consensus/pull/1768#discussion_r2747873186
    -- to gather all validation errors and report them together in the exception
    -- rather than just report the first error encountered.
    -- This assumes that vote validation is cheap, which may not be true in
    -- practice depending on the actual crypto/committee selection scheme.
    -- Hence we may revisit this to lazily abort validation upon the first error
    -- encountered.
    (errs, _) ->
      throw (PerasVoteValidationError errs)
