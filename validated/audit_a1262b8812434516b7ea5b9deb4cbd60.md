### Title
`implVerifyCert` Does Not Verify Quorum Stake Threshold, Enabling Sub-Quorum Certificate Acceptance — (File: `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/EveryoneVotes.hs`, `ouroboros-consensus/src/ouroboros-consensus/Ouroboros/Consensus/Committee/WFALS.hs`)

---

### Summary

Both `implVerifyCert` implementations for the `EveryoneVotes` and `WFALS` committee schemes verify individual voter membership and the aggregate cryptographic signature, but **never check that the total stake of the certificate's voters meets the quorum threshold**. A crafted certificate containing a single valid voter with minimal stake passes all verification checks. This is the direct analog of the external report: individual member validity is checked, but the minimum threshold of participation is not enforced.

---

### Finding Description

The `BlockSupportsPeras` typeclass defines `validatePerasCert` as the inbound certificate validation entry point. The production instance in `SupportsPeras.hs` is an explicit stub:

```haskell
-- TODO: perform actual validation against all possible 'PerasValidationErr' variants
validatePerasCert params cert =
  Right ValidatedPerasCert { vpcCert = cert, vpcCertBoost = perasWeight params }
``` [1](#0-0) 

This stub is wired directly into the production inbound certificate processing path via `makePerasCertPoolWriterFromChainDB`, which is called from the node-to-node handler:

```haskell
(validatePerasCert mkPerasParams)  -- TODO replace when actual plumbing is in place
``` [2](#0-1) [3](#0-2) 

This means **any certificate received from any peer is unconditionally accepted** today.

The intended production verification functions are `implVerifyCert` in `EveryoneVotes.hs` and `WFALS.hs`. Both perform the following checks:

**`EveryoneVotes.implVerifyCert`** (lines 301–340):
1. Each voter's seat index is within bounds.
2. Each voter has non-zero stake.
3. The aggregate vote signature is valid. [4](#0-3) 

**`WFALS.implVerifyCert`** (lines 494–586):
1. Each voter is a valid persistent or non-persistent member.
2. VRF outputs for non-persistent voters are valid.
3. The aggregate vote signature is valid. [5](#0-4) 

**Neither function calls `stakeAboveThreshold`** to verify that the total stake of the certificate's voters meets the quorum threshold. The `stakeAboveThreshold` function exists and is correctly used during certificate *forging* (in `votesReachQuorum` and `updateCandidateVoteState`), but is entirely absent from certificate *verification*:

```haskell
stakeAboveThreshold :: PerasParams -> PerasVoteStake -> Bool
stakeAboveThreshold params voteStake =
  stake >= quorumThreshold + safetyMargin
``` [6](#0-5) 

The quorum threshold is configured at `3/4` of total stake plus a safety margin: [7](#0-6) 

The `stakeAboveThreshold` call is present in `votesReachQuorum` (used when forging a cert) but absent from both `implVerifyCert` implementations: [8](#0-7) 

---

### Impact Explanation

In Peras, a `ValidatedPerasCert` grants a `PerasWeight` boost (default: 15) to a block's chain selection weight. Chain selection uses this boost to prefer boosted blocks over unboosted ones. If an adversary can inject a certificate that passes verification with only a single voter (or any sub-quorum set of voters), they can artificially boost an arbitrary block's chain weight, causing honest nodes to prefer a non-canonical chain. This is a **High** impact chain selection bug: an unprivileged peer can make an honest node prefer a non-canonical or adversarially chosen chain beyond the intended security assumptions of the Peras protocol. [9](#0-8) 

---

### Likelihood Explanation

The attacker-controlled entry path is fully reachable today: any peer connected via the Peras certificate diffusion mini-protocol can send a crafted `PerasCert` to `processCerts`, which calls `validatePerasCert` (the stub that always returns `Right`), and the certificate is immediately added to the `ChainDB` and triggers chain selection. No stake, no keys, and no quorum are required. Even after the stub is replaced with a call to `implVerifyCert`, the missing `stakeAboveThreshold` check means a certificate with a single valid voter still passes. [10](#0-9) 

---

### Recommendation

1. **Immediate**: Replace the `validatePerasCert` stub with a real implementation that calls `implVerifyCert` (or equivalent) and enforces the quorum stake threshold.
2. **In `implVerifyCert` (both `EveryoneVotes` and `WFALS`)**: After collecting the `EligibilityWitness` list, compute the total stake of all voters and call `stakeAboveThreshold` (or the committee-scheme-equivalent). Return a new error variant (e.g., `InsufficientQuorumStake`) if the threshold is not met.
3. Ensure the quorum check uses the same normalized stake units as `PerasParams` to avoid the unit mismatch noted in the existing `stakeAboveThreshold` TODO comment. [11](#0-10) 

---

### Proof of Concept

**Attacker steps (current production code):**

1. Connect to a Cardano node running Peras via the node-to-node protocol.
2. Send a `PerasCert` with an arbitrary `pcCertRound` and `pcCertBoostedBlock` pointing to an adversarially chosen block.
3. `processCerts` calls `validatePerasCert mkPerasParams` on the cert.
4. The stub returns `Right ValidatedPerasCert { vpcCertBoost = perasWeight mkPerasParams }` unconditionally.
5. The cert is added to the `ChainDB` via `ChainDB.addPerasCertAsync`, triggering chain selection with a boost of 15 for the adversary's chosen block.

**After stub is replaced (missing quorum check in `implVerifyCert`):**

1. Craft a `WFALSCert` containing a single persistent voter (seat index 0) with minimal stake, a valid aggregate signature over the adversary's chosen block, and no VRF outputs.
2. `implVerifyCert` verifies: seat 0 is within bounds ✓, voter has non-zero stake ✓, aggregate signature is valid ✓.
3. No `stakeAboveThreshold` check is performed.
4. The certificate is accepted and boosts the adversary's block, causing honest nodes to prefer it over the canonical chain. [4](#0-3) [5](#0-4)

processCerts ::
  MonadSTM m =>
  SystemTime m ->
  STM m (Set PerasRoundNo) ->
  (PerasCert blk -> Either (PerasValidationErr blk) (ValidatedPerasCert blk)) ->
  (WithArrivalTime (ValidatedPerasCert blk) -> m ()) ->
  [PerasCert blk] ->
  m ()
processCerts systemTime alreadyInDbSTM validateCert addCert certs = do
  alreadyInDb <- atomically alreadyInDbSTM
  let certsNotAlreadyInDb = filter (not . (`Set.member` alreadyInDb) . getPerasCertRound) certs
  now <- systemTimeCurrent systemTime
  case partitionEithers (validateCert <$> certsNotAlreadyInDb) of
    -- All certs are valid => add them to the pool
    ([], validatedCerts) ->
      mapM_
        (addCert . WithArrivalTime now)
        validatedCerts

implVerifyCert committee = \case
  EveryoneVotesCert electionId candidate voters aggSig -> do
    -- Traverse the list of voters in ascending seat index order, collecting:
    -- 1. their membership status
    -- 2. their vote verification keys (to verify the aggregate vote signature)
    (members, voteVerificationKeys) <-
      fmap munzip . flip traverse (NESet.toAscList voters) $ \case
        seatIndex
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee) -> do
              let voterVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              case nonZero voterStake of
                Nothing ->
                  Left (PoolHasNoStake seatIndex)
                Just nonZeroVoterStake ->
                  pure
                    ( EveryoneVotesMember
                        seatIndex
                        nonZeroVoterStake
                    , voterVerificationKey
                    )
          | otherwise ->
              Left (MissingSeatIndex seatIndex)
    -- Verify aggregate signature
    aggVerificationKey <-
      bimap CryptoError id $ do
        aggregateVoteVerificationKeys
          (Proxy @crypto)
          voteVerificationKeys
    bimap InvalidCertSignature id $
      verifyAggregateVoteSignature
        (Proxy @crypto)
        aggVerificationKey
        electionId
        candidate
        aggSig

    -- Return the list of voters attesting the election winner
    pure members

implVerifyCert committee = \case
  WFALSCert electionId candidate voters aggSig -> do
    -- Traverse the list of voters in ascending seat index order, collecting:
    -- 1. their membership status
    -- 2. their vote verification keys (to verify the aggregate vote signature)
    -- 3. optionally, their VRF verification keys and outputs (to verify the
    --    aggregate VRF output for non-persistent voters, if any)
    (members, voteVerificationKeys, optionalVRFKeysAndOutputs) <-
      fmap nonEmptyUnzip3 . flip traverse (NEMap.toAscList voters) $ \case
        -- Persistent voter
        (seatIndex, Nothing)
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
          , isPersistentMember seatIndex committee -> do
              let voterVoteVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              pure
                ( WFALSPersistentMember
                    seatIndex
                    voterStake
                , voterVoteVerificationKey
                , Nothing
                )
          | otherwise ->
              Left (NotAPersistentMember seatIndex)
        -- Non-persistent voter
        (seatIndex, Just vrfOutput)
          | Just (_, voterPublicKey, voterStake, _) <-
              getCandidateIfSeatWithinBounds seatIndex (extWFAStakeDistr committee)
          , not (isPersistentMember seatIndex committee) -> do
              let voterVoteVerificationKey =
                    getVoteVerificationKey (Proxy @crypto) voterPublicKey
              let voterVRFVerificationKey =
                    getVRFVerificationKey (Proxy @crypto) voterPublicKey
              let numSeats =
                    localSortitionNumSeats
                      (nonPersistentCommitteeSize committee)
                      (totalNonPersistentStake committee)
                      voterStake
                      (normalizeVRFOutput vrfOutput)
              case nonZero numSeats of
                Nothing ->
                  Left (ZeroNonPersistentSeats seatIndex)
                Just nonZeroNumSeats ->
                  pure
                    ( WFALSNonPersistentMember
                        seatIndex
                        voterStake
                        vrfOutput
                        nonZeroNumSeats
                    , voterVoteVerificationKey
                    , Just (voterVRFVerificationKey, vrfOutput)
                    )
          | otherwise ->
              Left (NotANonPersistentMember seatIndex)

    -- Verify aggregate signature
    aggVerificationKey <-
      bimap CryptoError id $
        aggregateVoteVerificationKeys
          (Proxy @crypto)
          voteVerificationKeys
    bimap InvalidCertSignature id $
      verifyAggregateVoteSignature
        (Proxy @crypto)
        aggVerificationKey
        electionId
        candidate
        aggSig

    -- Verify VRF outputs for non-persistent voters (if any)
    case catMaybes (NonEmpty.toList optionalVRFKeysAndOutputs) of
      -- No non-persistent voters => no VRF outputs to verify
      [] -> do
        pure ()
      -- Some non-persistent voters => verify their aggregate VRF outputs
      vrfKeysAndOutputs -> do
        let (vrfVerificationKeys, vrfOutputs) =
              munzip
                . NonEmpty.fromList -- safe 'vrfKeysAndOutputs' /= []
                $ vrfKeysAndOutputs
        bimap InvalidCertSignature id $
          batchVerifyVRFOutputs
            vrfVerificationKeys
            ( mkVRFElectionInput
                @crypto
                (epochNonce committee)
                electionId
            )
            vrfOutputs

    -- Return the list of voters attesting the election winner
    pure members
```
