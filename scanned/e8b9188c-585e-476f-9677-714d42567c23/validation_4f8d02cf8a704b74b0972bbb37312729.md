### Title
Native Fee Tokens Permanently Locked in Starknet OmniBridge — No Withdrawal Function - (File: `starknet/src/omni_bridge.cairo`)

### Summary

The Starknet `OmniBridge` contract accepts STRK tokens as `native_fee` during `init_transfer`, transferring them into the contract itself. However, the contract exposes no function to withdraw or recover these accumulated STRK tokens. All native fees paid by bridge users on Starknet are permanently locked.

### Finding Description

In `starknet/src/omni_bridge.cairo`, the `init_transfer` function accepts a `native_fee` parameter. When non-zero, it pulls STRK tokens from the caller directly into the contract address:

```cairo
if native_fee > 0 {
    let native_token = self.strk_token_address.read();
    let success = IERC20Dispatcher { contract_address: native_token }
        .transfer_from(caller, get_contract_address(), native_fee.into());
    assert(success, 'ERR_FEE_TRANSFER_FAILED');
}
``` [1](#0-0) 

The entire `IOmniBridge` interface and the full contract implementation contain no function to withdraw ERC20 tokens (including STRK) from the contract: [2](#0-1) 

The only state-mutating functions exposed are `log_metadata`, `deploy_token`, `fin_transfer`, `init_transfer`, `upgrade_token`, `set_pause_flags`, and `pause_all`. None of these transfer STRK or any ERC20 out of the contract to a fee recipient or admin. The contract storage also holds no fee-recipient address field. [3](#0-2) 

### Impact Explanation

Every STRK `native_fee` paid by any user calling `init_transfer` on Starknet is irrecoverably locked in the `OmniBridge` contract. The protocol and relayers can never retrieve these funds. This is a permanent, cumulative loss of bridging fee revenue — a direct fee mis-accounting that changes protocol balances. The magnitude grows with every bridge transfer that includes a non-zero `native_fee`.

### Likelihood Explanation

High. Any unprivileged bridge user who calls `init_transfer` with `native_fee > 0` triggers the loss. This is the standard path for paying relayer fees on Starknet. No special conditions, admin access, or attacker sophistication is required — normal protocol usage causes the loss.

### Recommendation

Add a privileged withdrawal function (restricted to `DEFAULT_ADMIN_ROLE` or a dedicated fee-recipient address) that transfers accumulated STRK (and any other ERC20 tokens) out of the contract:

```cairo
fn withdraw_fees(ref self: ContractState, token: ContractAddress, recipient: ContractAddress, amount: u128) {
    self.accesscontrol.assert_only_role(DEFAULT_ADMIN_ROLE);
    let success = IERC20Dispatcher { contract_address: token }
        .transfer(recipient, amount.into());
    assert(success, 'ERR_WITHDRAW_FAILED');
}
```

Alternatively, route `native_fee` directly to a designated fee-recipient address at the time of `init_transfer` rather than holding it in the contract.

### Proof of Concept

1. User calls `init_transfer` on the Starknet `OmniBridge` with `native_fee = 1_000_000_000_000_000_000` (1 STRK).
2. The contract executes `transfer_from(caller, get_contract_address(), 1e18)` — STRK enters the contract.
3. The bridge event is emitted; the transfer proceeds normally on-chain.
4. The relayer or protocol attempts to claim the STRK fee — no function exists to do so.
5. The 1 STRK is permanently locked. Repeated across all Starknet bridge users, the total locked STRK grows unboundedly. [4](#0-3)

        fn init_transfer(
            ref self: ContractState,
            token_address: ContractAddress,
            amount: u128,
            fee: u128,
            native_fee: u128,
            recipient: ByteArray,
            message: ByteArray,
        ) {
            assert(!_is_paused(@self, PAUSE_INIT_TRANSFER), 'ERR_INIT_TRANSFER_PAUSED');

            assert(amount > 0, 'ERR_ZERO_AMOUNT');
            assert(fee < amount, 'ERR_INVALID_FEE');

            let origin_nonce = self.current_origin_nonce.read() + 1;
            self.current_origin_nonce.write(origin_nonce);

            let caller = get_caller_address();

            if self.is_bridge_token(token_address) {
                IBridgeTokenDispatcher { contract_address: token_address }
                    .burn(caller, amount.into());
            } else {
                let success = IERC20Dispatcher { contract_address: token_address }
                    .transfer_from(caller, get_contract_address(), amount.into());
                assert(success, 'ERR_TRANSFER_FROM_FAILED');
            }

            if native_fee > 0 {
                let native_token = self.strk_token_address.read();
                let success = IERC20Dispatcher { contract_address: native_token }
                    .transfer_from(caller, get_contract_address(), native_fee.into());
                assert(success, 'ERR_FEE_TRANSFER_FAILED');
            }

            self
                .emit(
                    Event::InitTransfer(
                        InitTransfer {
                            sender: caller,
                            token_address,
                            origin_nonce,
                            amount,
                            fee,
                            native_fee,
                            recipient,
                            message,
                        },
                    ),
                )
        }
