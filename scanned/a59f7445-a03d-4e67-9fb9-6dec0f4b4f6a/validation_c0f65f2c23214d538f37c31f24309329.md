### Title
Bridged Native ETH Permanently Frozen When Recipient Contract Cannot Accept ETH - (File: `evm/src/omni-bridge/contracts/OmniBridge.sol`)

### Summary
In `OmniBridge.sol`, when finalizing a native-ETH transfer (`tokenAddress == address(0)`), the contract sends ETH to the recipient via a low-level call. If the recipient is a contract that cannot accept ETH, the call fails and the entire transaction reverts. Because there is no alternative withdrawal path or admin rescue function, the ETH is permanently locked in the bridge with no recovery mechanism.

### Finding Description
In `finTransfer()`, the native-ETH branch executes:

```solidity
(bool success, ) = payload.recipient.call{value: payload.amount}("");
if (!success) revert FailedToSendEther();
``` [1](#0-0) 

The `revert FailedToSendEther()` rolls back the entire transaction, including the earlier `completedTransfers[payload.destinationNonce] = true` state write. [2](#0-1) 

This means the nonce is never consumed and the relayer can retry indefinitely — but every retry will revert for the same reason. The ETH remains locked in the bridge contract with no admin rescue, no pull-payment fallback, and no alternative finalization path.

### Impact Explanation
Any user who bridges native ETH from NEAR to an EVM contract address that lacks a `receive()` or `fallback()` function (e.g., a multisig, DAO treasury, or proxy contract that does not forward ETH) will have their bridged ETH permanently frozen inside `OmniBridge`. There is no on-chain mechanism to redirect the funds to a different address or recover them. This constitutes permanent freezing of bridged funds.

### Likelihood Explanation
Realistic. Users routinely bridge assets to smart contract wallets, multisigs (e.g., Gnosis Safe variants that require `receive()` to be explicitly present), DAO contracts, or protocol treasuries. A contract that does not implement `receive()` is common. Additionally, a contract could be deployed at a CREATE2-predicted address after the NEAR-side `init_transfer` is submitted but before `finTransfer` is called on EVM, allowing a third party to occupy the recipient address with a non-ETH-accepting contract.

### Recommendation
Implement a pull-payment (withdrawal) pattern for native ETH: instead of pushing ETH directly to the recipient in `finTransfer`, credit the amount to a per-address claimable balance mapping and let the recipient pull it. Alternatively, add an admin-controlled rescue function that can redirect stuck ETH to a new recipient address when the original recipient is provably unable to accept it, gated by the same MPC/signature verification used for normal finalization.

### Proof of Concept
1. User on NEAR calls `init_transfer` targeting a NEAR→ETH bridge of native ETH, with `recipient` set to a Solidity contract address `C` that has no `receive()` function.
2. The NEAR bridge locks the user's wrapped-ETH tokens and emits an `InitTransfer` event.
3. A relayer calls `finTransfer` on `OmniBridge` with `payload.tokenAddress = address(0)` and `payload.recipient = C`.
4. `completedTransfers[nonce] = true` is written, then `C.call{value: amount}("")` is executed.
5. `C` has no `receive()`, so the call returns `success = false`.
6. `revert FailedToSendEther()` rolls back the entire transaction including the nonce write.
7. The ETH (`amount` wei) remains in `OmniBridge` with no path to recover it. Every subsequent `finTransfer` attempt reverts identically. [3](#0-2)

    function finTransfer(
        bytes calldata signatureData,
        BridgeTypes.TransferMessagePayload calldata payload
    ) external payable whenNotPaused(PAUSED_FIN_TRANSFER) {
        if (completedTransfers[payload.destinationNonce]) {
            revert NonceAlreadyUsed(payload.destinationNonce);
        }

        completedTransfers[payload.destinationNonce] = true;

        bytes memory borshEncoded = bytes.concat(
            bytes1(uint8(BridgeTypes.PayloadType.TransferMessage)),
            Borsh.encodeUint64(payload.destinationNonce),
            bytes1(payload.originChain),
            Borsh.encodeUint64(payload.originNonce),
            bytes1(omniBridgeChainId),
            Borsh.encodeAddress(payload.tokenAddress),
            Borsh.encodeUint128(payload.amount),
            bytes1(omniBridgeChainId),
            Borsh.encodeAddress(payload.recipient),
            bytes(payload.feeRecipient).length == 0 // None or Some(String) in rust
                ? bytes("\x00")
                : bytes.concat(
                    bytes("\x01"),
                    Borsh.encodeString(payload.feeRecipient)
                ),
            bytes(payload.message).length == 0
                ? bytes("")
                : Borsh.encodeBytes(payload.message)
        );
        bytes32 hashed = keccak256(borshEncoded);

        if (ECDSA.recover(hashed, signatureData) != nearBridgeDerivedAddress) {
            revert InvalidSignature();
        }

        MultiTokenInfo memory multiToken = multiTokens[payload.tokenAddress];

        if (payload.tokenAddress == address(0)) {
            // slither-disable-next-line arbitrary-send-eth
            (bool success, ) = payload.recipient.call{value: payload.amount}(
                ""
            );
            if (!success) revert FailedToSendEther();
        } else if (multiToken.tokenAddress != address(0)) {
            IERC1155(multiToken.tokenAddress).safeTransferFrom(
                address(this),
                payload.recipient,
                multiToken.tokenId,
                payload.amount,
                ""
            );

            ICustomMinter(customMinters[payload.tokenAddress]).mint(
                payload.tokenAddress,
                payload.recipient,
                payload.amount
            );
        } else if (isBridgeToken[payload.tokenAddress]) {
            if (payload.message.length == 0) {
                IBridgeToken(payload.tokenAddress).mint(
                    payload.recipient,
                    payload.amount
                );
            } else {
                IBridgeToken(payload.tokenAddress).mint(
                    payload.recipient,
                    payload.amount,
                    payload.message
                );
            }
        } else {
            IERC20(payload.tokenAddress).safeTransfer(
                payload.recipient,
                payload.amount
            );
        }

        finTransferExtension(payload);

        emit BridgeTypes.FinTransfer(

            payload.originNonce,

        );
    }
