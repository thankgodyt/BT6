### Title
`nativeFee` ETH Permanently Locked — No Withdrawal Mechanism (`OmniBridge.sol`)

---

### Summary

Every call to `initTransfer` that includes a non-zero `nativeFee` permanently locks that ETH inside `OmniBridge.sol`. The contract has no admin or user withdrawal function for accumulated native fees, and the `receive()` fallback compounds the issue by silently accepting arbitrary ETH with no recovery path.

---

### Finding Description

In `OmniBridge.initTransfer`, the caller sends `msg.value` covering both the bridged `amount` (for native ETH transfers) and a `nativeFee`. The function computes `extensionValue` by subtracting `nativeFee` from `msg.value`: [1](#0-0) 

```solidity
if (tokenAddress == address(0)) {
    extensionValue = msg.value - amount - nativeFee;
} else {
    extensionValue = msg.value - nativeFee;
    ...
}
```

Only `extensionValue` is forwarded to `initTransferExtension`. In `OmniBridgeWormhole`, that extension passes `value` (i.e., `extensionValue`) to Wormhole's `publishMessage`: [2](#0-1) 

```solidity
_wormhole.publishMessage{value: value}(
    wormholeNonce,
    payload,
    _consistencyLevel
);
```

The `nativeFee` portion is never forwarded anywhere — it stays in the contract. A search across all `.sol` files confirms there is no `withdraw`, `unstake`, or `refund` function anywhere in the contract suite. The only ETH egress paths are:

- `finTransfer` sending ETH to a recipient when `tokenAddress == address(0)` (bridged native ETH, not fees)
- `_wormhole.publishMessage` calls (fed by `extensionValue`, not `nativeFee`)

Additionally, the bare `receive()` fallback silently accepts arbitrary ETH with no accounting or recovery: [3](#0-2) 

```solidity
receive() external payable {}
```

`finTransfer` is also marked `payable` and its Wormhole extension forwards its own `msg.value` to Wormhole — it does not draw from the accumulated `nativeFee` pool: [4](#0-3) 

---

### Impact Explanation

Every `initTransfer` call with `nativeFee > 0` permanently destroys that ETH from the user's perspective — it enters the contract and can never leave. Over the bridge's lifetime, the total locked ETH equals the sum of all `nativeFee` values ever paid by users. This is a direct, irreversible loss of user funds with no recovery mechanism, matching the "permanent freezing of bridged funds" impact class.

---

### Likelihood Explanation

`nativeFee` is a first-class parameter of the public `initTransfer` interface and is the normal mechanism by which users compensate relayers for cross-chain message delivery. Any user performing a standard bridge transfer who sets `nativeFee > 0` triggers the lock. This is the expected, documented usage path — not an edge case. [5](#0-4) 

---

### Recommendation

Add an admin-controlled ETH withdrawal function (e.g., `withdrawFees(address payable recipient, uint256 amount) external onlyRole(DEFAULT_ADMIN_ROLE)`) so accumulated `nativeFee` ETH can be distributed to relayers or returned. Alternatively, forward `nativeFee` directly to a designated fee recipient address inside `initTransfer` rather than leaving it in the contract.

---

### Proof of Concept

1. User calls `initTransfer(erc20Token, 1e18, 0, 0.01 ether, "near:recipient", "")` sending `msg.value = 0.01 ether` as `nativeFee`.
2. `extensionValue = 0.01 ether - 0.01 ether = 0`.
3. `_wormhole.publishMessage{value: 0}(...)` is called — Wormhole receives nothing (or reverts if it requires a fee, but the `nativeFee` is still not forwarded).
4. `0.01 ether` remains in `OmniBridge`'s balance.
5. No function exists to retrieve it. `address(OmniBridge).balance` grows monotonically with every `initTransfer` call that includes a `nativeFee`. [6](#0-5) [7](#0-6)

    function initTransferExtension(
        address sender,
        address tokenAddress,
        uint64 originNonce,
        uint128 amount,
        uint128 fee,
        uint128 nativeFee,
        string calldata recipient,
        string calldata message,
        uint256 value
    ) internal override {
        bytes memory payload = bytes.concat(
            bytes1(uint8(MessageType.InitTransfer)),
            bytes1(omniBridgeChainId),
            Borsh.encodeAddress(sender),
            bytes1(omniBridgeChainId),
            Borsh.encodeAddress(tokenAddress),
            Borsh.encodeUint64(originNonce),
            Borsh.encodeUint128(amount),
            Borsh.encodeUint128(fee),
            Borsh.encodeUint128(nativeFee),
            Borsh.encodeString(recipient),
            Borsh.encodeString(message)
        );
        // slither-disable-next-line reentrancy-eth
        _wormhole.publishMessage{value: value}(
            wormholeNonce,
            payload,
            _consistencyLevel
        );

        wormholeNonce++;
    }
