### Title
Starknet `init_transfer()` Accepts Any Arbitrary Token Address Without Registration Check, Causing Permanent Fund Loss - (File: starknet/src/omni_bridge.cairo)

### Summary

The `init_transfer()` function in the Starknet bridge accepts any caller-supplied `token_address` without verifying that the token is registered in the bridge's token registry. Tokens transferred to the bridge for an unregistered token address are permanently locked with no recovery path.

### Finding Description

In `starknet/src/omni_bridge.cairo`, the `init_transfer()` function accepts a `token_address` parameter directly from the caller. The only check performed on this address is `is_bridge_token(token_address)`, which determines the *transfer mechanism* (burn vs. `transfer_from`) — not whether the token is actually registered and supported by the bridge. [1](#0-0) 

`is_bridge_token` returns `true` only if the token was deployed by the bridge via `deploy_token()` (i.e., it exists in `starknet_to_near_token`): [2](#0-1) 

For any token that is *not* a bridge-deployed token, the function falls through to the `else` branch and calls `transfer_from` on the arbitrary address without any further validation: [3](#0-2) 

After pulling the tokens, the function increments the nonce and emits an `InitTransfer` event with the unregistered token address: [4](#0-3) 

On the NEAR side, when a relayer attempts to finalize this transfer, `get_token_id()` will panic with `TokenNotRegistered` because the Starknet token address has no entry in `token_address_to_id`: [5](#0-4) 

The Starknet bridge contract has no token-rescue or admin-withdrawal function. The full contract exposes only `log_metadata`, `deploy_token`, `fin_transfer`, `init_transfer`, `upgrade_token`, `set_pause_flags`, `pause_all`, `upgrade`, and view functions — none of which can recover arbitrary ERC20 tokens locked in the contract: [6](#0-5) 

### Impact Explanation

Any user who calls `init_transfer()` with a token address that is not registered in the bridge (i.e., not present in `starknet_to_near_token`) will have their tokens permanently locked in the Starknet bridge contract. The cross-chain transfer will never be finalized on NEAR because the NEAR bridge cannot resolve the unregistered token address. There is no refund, no rescue function, and no admin path to recover the funds. This constitutes permanent freezing of bridged funds.

### Likelihood Explanation

The entry point is fully public and unprivileged. Any Starknet user can call `init_transfer()` with any `ContractAddress`. A user who holds a legitimate Starknet ERC20 token that has not yet been registered via `deploy_token()` (e.g., a newly listed token, a token whose `log_metadata` was submitted but `deploy_token` not yet executed on NEAR, or simply a mistaken address) will trigger this path. No special role, key, or collusion is required.

### Recommendation

Add an explicit registration check in `init_transfer()` before accepting any token transfer. Specifically, verify that the supplied `token_address` is either a bridge-deployed token (`is_bridge_token`) **or** is present in the `starknet_to_near_token` mapping as a registered native token. Reject the call with a clear error (e.g., `'ERR_TOKEN_NOT_REGISTERED'`) if neither condition holds:

```cairo
fn init_transfer(ref self: ContractState, token_address: ContractAddress, ...) {
    // Add this check:
    let is_registered = self.is_bridge_token(token_address)
        || self.starknet_to_near_token.read(token_address).len() > 0;
    assert(is_registered, 'ERR_TOKEN_NOT_REGISTERED');
    // ... rest of function
}
```

### Proof of Concept

1. Alice holds 1000 units of `TokenX`, a legitimate Starknet ERC20 that has not been registered in the Omni Bridge.
2. Alice calls `init_transfer(token_address=TokenX, amount=1000, fee=0, native_fee=0, recipient="alice.near", message="")`.
3. The function passes the pause check, amount/fee checks, and increments the nonce.
4. `is_bridge_token(TokenX)` returns `false` (not in `starknet_to_near_token`).
5. `IERC20Dispatcher { contract_address: TokenX }.transfer_from(alice, bridge, 1000)` succeeds — Alice's 1000 `TokenX` are now held by the bridge.
6. An `InitTransfer` event is emitted with `token_address = TokenX`.
7. A relayer picks up the event and calls `fin_transfer` on NEAR.
8. NEAR's `get_token_id(&OmniAddress::Starknet(TokenX))` panics with `ERR_TOKEN_NOT_REGISTERED`.
9. The transfer is never finalized. Alice's 1000 `TokenX` are permanently locked in the Starknet bridge contract with no recovery mechanism. [7](#0-6)

        fn init_transfer(
            ref self: ContractState,
            token_address: ContractAddress,
            amount: u128,
            fee: u128,
            native_fee: u128,
            recipient: ByteArray,
            message: ByteArray,
        ) {
            assert(!_is_paused(@self, PAUSE_INIT_TRANSFER), 'ERR_INIT_TRANSFER_PAUSED');

            assert(amount > 0, 'ERR_ZERO_AMOUNT');
            assert(fee < amount, 'ERR_INVALID_FEE');

            let origin_nonce = self.current_origin_nonce.read() + 1;
            self.current_origin_nonce.write(origin_nonce);

            let caller = get_caller_address();

            if self.is_bridge_token(token_address) {
                IBridgeTokenDispatcher { contract_address: token_address }
                    .burn(caller, amount.into());
            } else {
                let success = IERC20Dispatcher { contract_address: token_address }
                    .transfer_from(caller, get_contract_address(), amount.into());
                assert(success, 'ERR_TRANSFER_FROM_FAILED');
            }

            if native_fee > 0 {
                let native_token = self.strk_token_address.read();
                let success = IERC20Dispatcher { contract_address: native_token }
                    .transfer_from(caller, get_contract_address(), native_fee.into());
                assert(success, 'ERR_FEE_TRANSFER_FAILED');
            }

            self
                .emit(
                    Event::InitTransfer(
                        InitTransfer {
                            sender: caller,
                            token_address,
                            origin_nonce,
                            amount,
                            fee,
                            native_fee,
                            recipient,
                            message,
                        },
                    ),
                )
        }
